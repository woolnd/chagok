# 신경망

## 1. 퍼셉트론에서 신경망으로

퍼셉트론은 복잡한 함수도 표현이 가능하다는 장점이 있지만, 가중치를 설정하는 작업은 여전히 사람이 수동으로 해야 한다는 단점이 있다. 신경망은 이 단점을 해결한다. 가중치 매개변수의 적절한 값을 데이터로부터 자동으로 학습하는 능력을 갖추고 있기 때문이다.

그림: 입력층(노드 2개) → 은닉층(노드 3개) → 출력층(노드 2개). 앞 층의 모든 노드가 다음 층의 모든 노드와 연결

가운데 은닉층은 사람 눈에 보이지 않는다.

## 2. 활성화 함수

활성화 함수(Activation Function): 입력 신호에 가중치를 곱하고 편향을 더한 총합을 받아, 이를 적절한 출력 신호로 변환해 주는 함수다.

### 퍼셉트론 복습

활성화 함수가 어디서 나오는지 퍼셉트론 식부터 다시 보면 다음과 같다.

```text
y = 0   (b + w₁x₁ + w₂x₂ ≤ 0)
y = 1   (b + w₁x₁ + w₂x₂ > 0)
```

여기서 b는 편향이고, 편향은 입력 신호가 항상 1이다. 퍼셉트론 식 w₁x₁ + w₂x₂ > θ에서 θ를 왼쪽으로 넘기면 −θ + w₁x₁ + w₂x₂ > 0이 된다. 이 −θ가 편향 b다 (b = −θ). 그래서 임계값이 높을수록 편향은 작아져 활성화되기 어렵다.

b + w₁x₁ + w₂x₂를 x라 생각하면 아래처럼 쓸 수 있다.

```text
y = h(b + w₁x₁ + w₂x₂)

h(x) = 0   (x ≤ 0)
h(x) = 1   (x > 0)
```

입력 신호의 총합이 h(x)라는 함수를 거쳐 변환되고, 그 변환된 값이 y로 출력된다. 다시 말해 h(x)는 입력 신호의 총합이 활성화를 일으키는지를 정하는 역할을 하고, 이것이 활성화 함수다.

### 뉴런 a와 y

이 과정을 두 단계로 나눠 쓰면 다음과 같다.

```text
a = b + w₁x₁ + w₂x₂
y = h(a)
```

가중치와 입력신호를 조합한 결과가 a라는 뉴런이 되고, 활성화 함수 h()를 통과하여 y라는 뉴런으로 변화되는 과정이다.

## 3. 계단 함수

계단 함수(Step Function): 입력값이 특정 임계값(Threshold)을 넘느냐 넘지 않느냐에 따라 출력이 0에서 1로(또는 지정된 값으로) 급격히 바뀌는 함수다.

퍼셉트론 복습에서 본 h(x)가 바로 계단 함수다.

```text
h(x) = 0   (x ≤ 0)
h(x) = 1   (x > 0)
```

그림: x가 0 이하면 0, 0을 넘으면 1로 계단처럼 한 번에 올라간다

## 4. 시그모이드 함수

시그모이드 함수: 입력을 0과 1 사이의 부드러운 값으로 바꿔주는 활성화 함수. 퍼셉트론의 계단 함수를 "부드럽게" 만든 버전이라고 보면 된다.

```text
h(x) = 1 / (1 + exp(−x))
```

그림: 왼쪽에서 0에 가깝다가 S자 곡선으로 부드럽게 올라가 오른쪽에서 1에 가까워진다

## 5. 계단 함수와 시그모이드 함수 비교

### 차이점

가장 큰 차이는 매끈함이다. 계단 함수는 0을 경계로 출력이 갑자기 바뀌어 0과 1 중 하나의 값만 돌려주는 반면, 시그모이드 함수는 부드러운 곡선이라 입력에 따라 출력이 연속적으로 변화하는 실수를 돌려준다.

매끈함은 정말 중요하다. 시그모이드는 가중치를 조금 바꾸면 출력도 조금 바뀌어, 가중치를 어느 방향으로 고쳐야 할지 알 수 있다. 계단 함수는 출력이 거의 안 바뀌어 알 수 없다. 따라서 퍼셉트론에서는 뉴런 사이에 0 혹은 1이 흐르고, 신경망에서는 연속적인 실수가 흐른다.

### 공통점

둘은 같은 모양을 하고 있다. 입력이 작을 때 출력은 0에 가깝고(혹은 0), 입력이 커지면 출력이 1에 가까워진다(혹은 1). 따라서 입력이 중요하면 큰 값을, 중요하지 않으면 작은 값을 출력한다. 그리고 입력이 아무리 작거나 커도 출력은 0에서 1 사이다.

## 6. 비선형 함수

계단 함수와 시그모이드 함수는 또 하나의 공통점이 있다. 둘 다 비선형 함수라는 것이다. 신경망에서는 활성화 함수로 비선형 함수를 사용해야 한다.

선형 함수를 쓰면 안 되는 이유는 층을 깊게 하는 의미가 없어지기 때문이다. 활성화 함수가 h(x) = cx처럼 선형 함수이면, 여러 번 겹쳐도 하나의 선형 함수로 합쳐진다. 그래서 층을 깊게 쌓아도 은닉층 없는 네트워크와 같다.

퍼셉트론으로 만든 XOR 게이트에서도 사실상 비선형 활성화 함수를 사용한 것이다.

## 7. ReLU 함수

ReLU 함수: 입력이 0을 넘으면 그 입력을 그대로 출력하고, 0 이하이면 0을 출력하는 함수.

```text
h(x) = x   (x > 0)
h(x) = 0   (x ≤ 0)
```

그림: x가 0 이하면 0으로 평평하다가, 0을 넘으면 오른쪽 위로 곧게 올라가는 직선

최근에는 시그모이드 함수 대신 ReLU 함수를 사용한다. 시그모이드 함수는 입력이 아주 크거나 작으면 기울기가 0에 가까워지고, 최대 기울기도 0.25에 불과하다. 역전파 때 이 작은 기울기가 층마다 곱해지면서 앞쪽 층으로 갈수록 기울기가 0에 가까워져 학습이 되지 않는 기울기 소실 문제가 생긴다. ReLU는 입력이 0보다 크면 기울기가 항상 1이라 기울기가 줄어들지 않아 이 문제를 완화한다. 다만 음수 입력에서는 기울기가 0이라 뉴런이 죽는 문제가 있어, Leaky ReLU 같은 변형을 쓰기도 한다.

## 8. 출력층 설계

신경망은 분류와 회귀 모두에 이용할 수 있다. 어떤 문제냐에 따라 출력층에서 사용하는 활성화 함수가 달라지는데, 일반적으로 회귀에는 항등 함수를, 분류에는 소프트맥스 함수를 사용한다.

### 분류와 회귀

분류는 데이터가 어느 클래스에 속하느냐는 문제이고, 회귀는 입력 데이터에서 수치를 예측하는 문제다.

### 항등 함수

회귀에 쓰는 항등 함수는 입력을 그대로 출력한다. 그래서 입력 신호가 그대로 출력 신호가 된다.

### 소프트맥스 함수

분류에 쓰는 소프트맥스 함수는 다음과 같다.

```text
yₖ = exp(aₖ) / Σᵢ₌₁ⁿ exp(aᵢ)
```

분자는 입력 신호 aₖ의 지수 함수이고, 분모는 모든 입력 신호의 지수 함수의 합으로 구성된다. 소프트맥스 함수의 출력은 0에서 1 사이의 값이며 총합은 1이다.

## 9. 전처리와 배치

출력층을 정했으니 이번에는 신경망에 들어가는 입력 데이터를 본다. 전처리는 신경망의 입력 데이터에 특정 변환을 가하는 작업이고, 정규화는 데이터를 특정 범위로 변환하는 처리다. 배치는 하나로 묶은 입력 데이터다.

## 10. 학습 과정

신경망은 가중치를 데이터로부터 자동으로 학습한다고 했다. 그 과정은 순전파로 예측하고, 손실로 틀린 정도를 재고, 역전파로 기울기를 구해, 경사하강법으로 가중치를 고치는 순서로 이어진다.

### 순전파

순전파는 입력 데이터를 입력층에서 출력층 방향으로 전달하며, 각 층에서 가중합·편향·활성화 함수를 차례로 적용해 예측값을 계산하는 과정이다. 예측값이 나오면, 이것이 정답과 얼마나 다른지 확인해야 한다.

### 손실

손실은 예측값과 정답의 차이를 숫자로 나타낸 값이다. 손실이 작을수록 예측이 정답에 가깝다. 손실을 줄이려면 예측을 바꿔야 하고, 예측을 바꿀 수 있는 값은 가중치뿐이다. 그렇다면 가중치를 어느 방향으로 바꿔야 할지 알아야 한다.

### 미분

미분은 입력을 아주 조금 바꿨을 때 출력이 얼마나 변하는지를 나타내는 순간 변화율(기울기)이다. 손실을 가중치로 미분한 값은 현재 가중치에서 손실의 경사(손실의 변화량)를 나타낸다. 즉, 가중치를 조금 바꿨을 때 손실이 어느 방향으로, 얼마나 민감하게(몇 배로) 변하는지를 의미한다. 하지만 손실과 가중치 사이에는 여러 층이 끼어 있어 직접 미분할 수 없다.

### 연쇄법칙

연쇄법칙은 여러 단계로 연결된 합성 함수에서, 처음 값을 조금 바꿨을 때 마지막 값이 얼마나 변하는지(미분)를 각 단계의 미분을 곱해서 구하는 법칙이다. 그래서 처음부터 끝까지의 변화율은 각 단계 배율의 곱이 된다. 이 법칙을 신경망 전체에 효율적으로 적용하는 방법이 역전파다.

### 역전파

역전파는 연쇄법칙을 이용해 손실에 대한 각 층의 가중치의 기울기(손실/가중치)를 출력층에서 입력층 방향으로 거꾸로 계산하는 과정이다. 각 층은 뒤에서 넘겨받은 "손실을 이 층의 출력으로 미분한 값"(손실/출력)에 "이 층의 출력을 자기 가중치로 미분한 값"(출력/가중치)을 곱한다. 곱하면 분수를 약분하듯 중간의 "출력"이 상쇄되어, 가중치가 바뀔 때 손실이 얼마나 변하는지(손실/가중치)만 남는다. 이어서 손실/출력에 "이 층의 출력을 입력으로 미분한 값"(출력/입력)을 곱해 앞 층에 넘겨준다.

곱하는 순서를 반드시 뒤에서부터 해야 하는 것은 아니지만, 뒤쪽에서 구한 값을 앞쪽 층들이 재사용할 수 있어 모든 가중치의 기울기를 효율적으로 한 번에 구할 수 있다. 이 기울기는 손실이 줄어드는 방향을 알려주며, 경사하강법이 그 반대 방향으로 가중치를 조금씩 조절한다. 다만 층마다 곱해지는 값이 계속 1보다 작으면 앞쪽으로 갈수록 기울기가 0에 가까워지는데, 이것이 ReLU 함수에서 본 기울기 소실이다.

### 경사하강법

경사하강법은 각 가중치의 기울기(손실의 경사) 반대 방향으로 가중치를 조금씩 옮겨 손실을 줄이는 방법이다.

```text
새 가중치 = 현재 가중치 − 학습률 × 기울기
```

기울기가 양수면 가중치를 줄이고, 음수면 늘린다.
