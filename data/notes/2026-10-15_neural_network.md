# 신경망

## 1. 퍼셉트론에서 신경망으로

- 퍼셉트론의 장점: 복잡한 함수도 표현이 가능
- 퍼셉트론의 단점: 가중치를 설정하는 작업은 여전히 사람이 수동으로
- 신경망은 단점을 해결 어떻게?: 가중치 매개변수의 적절한 값을 데이터로부터 자동으로 학습하는 능력을 갖추고 있다.
- 그림: 입력층(노드 2개) → 은닉층(노드 3개) → 출력층(노드 2개). 앞 층의 모든 노드가 다음 층의 모든 노드와 연결
- 은닉층은 사람 눈에 보이지 않는다

## 2. 활성화 함수

활성화 함수(Activation Function): 입력 신호에 가중치를 곱하고 편향을 더한 총합을 받아, 이를 적절한 출력 신호로 변환해 주는 함수입니다.

### 퍼셉트론 복습

```text
y = 0   (b + w₁x₁ + w₂x₂ ≤ 0)
y = 1   (b + w₁x₁ + w₂x₂ > 0)
```

- 편향은 입력 신호가 항상 1
- 퍼셉트론 식 w₁x₁ + w₂x₂ > θ에서 θ를 왼쪽으로 넘기면 −θ + w₁x₁ + w₂x₂ > 0이 된다. 이 −θ가 편향 b다 (b = −θ). 임계값이 높을수록 편향은 작아져 활성화되기 어렵다
- b + w₁x₁ + w₂x₂를 x라 생각하면 아래처럼 쓸 수 있다

```text
y = h(b + w₁x₁ + w₂x₂)

h(x) = 0   (x ≤ 0)
h(x) = 1   (x > 0)
```

- 입력 신호의 총합이 h(x)라는 함수를 거쳐 변환되어 그 변환된 값이 y의 출력이 됨
- 다시 말해 입력 신호의 총합이 활성화를 일으키는지를 정하는 역할

### 뉴런 a와 y

```text
a = b + w₁x₁ + w₂x₂
y = h(a)
```

- 가중치와 입력신호를 조합한 결과가 a라는 뉴런이 되고 활성화 함수 h()를 통과하여 y라는 뉴런으로 변화되는 과정이다.

## 3. 계단 함수

계단 함수(Step Function)는 입력값이 특정 임계값(Threshold)을 넘느냐 넘지 않느냐에 따라 출력이 0에서 1로(또는 지정된 값으로) 급격히 바뀌는 함수입니다.

```text
h(x) = 0   (x ≤ 0)
h(x) = 1   (x > 0)
```

- 그림: x가 0 이하면 0, 0을 넘으면 1로 계단처럼 한 번에 올라간다

## 4. 시그모이드 함수

시그모이드 함수는 입력을 0과 1 사이의 부드러운 값으로 바꿔주는 활성화 함수예요. 퍼셉트론의 계단 함수를 "부드럽게" 만든 버전이라고 보면 됩니다.

```text
h(x) = 1 / (1 + exp(−x))
```

- 그림: 왼쪽에서 0에 가깝다가 S자 곡선으로 부드럽게 올라가 오른쪽에서 1에 가까워진다

## 5. 계단 함수와 시그모이드 함수 비교

### 차이점

- 시그모이드 함수는 부드러운 곡선, 입력에 따라 출력이 연속적으로 변화
- 계단함수는 0을 경계로 출력이 갑자기 바뀌어버립니다.
- 매끈함은 정말 중요: 계단 함수는 0과 1중 하나의 값만 돌려주는 반면 시그모이드 함수는 실수를 돌려준다. 그래서 가중치를 조금 바꾸면 출력도 조금 바뀌어, 가중치를 어느 방향으로 고쳐야 할지 알 수 있다 (계단 함수는 출력이 거의 안 바뀌어 알 수 없다)
- 따라서 퍼셉트론에서는 뉴런 사이에 0 혹은 1이 흐르고 신경망에서는 연속적인 실수가 흐른다.

### 공통점

- 둘은 같은 모양을 하고 있다. 입력이 작을때 출력은 0에 가깝고 (혹은 0) 입력이 커지면 출력이 1에 가까워진다 (혹은 1)
- 따라서 입력이 중요하면 큰 값을 출력하고 입력이 중요하지 않으면 작은 값을 출력
- 아무리 작아도 커도 출력은 0에서 1사이다

## 6. 비선형 함수

활성화 함수가 h(x) = cx처럼 선형 함수이면, 여러 번 겹쳐도 하나의 선형 함수로 합쳐진다. 그래서 층을 깊게 쌓아도 은닉층 없는 네트워크와 같다. 따라서 층을 쌓는 효과를 얻으려면 비선형 활성화 함수가 필요하다.

- 계단 함수와 시그모이드 함수 둘다 비선형 함수이다
- 신경망에서는 활성화 함수로 비선형 함수를 사용해야 합니다.
- 선형함수 X why: 선형 함수를 이용하면 신경망의 층을 깊게 하는 의미가 없기 때문이다.
- XOR 게이트에서도 사실상 비선형 활성화 함수를 사용한 것이다.

## 7. ReLU 함수

- 최근에는 시그모이드 함수 대신 ReLU함수를 사용
- 왜 ReLU?: 시그모이드는 입력이 아주 크거나 작으면 곡선이 거의 평평해져, 학습할 때 가중치를 고치는 신호(기울기)가 0에 가까워진다. 층이 깊을수록 이 신호가 층마다 줄어들어 앞쪽 층은 거의 학습되지 않는다 (기울기 소실). ReLU는 0을 넘으면 기울기가 항상 1이라 신호가 줄지 않고, 계산도 단순하다
- ReLU함수는 입력이 0을 넘으면 그 입력을 그대로 출력하고 이하이면 0을 출력하는 함수

```text
h(x) = x   (x > 0)
h(x) = 0   (x ≤ 0)
```

- 그림: x가 0 이하면 0으로 평평하다가, 0을 넘으면 오른쪽 위로 곧게 올라가는 직선
