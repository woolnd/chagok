# 합성곱 신경망(CNN)

## 1. 전체 구조

합성곱 신경망(CNN)은 합성곱 계층과 풀링 계층을 써서, 이미지처럼 형상을 가진 데이터를 공간 정보를 유지한 채 처리하며 특징을 뽑아내는 신경망이다. 주로 이미지 인식에 쓰인다.

지금까지 본 신경망은 인접하는 계층의 모든 뉴런과 결합되어 있었다. 이를 완전연결이라고 하며, 완전히 연결된 계층을 Affine 계층이라고 한다.

그림: x → Affine → ReLU → Affine → ReLU → Affine → ReLU → Affine → ReLU → Affine → Softmax

완전연결 신경망은 Affine 계층 뒤에 활성화 함수를 갖는 ReLU 계층이 이어진다. 이 그림에서는 Affine-ReLU 조합이 4개 쌓였고, 마지막 5번째 층은 Affine 계층에 이어 소프트맥스 계층에서 최종 결과를 출력한다. 소프트맥스는 출력층의 각 값에 exp를 취한 뒤 전체 합으로 나누어, 0~1 사이이고 합이 1인 확률로 변환하는 함수다. 값의 크기 순서는 유지되며, 다중 분류의 출력층에서 교차 엔트로피 손실과 함께 쓰인다.

그림: x → Conv → ReLU → Pooling → Conv → ReLU → Pooling → Conv → ReLU → Affine → ReLU → Affine → Softmax

CNN에서는 새로운 합성곱 계층(Conv)과 풀링 계층(Pooling)이 추가된다. CNN의 계층은 Conv-ReLU-(Pooling) 흐름으로 연결된다. 주목할 점은 출력에 가까운 층에서는 지금까지의 Affine-ReLU 구성을 사용할 수 있다는 것이다. 마지막 출력 계층에서는 Affine-Softmax 조합을 그대로 사용한다.

## 2. 합성곱 계층

### 완전연결 계층의 문제점

완전연결 계층에서는 인접하는 계층의 뉴런이 모두 연결되고, 출력의 수는 임의로 정할 수 있다. 문제는 데이터의 형상이 무시된다는 것이다. 입력 데이터가 이미지인 경우, 이미지는 통상 세로·가로·채널(색상)로 구성된 3차원 데이터다. 그러나 완전연결 계층에 입력할 때는 3차원 데이터를 평평한 1차원 데이터로 평탄화해 줘야 한다.

이미지는 3차원 형상이며, 이 형상에는 공간적 정보가 담겨 있다. 3차원 속에는 의미를 갖는 본질적인 패턴이 숨어 있을 것이다. 그러나 완전연결 계층은 형상을 무시하고 모든 입력 데이터를 동등한 뉴런으로 취급하여, 형상에 담긴 정보를 살릴 수 없다.

한편 합성곱 계층은 형상을 유지한다. 이미지도 3차원 데이터로 입력받으며, 다음 계층에도 3차원 데이터로 전달한다. 그래서 CNN에서는 이미지처럼 형상을 가진 데이터를 제대로 이해할 가능성이 있다. 합성곱 계층의 입출력 데이터를 특징 맵이라고도 한다. 입력 데이터를 입력 특징 맵, 출력 데이터를 출력 특징 맵이라고 한다.

### 합성곱 연산

합성곱 계층에서는 합성곱 연산을 처리한다. 합성곱 연산은 이미지 처리에서 말하는 필터 연산에 해당한다.

그림: 입력 4×4 (1 2 3 0 / 0 1 2 3 / 3 0 1 2 / 2 3 0 1) ⊛ 필터 3×3 (2 0 1 / 0 1 2 / 1 0 2) → 출력 2×2 (15 16 / 6 15)

합성곱 연산은 입력 데이터에 필터를 적용한다. 위 예에서는 입력 (4, 4), 필터 (3, 3), 출력 (2, 2)가 된다. 필터를 커널이라고도 한다.

윈도우는 필터가 현재 겹쳐 있는 입력 데이터의 영역이며, 크기는 필터와 같다. 합성곱 연산은 필터의 윈도우를 일정 간격으로 이동해 가며 입력 데이터에 적용한다. 그리고 입력과 필터에서 대응하는 원소끼리 곱한 후 그 총합을 구한다.

완전연결 신경망에는 가중치 매개변수와 편향이 존재하는데, CNN에서는 필터의 매개변수가 그동안의 가중치에 해당한다. 편향은 필터를 적용한 후의 데이터에 더해진다. 편향은 항상 하나(1×1)만 존재하며, 그 하나의 값을 필터를 적용한 모든 원소에 더한다.

### 패딩

합성곱 연산을 수행하기 전에 입력 데이터 주변을 특정 값(예컨대 0)으로 채우기도 한다. 이를 패딩(padding)이라 한다.

패딩은 주로 출력 크기를 조정할 목적으로 사용한다. 합성곱 연산을 거칠 때마다 크기가 작아지면 어느 시점에서는 출력 크기가 1이 되어 버려, 더 이상은 합성곱 연산을 적용할 수 없다. 이러한 사태를 막기 위해 패딩을 사용한다. 예를 들어 (4, 4) 입력에 폭 1의 패딩을 하면 출력이 (4, 4)로 유지된다.

### 스트라이드

필터를 적용하는 위치의 간격을 스트라이드(stride)라고 한다. 스트라이드를 2로 하면 필터를 적용하는 윈도우가 두 칸씩 이동한다.

이처럼 스트라이드를 키우면 출력 크기는 작아지고, 패딩을 크게 하면 출력 크기가 커진다. 입력 크기를 (H, W), 필터 크기를 (FH, FW), 출력 크기를 (OH, OW), 패딩을 P, 스트라이드를 S라고 하면 출력 크기는 다음과 같다.

```text
OH = (H + 2P − FH) / S + 1
OW = (W + 2P − FW) / S + 1
```

출력 크기가 정수가 아니면 오류를 내는 등의 대응을 해 줘야 한다. 그래서 가장 가까운 정수로 반올림하는 경우도 있다.

### 3차원 데이터의 합성곱 연산

채널 쪽으로 특징 맵이 여러 개 있다면, 입력 데이터와 필터의 합성곱 연산을 채널마다 수행하고 그 결과를 더해서 하나의 출력을 얻는다. 3차원 합성곱 연산에서 주의할 점은 입력 데이터의 채널 수와 필터의 채널 수가 같아야 한다는 것이다.

### 블록으로 생각하기

보통 출력 데이터는 한 장의 특징 맵이다. 다수의 채널을 내보내려면 필터를 다수 사용한다. 필터를 FN개 적용하면 출력 맵도 FN개가 생성되고, 그 FN개의 맵을 모으면 형상이 (FN, OH, OW)가 된다. 이 완성된 블록을 다음 계층으로 넘기겠다는 것이 CNN의 처리 흐름이다.

이처럼 합성곱 연산에서는 필터의 수도 고려해야 한다. 필터의 가중치 데이터는 4차원 데이터이며 (출력 채널 수, 입력 채널 수, 높이, 너비) 순이다. 편향은 채널 하나에 값 하나씩 구성되며, 형상은 (FN, 1, 1)이다.

### 배치 처리

미니배치는 전체 데이터에서 뽑은 일부 묶음(무엇을 학습할지)이고, 배치 처리는 그 묶음을 행렬로 쌓아 한 번에 계산하는 방식(어떻게 계산할지)이다.

합성곱 연산도 배치 처리가 가능하다. 데이터의 차원을 하나 늘려 4차원 데이터 (데이터 수, 채널 수, 높이, 너비)로 다룬다. 신경망에 4차원 데이터가 하나 흐를 때마다 데이터 N개에 대한 합성곱 연산이 이루어진다. 즉 N회분의 처리를 한 번에 수행한다.

## 3. 풀링 계층

풀링은 세로·가로 방향의 공간을 줄이는 연산이다. 최대 풀링은 대상 영역에서 최댓값을 취하는 연산이고, 평균 풀링은 대상 영역의 평균을 계산한다.

풀링 계층의 특징은 3가지다. 첫째, 학습해야 할 매개변수가 없다. 풀링은 대상 영역에서 최댓값이나 평균을 취하는 명확한 처리이므로 특별히 학습할 것이 없다. 둘째, 채널 수가 변하지 않는다. 채널마다 독립적으로 계산하기 때문에 입력 데이터의 채널 수 그대로 출력 데이터로 내보낸다. 셋째, 입력의 변화에 영향을 적게 받는다. 입력 데이터가 조금 변해도 풀링의 결과는 잘 변하지 않는다.

## 4. 필터와 특징 맵

합성곱 계층의 필터(가중치)는 무엇을 찾을지에 대한 기준이다. 어떤 패턴을 찾을지를 학습해 담고 있으며, 모든 입력 이미지에 똑같이 적용된다. 특징 맵(합성곱 출력)은 필터를 기준으로 입력에서 찾아낸 결과다. 입력 이미지에서 그 패턴이 어디에, 얼마나 있는지를 담으며 이미지마다 달라진다.

### 층이 깊어질수록

앞쪽 층 필터는 가장자리, 색 변화 같은 단순한 패턴을 찾는다. 중간 층 필터는 앞 층의 특징 맵을 조합해 질감, 모양을 찾는다. 뒤쪽 층 필터는 더 조합해 눈, 바퀴, 얼굴 같은 사물의 부분을 찾는다. 따라서 특징 맵은 층이 깊어질수록 사물의 의미 있는 정보를 더 추상적으로 표현한다.

### 필터의 학습

필터의 값은 사람이 정하는 것이 아니라 학습으로 정해진다. 순전파로 예측해 손실을 계산하고, 역전파로 각 필터 값의 기울기를 구한 뒤, 경사 하강법으로 손실이 줄어드는 방향으로 필터를 수정한다.

필터가 받는 목표는 "손실을 줄여라" 하나지만, 정답을 잘 맞히려면 사물을 구분하는 데 유용한 패턴을 찾아야 한다. 그 결과로 필터가 사물의 중요한 특징을 찾도록 학습된다.

## 5. 대표적인 CNN

### LeNet

LeNet(1998)은 손글씨 숫자 인식을 위해 만든 최초의 CNN이다. 합성곱 계층과 서브샘플링 계층을 반복하고, 마지막에 완전연결 계층으로 결과를 출력한다. 활성화 함수로 시그모이드를 사용하고, 서브샘플링으로 데이터 크기를 줄인다.

서브샘플링은 데이터의 공간 크기(가로·세로)를 줄이는 처리다. LeNet은 영역의 평균값으로 줄였고, 현재 CNN은 주로 최대 풀링을 쓴다. 계산량을 줄이고 작은 위치 변화에 강해지게 한다.

완전연결 계층만 쓰면 이미지를 한 줄로 펼쳐야 해서 가로·세로 위치 관계(공간 정보)가 사라진다. LeNet은 합성곱으로 이미지의 공간 구조를 유지하면서 특징을 뽑고, 필터를 공유해 매개변수 수도 줄이려는 목적으로 등장했다.

### AlexNet

AlexNet(2012)은 이미지 인식 대회(ILSVRC 2012)에서 기존 방법을 큰 차이로 이기며 딥러닝 붐을 일으켰다. 합성곱 5층 + 완전연결 3층 구조로 LeNet보다 크고 깊다. 활성화 함수로 ReLU를 사용하고, LRN으로 국소적 정규화를 하며, 드롭아웃으로 과대적합을 억제한다. GPU를 활용해 대규모 학습을 가능하게 했다.

LRN(국소적 응답 정규화)은 한 뉴런의 출력을 같은 위치 이웃 채널 값들의 제곱합으로 나누어, 비슷하게 강한 반응들은 다 같이 낮추고 혼자 튀는 반응은 상대적으로 더 눈에 띄게 만드는 정규화 방법이다. 하지만 같은 위치에 여러 특징(가장자리, 질감, 모양 등)이 실제로 함께 있어 여러 채널이 같이 강하게 반응하는 경우에도, 이를 특별하지 않다고 보고 모두 낮춰 중요한 정보를 약하게 만들 수 있다. 성능 향상도 크지 않아 현재는 배치 정규화로 대체되었다.

AlexNet이 나올 무렵 ImageNet 같은 대량의 데이터와 GPU의 발전으로 큰 신경망을 학습할 수 있는 환경이 갖춰졌다. 시그모이드는 층이 깊어지면 기울기 소실이 생겨 ReLU로 바꾸었고, 모델이 커지면서 생기는 과대적합을 드롭아웃으로 해결하려 했다.

### VGG

VGG(2014)는 3×3 크기의 작은 필터만 사용해 합성곱 층을 깊게 쌓은 단순한 구조다(16층, 19층 버전). 합성곱 2~4층 뒤에 풀링으로 크기를 절반씩 줄이는 과정을 반복한다. 구조가 단순해 응용하기 쉬워 많이 쓰였지만, 매개변수가 많아(대부분 완전연결 계층) 무겁다.

VGG는 "층을 깊게 하면 성능이 얼마나 좋아지는가"를 확인하려 했다. 3×3 필터 두 번은 5×5 필터 한 번과 같은 영역을 보면서도 매개변수가 적고, 층마다 활성화 함수가 들어가 표현력이 높아진다. 그래서 큰 필터 대신 작은 필터를 깊게 쌓는 방식을 택했다.

### GoogLeNet

GoogLeNet(2014)은 ILSVRC 2014 우승 모델로 22층 구조다. 크기가 다른 필터(1×1, 3×3, 5×5)와 풀링을 가로로 나란히 적용하고 결과를 합치는 인셉션 구조를 사용한다. 1×1 합성곱으로 채널 수를 먼저 줄여 계산량과 매개변수를 크게 줄였다. 그래서 VGG보다 깊으면서도 매개변수는 훨씬 적다.

이미지마다 특징의 크기가 달라 어떤 크기의 필터가 좋은지 정하기 어려웠다. 그래서 여러 크기를 동시에 쓰고 학습으로 고르게 했다. 또 층을 깊고 넓게 하면 계산량이 폭발적으로 늘어나므로, 1×1 합성곱으로 채널을 줄여 효율을 높이려 했다.

### ResNet

ResNet(2015)은 ILSVRC 2015 우승 모델로, 152층까지 깊게 쌓았다. 입력을 몇 개 층을 건너뛰어 출력에 더하는 스킵 연결(Skip Connection, 출력 = F(x) + x)을 사용한다. 층은 입력과의 차이(잔차)만 학습하면 되므로 학습이 쉬워진다.

층을 일정 이상 깊게 쌓으면 오히려 성능이 떨어지는 문제가 있었다. 역전파 때 기울기가 앞쪽 층까지 제대로 전달되지 않았기 때문이다. 스킵 연결은 역전파 때 기울기를 감소 없이 그대로 전달하는 지름길 역할을 해, 매우 깊은 신경망도 학습할 수 있게 했다.
