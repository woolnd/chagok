확인 항목
- 승인 + 안 보낸 문제 중 먼저 승인한 것부터 나오고, 보내면 다시 안 나옴 (대기·반려는 안 나옴)
- AI가 만든 글의 `<eos>`, `x < y`, `<b>` 같은 글자가 escape돼 글자 그대로 보임, 답안 줄바꿈은 `<br>`
- 출처: 검색 판단에서 관련 있다고 본 조각 id를 DB에 저장 → 메일에 "노트 > 소제목 (파일)"로
- Resend가 403(받는 사람 제한) 등으로 실패하면 멈추고 보낸 날을 기록하지 않음 (가짜 서버로 확인)
- 출처가 없는 예전 문제는 노트 태그가 빈 상자로 보임 (앞으로 만드는 문제는 출처가 항상 있음)

## 2026-11-24 · 채점 AI (`feat/#20-grade`)

내가 판정한 문제 20개 (승인·반려 예시. 주말 검토 기록은 아직 0개), Claude Haiku 5.5, 예시 없이 기준만

```
$ uv run --env-file .env python -m chagok.grade

내 승인율 0.60  추정 승인율 0.70

```

| 실행 | 바꾼 것 | 승인/반려 일치 | 사유까지 일치 | 추정 승인율 (내 0.60) |

|---|---|---|---|

확인 항목
- 채점 AI가 나보다 너그러움: 틀린 4개 중 3개가 내가 반려한 것을 승인 → 추정 승인율이 10%p 높게 나옴
- 사실 확인 기준(근거 없음 3개)은 모두 맞힘. 취향이 들어가는 기준(너무 어려움, 장황함, 애매함)에서 선이 다름
- 기준 두 개를 지시문에 넣어도 일치율은 같음: 기준을 몰라서가 아니라 같은 기준을 다르게 적용함 → 내 판정을 예시로 보여주는 방법은 데이터가 30~50개 쌓인 뒤에 (평가하는 문제는 예시에서 빼고)
- 확신도: 틀린 것(0.76)이 맞힌 것(0.87)보다 낮음 → "애매한 것만 나에게" 기준값은 데이터가 쌓이면 정함
- 출처 찾기: 예시의 "…; 5. 다층 퍼셉트론"처럼 #이 없는 출처는 앞 출처의 "파일#제목"을 붙임
- 비어 있는 "- 반려 사유:" 줄은 콜론 뒤 공백도 없어서 정규식을 [ \t]*로 (\s는 다음 줄까지 넘어감)
