# 학습 관련 기술들

앞 노트에서 신경망 학습의 기본 틀을 만들었다. 미니배치로 손실을 구하고, 역전파로 기울기를 구해, 경사 하강법으로 가중치를 고친다. 이 노트는 그 틀을 더 빠르고, 더 안정적이고, 새 데이터에도 강하게 만드는 기술들이다.

```text
1. 매개변수 갱신      : 기울기로 가중치를 "어떻게" 고칠까?
2. 가중치의 초깃값    : 갱신을 "어디서" 시작할까?
3. 배치 정규화        : 학습 중에 값의 분포를 어떻게 안정시킬까?
4. 과대적합 억제      : 훈련 데이터만 외우지 않게 하려면?
5~6. 하이퍼파라미터   : 사람이 정하는 값은 어떻게 고를까?
```

## 1. 매개변수 갱신

손실을 가장 작게 만드는 매개변수를 찾는 문제를 최적화(optimization)라 하고, 매개변수를 갱신하는 방법을 옵티마이저(optimizer)라고 부른다. 지금까지 쓴 옵티마이저는 SGD였다.

### SGD

```text
W ← W − η ∂L/∂W
```

기울어진 방향으로 학습률 η만큼 이동하는 단순한 방법이다. 단순하고 구현하기 쉽지만, 문제에 따라 매우 비효율적이다.

### SGD의 단점

다음 함수의 최솟값을 찾는 문제를 보자.

```text
f(x, y) = x²/20 + y²
```

이 함수는 x 방향으로는 완만하고, y 방향으로는 가파른 그릇 모양이다. 이처럼 방향에 따라 기울기(가파른 정도)가 다른 함수를 비등방성(anisotropic) 함수라고 한다.

```text
 y
 ^
 |   ___________________________
 |  /  *                        \
 | |    \    /\    /\            |
 | |     \  /  \  /  \  /\       |
 | |      \/    \/    \/  \/-->  (0,0)
 |  \___________________________/
 +------------------------------------> x
 start (-7, 2)
```

그림: 가로로 긴 타원 모양 등고선. (−7, 2)에서 출발한 SGD 경로가 위아래로 크게 지그재그하며 중심 (0, 0)으로 다가간다

SGD는 지그재그로 움직이며 최솟값에 느리게 다가간다. 이 함수의 기울기는 대부분 위치에서 가파른 y 방향을 크게 가리키고, 정작 최솟값이 있는 x 방향으로는 조금만 가리킨다. 즉 SGD의 근본적인 문제는 기울어진 방향이 최솟값의 방향과 다르다는 점이다. 이 문제를 해결하는 방법으로 모멘텀, AdaGrad, Adam을 본다.

### 모멘텀

모멘텀(Momentum)은 운동량(관성)을 뜻한다. 공이 그릇 바닥을 굴러가듯, 지금까지 움직이던 방향과 속도를 기억해서 갱신에 반영한다.

```text
v ← αv − η ∂L/∂W
W ← W + v
```

v는 속도(velocity)다. 매 갱신마다 기울기라는 힘을 받아 속도가 바뀌고, 그 속도만큼 W가 이동한다. αv 항은 힘(기울기)을 받지 않아도 이전 속도를 α배만큼 유지해 관성으로 계속 움직이게 한다. α는 보통 0.9로 잡고, 1보다 작으므로 속도는 서서히 줄어든다(마찰 역할).

모멘텀이 지그재그를 줄이는 원리는 이렇다.

```text
x축: 기울기가 작고 부호가 계속 같다 → 같은 방향의 힘이 쌓여 점점 가속
y축: 기울기가 크고 0을 넘나들며 부호가 계속 바뀐다 → 위아래 힘이 서로 상쇄
```

그 결과 x축 방향으로는 빠르게 나아가고 y축 방향의 흔들림은 줄어, SGD보다 빨리 최솟값에 도달한다.

모멘텀이 "방향"을 고쳤다면, 다음은 "보폭(학습률)"을 고치는 방법이다.

### AdaGrad

학습률은 너무 작으면 학습이 너무 오래 걸리고, 너무 크면 발산한다. 그래서 학습을 진행하면서 학습률을 점차 줄이는 학습률 감소(learning rate decay) 기법을 쓴다. 처음에는 크게 움직이다가 점점 작게 움직이는 것이다.

가장 간단한 방법은 모든 매개변수의 학습률을 한꺼번에 낮추는 것이다. 이를 발전시켜, 매개변수마다 따로 학습률을 조정하는 방법이 AdaGrad(Adaptive Gradient)다.

```text
h ← h + ∂L/∂W ⊙ ∂L/∂W
W ← W − η (1/√h) ∂L/∂W

⊙: 원소별 곱
```

h는 지금까지의 기울기를 제곱해서 계속 더한 값이다. 갱신할 때 1/√h를 곱하므로, 지금까지 크게 움직인 매개변수일수록 학습률이 작아진다.

```text
 y
 ^
 |   ___________________________
 |  /  *                        \
 | |    \                        |
 | |     '-.                     |
 | |        '----.______------>  (0,0)
 |  \___________________________/
 +------------------------------------> x
```

그림: AdaGrad의 경로. y축 방향으로 처음에만 크게 움직이고, 금방 보폭이 줄어 지그재그 없이 중심으로 들어간다

y축 방향은 기울기가 커서 처음에 크게 움직이지만, 그만큼 h가 빨리 커져 y축 보폭이 금방 줄어든다. 그래서 지그재그가 사라진다.

AdaGrad의 문제는 h가 계속 커지기만 한다는 것이다. 학습을 오래 하면 1/√h가 0에 가까워져 갱신이 거의 멈춘다. 이를 개선한 방법이 RMSProp(Root Mean Square Propagation)이다.

```text
h ← ρh + (1 − ρ) ∂L/∂W ⊙ ∂L/∂W      (ρ: 보통 0.9)
```

과거 기울기를 모두 똑같이 더하지 않고, 먼 과거의 기울기는 점점 잊고 최근 기울기를 크게 반영한다. 이를 지수이동평균(EMA, Exponential Moving Average)이라 한다. h가 무한히 커지지 않으므로 학습이 멈추지 않는다.

### Adam

모멘텀은 방향을, AdaGrad·RMSProp은 매개변수별 보폭을 개선했다. 두 아이디어를 합친 것이 Adam(Adaptive Moment Estimation)이다.

```text
m ← β₁m + (1 − β₁) ∂L/∂W              ← 기울기의 평균 (모멘텀 역할, 1차 모멘트)
v ← β₂v + (1 − β₂) ∂L/∂W ⊙ ∂L/∂W      ← 기울기 제곱의 평균 (RMSProp 역할, 2차 모멘트)
m̂ = m / (1 − β₁ᵗ),  v̂ = v / (1 − β₂ᵗ)   ← 편향 보정 (t: 갱신 횟수)
W ← W − η m̂ / (√v̂ + ε)
```

m과 v는 0에서 시작하므로 학습 초기에는 실제보다 0 쪽으로 치우친다. 이를 바로잡는 것이 편향 보정(bias correction)이다. t가 커지면 1 − βᵗ가 1에 가까워져 보정 효과는 사라진다.

Adam의 하이퍼파라미터는 학습률 η, β₁, β₂ 세 개다. 논문의 기본값은 β₁ = 0.9, β₂ = 0.999이고, 대부분의 경우 이 값으로 좋은 결과를 얻는다. Adam의 경로도 그릇 바닥을 구르듯 움직이지만, 보폭이 적응적으로 조정되어 모멘텀보다 좌우 흔들림이 적다.

### 어느 갱신 방법을 쓸까?

모든 문제에서 항상 뛰어난 방법은 없다. 풀어야 할 문제와 하이퍼파라미터 설정에 따라 결과가 달라진다. 실무에서는 하이퍼파라미터에 덜 민감한 Adam을 기본으로 많이 쓰고, SGD(모멘텀 포함)도 여전히 많이 쓴다. 특히 트랜스포머 계열 모델은 Adam의 변형인 AdamW를 주로 쓴다. AdamW는 4절의 가중치 감소를 손실에 더하지 않고 갱신 단계에서 가중치에 직접 적용해, Adam의 적응적 학습률과 가중치 감소가 서로 간섭하지 않게 한 것이다.

매개변수를 "어떻게" 갱신할지 정했다. 다음은 갱신을 "어디서" 시작할지다.

## 2. 가중치의 초깃값

### 0으로 시작하면 안 되는 이유

과대적합을 줄이려면 가중치가 작은 편이 좋다(4절의 가중치 감소). 그래서 초깃값도 작은 값에서 시작하는 것이 정공법이다. 그렇다고 가중치를 모두 0으로 시작하면 학습이 되지 않는다.

가중치를 모두 0(또는 모두 같은 값)으로 두면, 같은 층의 뉴런들이 모두 같은 입력에 같은 가중치를 곱하므로 같은 값을 출력한다. 역전파 때도 모두 같은 기울기를 받아 똑같이 갱신된다. 결국 뉴런을 100개 둬도 1개와 다를 바가 없다. 이를 대칭성 문제(symmetry problem)라 하고, 이를 깨기 위해 초깃값은 무작위로 설정한다.

### 초깃값이 너무 크거나 작으면

```text
너무 큼: 가중합이 큰 양수·음수 → 시그모이드 출력이 0과 1로 쏠림
         → 그래프 양 끝의 평평한 구간이라 기울기 ≈ 0 → 기울기 소실

너무 작음: 가중합이 0 근처 → 시그모이드 출력이 모두 0.5 근처
         → 기울기 소실은 없지만 모든 뉴런이 같은 값을 내므로 표현력 제한
```

그림으로 보면 각 층의 활성화값(activation value, 활성화 함수의 출력) 분포가 다음과 같이 된다.

```text
(a)               (b)               (c)
#        #             #
#        #            ###           #######
#        #           #####         #########
+--------+       +----------+      +---------+
0        1       0   0.5    1      0         1
```

그림: 각 층의 활성화값 분포. (a) 초깃값이 너무 크면 0과 1 양 끝에 몰리고, (b) 너무 작으면 0.5에 몰리며, (c) 적당하면 고르게 퍼진다

따라서 목표는 각 층의 활성화값이 적당히 고르게 퍼지도록 초깃값의 크기를 정하는 것이다.

### Xavier 초깃값

가중치는 표준정규분포(평균 0, 표준편차 1인 종 모양 분포)에서 뽑은 값에 숫자 c를 곱해 만든다. c를 곱하면 표준편차(standard deviation, 값이 평균에서 퍼진 정도)도 c가 된다. 그럼 c를 얼마로 해야 할까?

뉴런의 가중합은 앞 층 노드 n개의 값에 가중치를 곱해 더한 것이다. 독립적인 값을 n개 더하면 분산(variance, 표준편차의 제곱)이 n배가 된다. 이를 상쇄하려면 가중치의 분산을 1/n로, 즉 표준편차를 1/√n로 줄이면 된다.

```text
Xavier 초깃값: 표준편차 = 1/√n      (n: 앞 층의 노드 수)
예) 앞 층 노드 100개 → 표준편차 0.1
```

이렇게 하면 층을 지나도 가중합이 너무 커지거나 작아지지 않는다. 참고로 원래 논문은 앞 층과 다음 층 노드 수를 모두 고려해 √(2/(n_in + n_out))을 쓰지만, 앞 층만 고려한 1/√n로 단순화해 쓰기도 한다.

### He 초깃값

Xavier는 시그모이드, tanh처럼 좌우 대칭이고 가운데가 직선에 가까운 함수를 가정한다. ReLU는 음수를 모두 0으로 만들어 값의 절반이 사라지므로, 그만큼 분산을 2배로 키워야 한다.

```text
He 초깃값: 표준편차 = √(2/n)
```

정리하면 활성화 함수가 시그모이드·tanh면 Xavier, ReLU면 He 초깃값을 쓴다.

초깃값은 학습을 "시작할 때"의 분포만 맞춰 준다. 그런데 학습하면서 가중치가 바뀌면 분포도 다시 흐트러진다. 그래서 학습 내내 분포를 직접 맞춰 주는 방법이 나왔다.

## 3. 배치 정규화

### 아이디어

배치 정규화(Batch Normalization)는 각 층에서 값을 미니배치 단위로 평균 0, 분산 1이 되도록 정규화하는 방법이다. 층 사이(활성화 함수 앞 또는 뒤)에 끼워 넣는다.

```text
Affine → [Batch Norm] → ReLU → Affine → [Batch Norm] → ReLU → …
```

정규화(normalization)는 값에서 평균을 빼고 표준편차로 나누는 것이다. 값들의 순서와 상대적 간격은 그대로 두고, 위치(평균)와 퍼짐(분산)만 맞춘다.

```text
μB  ← (1/m) Σᵢ₌₁ᵐ xᵢ                  ← 미니배치의 평균
σB² ← (1/m) Σᵢ₌₁ᵐ (xᵢ − μB)²          ← 미니배치의 분산
x̂ᵢ  ← (xᵢ − μB) / √(σB² + ε)          ← 정규화
yᵢ  ← γx̂ᵢ + β                         ← 확대·이동

m: 미니배치 크기, ε: 0으로 나누는 것을 막는 아주 작은 값
```

정규화만 하면 모든 층이 평균 0, 분산 1로 고정되어 오히려 표현력이 제한될 수 있다. 그래서 학습되는 매개변수 γ(확대)와 β(이동)로 다시 조정한다. γ = 1, β = 0에서 시작해, 학습하면서 그 층에 알맞은 분포를 스스로 찾는다.

### 왜 효과가 있나

학습 중에 앞 층의 가중치가 바뀌면 뒤 층으로 들어오는 값의 분포도 계속 흔들린다. 그러면 뒤 층은 계속 바뀌는 입력에 맞춰야 해서 학습이 느리고 불안정해진다. 배치 정규화는 각 층에 들어오는 분포를 항상 일정하게 맞춰, 초깃값으로 간접적으로 맞추려던 "활성화값이 고르게 퍼진 상태"를 학습 내내 직접 유지한다.

```text
1. 학습이 빠르다: 학습률을 크게 잡아도 안정적으로 수렴한다
2. 초깃값에 덜 민감하다
3. 과대적합을 어느 정도 억제한다: 미니배치마다 평균·분산이 조금씩 달라 약간의 잡음 효과가 생긴다
```

### 추론할 때는

추론할 때는 데이터가 한 개씩 들어올 수도 있어 미니배치 평균·분산을 구할 수 없다. 그래서 학습하는 동안 미니배치 평균·분산의 이동평균을 저장해 두었다가, 추론할 때는 그 값으로 정규화한다.

지금까지는 학습을 빠르고 안정적으로 만드는 기술이었다. 다음은 학습이 "너무 잘 돼서" 생기는 문제다.

## 4. 과대적합 억제

과대적합(overfitting)은 앞 노트에서 본 것처럼 훈련 데이터에만 지나치게 맞춰져 새 데이터를 잘 못 푸는 상태다. 주로 두 경우에 일어난다.

```text
1. 매개변수가 많고 표현력이 높은 모델
2. 훈련 데이터가 적을 때
```

이를 억제하는 대표적인 방법이 가중치 감소와 드롭아웃이다.

### 가중치가 크면 왜 과대적합이 일어나나

가중치는 입력이 조금 변했을 때 출력이 얼마나 크게 변하는지를 정한다. 훈련 데이터에는 잡음이 섞여 있어서, 거의 같은 입력인데 정답이 다른 경우가 있다. 이것까지 맞히려면 입력이 조금만 달라져도 출력이 확 바뀌는 급한 경계가 필요하고, 그런 경계는 가중치가 커야 만들 수 있다.

학습은 훈련 손실만 줄이려 하므로 잡음까지 맞추는 방향으로 가중치를 키운다. 그 결과 훈련 데이터는 잘 맞히지만 새 데이터에서는 성능이 떨어진다. 반대로 가중치를 작게 유지하면 출력이 완만하게 변하는 단순한 모델이 되어 잡음을 덜 외운다.

### 가중치 감소

가중치 감소(weight decay)는 손실 함수에 "가중치가 클수록 커지는 벌칙(penalty)"을 더해, 가중치가 커지지 않게 하는 방법이다. 가중치의 크기를 재는 방법으로 노름(norm)을 쓴다.

```text
L2 노름 = √(w₁² + w₂² + … + wₙ²)    ← 벡터의 길이
L1 노름 = |w₁| + |w₂| + … + |wₙ|
예) (3, 4)의 L2 노름 = √(9 + 16) = 5,  L1 노름 = 3 + 4 = 7
```

L2 정규화(L2 regularization)는 L2 노름의 제곱에 ½λ를 곱해 손실에 더한다.

```text
새 손실 = 원래 손실 + ½λ(w₁² + w₂² + … + wₙ²)
미분하면: 기울기 = 원래 기울기 + λW
```

제곱을 쓰면 루트가 사라지고, ½은 미분했을 때 λW로 깔끔하게 만들기 위한 상수다. λ는 벌칙의 세기로, 클수록 가중치를 강하게 누른다.

역전파에서 기울기에 λW가 더해지므로, 매 갱신마다 가중치가 자기 크기에 비례해 0 쪽으로 끌려간다. 큰 가중치는 크게, 작은 가중치는 조금 줄어서 전체가 골고루 작아진다(0이 되지는 않는다).

L1 정규화(L1 regularization)는 L1 노름에 λ를 곱해 더한다. 미분하면 가중치 크기와 상관없이 일정한 힘(λ)으로 줄이므로, 작은 가중치는 아예 0이 되어 필요 없는 입력을 끊어 내는 단순한 모델이 된다.

가중치 감소를 적용하면 훈련 정확도와 시험 정확도의 차이가 줄고, 훈련 정확도가 100%에 도달하지 않는다. 훈련 데이터를 덜 외운다는 뜻이다.

### 드롭아웃

모델이 복잡해지면 가중치 감소만으로는 부족하다. 이때 드롭아웃(dropout)을 쓴다.

드롭아웃은 훈련 때 은닉층 뉴런을 무작위로 꺼서(출력 0) 학습하는 방법이다. 데이터를 흘릴 때마다 끌 뉴런을 새로 무작위로 고른다.

```text
일반 신경망              드롭아웃 적용 (훈련 때)
( )--( )--( )            ( )--( )--( )
( )--( )--( )            ( )  (X)  ( )
( )--( )--( )            ( )--( )--(X)
                         X: 이번에 꺼진 뉴런
```

특정 뉴런이 꺼질 수 있으므로, 신경망은 어느 한 뉴런에 의존하지 않고 여러 뉴런에 정보를 나눠 담게 된다. 그래서 과대적합이 줄어든다.

시험 때는 모든 뉴런을 켠다. 대신 훈련 때는 일부만 켜져 다음 층이 더 작은 신호를 받았으므로, 크기를 맞추기 위해 각 뉴런의 출력에 (1 − 삭제 비율)을 곱한다. 참고로 PyTorch 같은 프레임워크는 반대로 훈련 때 남은 뉴런의 출력을 1/(1 − 삭제 비율)배 키워 두고 시험 때는 그대로 쓴다(inverted dropout). 결과는 같다.

### 조기 종료

가장 간단한 방법도 있다. 학습하면서 에포크마다 검증 데이터(5절)의 손실을 확인하고, 검증 손실이 더 이상 줄지 않고 오르기 시작하면 학습을 멈춘다. 이를 조기 종료(early stopping)라고 한다. 훈련 손실은 계속 줄어도 검증 손실이 오르기 시작했다면, 그때부터는 훈련 데이터를 외우기 시작한 것이기 때문이다.

```text
손실
 ^
 | \
 |  \          ___---  검증 손실
 |   \____----
 |    \
 |     '--.___
 |            '----___  훈련 손실
 +--------+---------------> 에포크
          ^ 여기서 멈춤
```

### 드롭아웃과 앙상블

앙상블 학습(ensemble learning)은 여러 모델을 따로 학습시킨 뒤, 시험 때 출력을 평균 내는 방법이다. 모델마다 하는 실수가 달라 서로 상쇄되므로 성능이 좋아진다.

드롭아웃은 매번 다른 뉴런 조합, 즉 매번 다른 작은 신경망을 학습한다. 그리고 시험 때 모든 뉴런을 켜고 출력 크기를 맞추는 것은 그 작은 신경망들을 평균 내는 것과 비슷하다. 그래서 드롭아웃은 모델 하나로 앙상블 효과를 낸다.

지금까지 학습률, λ, 삭제 비율처럼 사람이 정해야 하는 값이 많이 나왔다. 이 값들은 어떻게 고를까?

## 5. 검증 데이터

하이퍼파라미터를 여러 값으로 바꿔 가며 성능을 비교해야 한다. 이때 시험 데이터를 쓰면 안 된다. 시험 데이터로 하이퍼파라미터를 고르면, 하이퍼파라미터가 시험 데이터에 맞춰진다(과대적합된다). 그러면 시험 데이터 점수는 더 이상 "처음 보는 데이터에 대한 실력"이 아니게 된다.

그래서 하이퍼파라미터 전용으로 쓸 데이터를 따로 둔다. 이를 검증 데이터(validation data)라고 한다.

```text
훈련 데이터: 매개변수(가중치) 학습
검증 데이터: 하이퍼파라미터 성능 평가
시험 데이터: 마지막에 한 번, 범용 성능 평가
```

가장 간단한 방법은 훈련 데이터의 20% 정도를 검증 데이터로 먼저 떼어 두는 것이다.

## 6. 하이퍼파라미터 최적화

### 범위를 좁혀 가기

핵심은 최적값이 있을 범위를 조금씩 좁혀 가는 것이다.

```text
0단계: 하이퍼파라미터의 범위를 대략 정한다
1단계: 그 범위에서 값을 무작위로 뽑는다
2단계: 뽑은 값으로 학습하고 검증 데이터로 정확도를 본다 (에포크는 작게)
3단계: 1~2단계를 여러 번(예: 100회) 반복하고, 결과가 좋은 쪽으로 범위를 좁힌다
→ 범위가 충분히 좁아지면 그 안에서 값을 하나 고른다
```

범위는 0.001 ~ 1,000처럼 10의 거듭제곱 단위로 넓게 잡는다. 이를 로그 스케일(log scale)로 지정한다고 한다. 학습률 0.001과 0.01의 차이는 0.1과 0.11의 차이보다 훨씬 중요하기 때문이다. 하이퍼파라미터 탐색은 오래 걸리므로, 학습이 가망 없어 보이는 값은 일찍 포기하고 에포크도 작게 잡는다.

### 탐색 방법

```text
그리드 서치(grid search):     후보값을 격자로 정하고 모든 조합을 시험
랜덤 서치(random search):     범위 안에서 무작위로 뽑아 시험
베이즈 최적화(Bayesian optimization): 이전 결과로 "좋을 것 같은 곳"을 추정해 다음 시험 위치를 고름
```

그리드 서치는 단순하지만, 하이퍼파라미터가 늘어나면 조합 수가 폭발적으로 늘어난다. 랜덤 서치는 같은 시도 횟수로 중요한 하이퍼파라미터를 더 다양한 값으로 시험할 수 있어 그리드 서치보다 효율적인 경우가 많다. 베이즈 최적화는 적은 시도로 좋은 값을 찾을 수 있다.

```text
[grid search]                [random search]

 o   o   o                   o       o
                               o
 o   o   o                 o      o
                                    o
 o   o   o                   o   o     o
-------------> important    -------------> important
```

그림: 9번씩 시도할 때, 하이퍼파라미터 중 가로축 하나만 중요하다면 그리드 서치는 그 축에서 3개 값만 시험하지만 랜덤 서치는 9개 값을 시험한다
