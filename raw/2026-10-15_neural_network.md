# 신경망

## 1. 퍼셉트론에서 신경망으로

퍼셉트론은 층을 쌓으면 XOR 같은 복잡한 함수도 표현할 수 있었다. 하지만 큰 단점이 하나 남아 있다. 가중치와 임계값을 여전히 사람이 직접 정해야 한다는 것이다. 게이트 몇 개라면 손으로 정할 수 있지만, 가중치가 수백만 개라면 불가능하다.

신경망(neural network)은 이 단점을 해결한다. 가중치 매개변수(parameter)의 적절한 값을 데이터로부터 자동으로 학습하기 때문이다. 이 노트에서는 먼저 신경망이 어떻게 예측하는지(순전파)를 보고, 마지막에 어떻게 학습하는지를 큰 그림으로 본다.

### 신경망의 구조

```text
 [input]      [hidden]      [output]

               ( h1 )
   ( x1 )                    ( y1 )
               ( h2 )
   ( x2 )                    ( y2 )
               ( h3 )

 x1, x2 각각이 h1, h2, h3 모두와 연결되고,
 h1, h2, h3 각각이 y1, y2 모두와 연결된다
```

그림: 입력층(input layer, 노드 2개) → 은닉층(hidden layer, 노드 3개) → 출력층(output layer, 노드 2개). 앞 층의 모든 노드가 다음 층의 모든 노드와 연결된다

입력층은 데이터를 받는 층, 출력층은 결과를 내는 층이다. 가운데 층은 은닉층이라고 부르는데, 입력층과 출력층의 값은 우리가 직접 넣거나 확인하지만, 은닉층의 값은 겉으로 드러나지 않고 신경망 안에서만 쓰이기 때문이다.

구조만 보면 다층 퍼셉트론과 거의 같다. 차이는 신호를 다음 층으로 넘기는 방식, 즉 활성화 함수에 있다.

## 2. 활성화 함수

### 퍼셉트론 식 다시 보기

퍼셉트론은 편향 b를 써서 다음과 같이 쓸 수 있었다.

```text
y = 0   (b + w₁x₁ + w₂x₂ ≤ 0)
y = 1   (b + w₁x₁ + w₂x₂ > 0)
```

b는 임계값에 마이너스를 붙인 값(b = −θ)이었다. 그래서 임계값이 높을수록 b는 작아지고, 뉴런은 활성화되기 어려워진다.

이 식은 "가중합을 구한다"와 "0을 넘었는지 판단한다"라는 두 가지 일을 한꺼번에 하고 있다. 판단하는 부분을 함수 h로 따로 떼어 내면 다음과 같다.

```text
y = h(b + w₁x₁ + w₂x₂)

h(x) = 0   (x ≤ 0)
h(x) = 1   (x > 0)
```

이 h처럼 입력 신호의 총합을 받아서 출력 신호로 바꿔 주는 함수를 활성화 함수(activation function)라고 한다. 이름 그대로, 총합이 뉴런을 활성화시키는지를 정하는 함수다.

### 뉴런 안의 두 단계

이 과정을 두 단계로 나눠 쓰면 뉴런 안에서 일어나는 일이 더 잘 보인다.

```text
a = b + w₁x₁ + w₂x₂     ← 1단계: 가중합
y = h(a)                ← 2단계: 활성화 함수
```

```text
   1  ---(b)----\
   x1 ---(w1)----[ a ]---h()---> y
   x2 ---(w2)---/
```

그림: 뉴런 하나 안에서 가중합 a를 구하고, 활성화 함수 h를 거쳐 y를 출력한다

즉 뉴런 하나는 "가중합 a를 구하고, h에 통과시켜 y를 내보낸다". 그렇다면 h로 무엇을 쓰느냐에 따라 신경망의 성질이 달라진다. 퍼셉트론이 쓰던 계단 함수부터 보자.

## 3. 계단 함수

계단 함수(step function)는 입력이 0을 넘으면 1, 넘지 않으면 0을 출력하는 함수다. 앞에서 본 h가 바로 계단 함수다.

```text
h(x) = 0   (x ≤ 0)
h(x) = 1   (x > 0)
```

```text
 y
 ^
1+           +--------------
 |           |
 |           |
0+-----------+
 +-----------+-------------> x
             0
```

그림: x가 0 이하면 0, 0을 넘으면 1로 계단처럼 한 번에 올라간다

출력이 0 아니면 1이라 단순하지만, 0을 기준으로 값이 뚝 끊긴다. 이 "뚝 끊김"을 부드럽게 바꾼 것이 시그모이드 함수다.

## 4. 시그모이드 함수

시그모이드 함수(sigmoid function)는 입력을 0과 1 사이의 부드러운 값으로 바꿔 주는 함수다. 계단 함수를 부드럽게 만든 버전이라고 보면 된다.

```text
h(x) = 1 / (1 + exp(−x))
```

```text
   y
   ^
 1 +                    ..------
   |                 .'
   |               .'
0.5+ - - - - - - -*
   |            .'
   |          .'
 0 +------..'
   +--------------+-------------> x
                  0
```

그림: 왼쪽에서 0에 가깝다가 S자 곡선으로 부드럽게 올라가 오른쪽에서 1에 가까워진다. x = 0일 때 0.5다

## 5. 계단 함수와 시그모이드 함수 비교

### 차이점: 매끈함

가장 큰 차이는 매끈함이다. 계단 함수는 0을 경계로 출력이 갑자기 바뀌고 0과 1 둘 중 하나만 돌려준다. 시그모이드 함수는 부드러운 곡선이라 입력에 따라 출력이 연속적으로 변하는 실수를 돌려준다. 그래서 퍼셉트론에서는 뉴런 사이에 0 또는 1이 흐르고, 신경망에서는 연속적인 실수가 흐른다.

매끈함이 중요한 이유는 학습 때문이다. 시그모이드는 가중치를 조금 바꾸면 출력도 조금 바뀐다. 그래서 "가중치를 어느 쪽으로 고쳐야 결과가 좋아지는지" 알 수 있다. 계단 함수는 가중치를 조금 바꿔도 출력이 그대로이거나, 어느 순간 갑자기 바뀐다. 고칠 방향을 알려 주는 단서가 없는 것이다. 이 이야기는 다음 노트(신경망 학습)에서 자세히 본다.

### 공통점: 모양과 범위

둘은 큰 흐름이 같다. 가중합이 작으면 출력이 0(또는 0에 가까운 값)이고, 가중합이 크면 출력이 1(또는 1에 가까운 값)이다. 그리고 입력이 아무리 크거나 작아도 출력은 항상 0에서 1 사이다.

## 6. 비선형 함수

계단 함수와 시그모이드 함수는 또 하나의 공통점이 있다. 둘 다 비선형 함수(nonlinear function)라는 것이다. 신경망의 활성화 함수는 반드시 비선형이어야 한다.

선형 함수를 쓰면 층을 깊게 하는 의미가 없어지기 때문이다. 활성화 함수가 h(x) = cx처럼 선형이라고 하자. 3층을 쌓으면 y = h(h(h(x))) = c × c × c × x = c³x가 된다. 이건 a = c³인 y = ax 하나와 똑같다. 즉 선형 함수는 아무리 겹쳐도 선형 함수 하나로 합쳐져서, 층을 쌓아도 은닉층 없는 네트워크와 같아진다.

퍼셉트론으로 XOR를 만들 수 있었던 것도 사실은 계단 함수라는 비선형 활성화 함수를 썼기 때문이다.

그럼 비선형이기만 하면 무엇이든 괜찮을까? 실제로는 학습이 잘 되는지가 중요하고, 그래서 요즘은 시그모이드보다 ReLU를 더 많이 쓴다.

## 7. ReLU 함수

ReLU(Rectified Linear Unit) 함수는 입력이 0을 넘으면 입력을 그대로 출력하고, 0 이하이면 0을 출력하는 함수다.

```text
h(x) = x   (x > 0)
h(x) = 0   (x ≤ 0)
```

```text
 y
 ^
 |                 /
 |               /
 |             /
 |           /
0+----------+
 +----------+--------------> x
            0
```

그림: x가 0 이하면 0으로 평평하다가, 0을 넘으면 오른쪽 위로 곧게 올라가는 직선

모양은 직선 두 개를 이어 붙인 것이지만, 0에서 꺾이기 때문에 전체로 보면 비선형 함수다.

### 시그모이드 대신 ReLU를 쓰는 이유

학습할 때는 출력층에서 입력층 방향으로 "기울기"를 전달하는데(다음 노트에서 볼 역전파), 이때 각 층의 활성화 함수 기울기가 계속 곱해진다.

시그모이드는 기울기가 가장 클 때(x = 0)도 0.25밖에 안 되고, 입력이 아주 크거나 작으면 거의 0이다. 1보다 작은 값을 층마다 곱하면 앞쪽 층으로 갈수록 기울기가 0에 가까워져 학습이 거의 되지 않는다. 이것을 기울기 소실(vanishing gradient)이라고 한다.

ReLU는 입력이 0보다 크면 기울기가 항상 1이다. 1은 여러 번 곱해도 줄어들지 않으므로 기울기 소실이 크게 줄어든다. 계산도 "0보다 큰지"만 보면 되어서 빠르다.

다만 입력이 0 이하이면 기울기가 0이라, 어떤 뉴런이 계속 음수만 받으면 그 뉴런은 더 이상 학습되지 않는다. 이것을 "뉴런이 죽는다(dying ReLU)"고 한다. 그래서 음수 쪽에도 작은 기울기(예: 0.01x)를 주는 Leaky ReLU 같은 변형을 쓰기도 한다.

지금까지 본 활성화 함수는 주로 은닉층에 쓴다. 그렇다면 마지막 출력층은 어떻게 할까?

## 8. 출력층 설계

출력층에서는 풀고 싶은 문제에 맞는 함수를 따로 고른다. 신경망이 푸는 문제는 크게 분류와 회귀 두 가지다.

### 분류와 회귀

분류(classification)는 데이터가 어느 클래스에 속하는지 고르는 문제다. 예를 들어 사진 속 동물이 고양이인지 개인지 고른다. 회귀(regression)는 입력에서 연속적인 수치를 예측하는 문제다. 예를 들어 사진 속 사람의 몸무게를 예측한다.

```text
회귀          → 항등 함수
2클래스 분류   → 시그모이드 함수
다중 클래스 분류 → 소프트맥스 함수
```

### 항등 함수

회귀에 쓰는 항등 함수(identity function)는 입력을 그대로 출력한다. 예측하려는 값이 범위 제한 없는 수치이므로, 출력을 가공하지 않고 그대로 내보낸다.

### 소프트맥스 함수

분류에 쓰는 소프트맥스 함수(softmax function)는 다음과 같다.

```text
yₖ = exp(aₖ) / Σᵢ₌₁ⁿ exp(aᵢ)

n: 출력층의 뉴런 수, aₖ: k번째 뉴런의 입력
```

분자는 k번째 입력의 지수 함수이고, 분모는 모든 입력의 지수 함수를 더한 값이다. 그래서 출력은 각각 0에서 1 사이이고, 다 더하면 1이 된다. 이 성질 덕분에 소프트맥스의 출력을 "각 클래스일 확률"로 해석할 수 있다.

```text
a = ( 0.3,  2.9,  4.0 )
y ≈ ( 0.02, 0.25, 0.74 )   (총합 1)
→ 세 번째 클래스일 확률이 74%
```

출력층의 뉴런 수는 분류하고 싶은 클래스 수로 정한다. 숫자 0~9를 분류한다면 뉴런 10개다.

### 소프트맥스 구현 시 주의점

exp는 값이 아주 빠르게 커져서, 입력이 1000만 되어도 컴퓨터가 표현할 수 있는 범위를 넘어 오버플로(overflow)가 난다. 그래서 실제로는 모든 입력에서 입력의 최댓값을 빼고 계산한다. 분자와 분모에 같은 값을 곱한 것과 같아서 결과는 변하지 않고, 값은 안전한 범위에 들어온다.

```text
yₖ = exp(aₖ − max(a)) / Σᵢ exp(aᵢ − max(a))
```

### 추론할 때는 생략하기도 한다

소프트맥스는 exp가 커지는 순서를 바꾸지 않으므로, 입력이 가장 큰 뉴런이 출력도 가장 크다. 그래서 학습을 마친 뒤 "어떤 클래스인지"만 알면 되는 추론 단계에서는 소프트맥스를 생략하기도 한다. 학습할 때는 손실을 계산해야 하므로 생략하지 않는다.

출력층까지 정했으니 신경망의 구조는 완성됐다. 이제 신경망에 넣을 데이터 쪽을 보자.

## 9. 전처리와 배치

### 전처리와 정규화

전처리(preprocessing)는 데이터를 신경망에 넣기 전에 특정 변환을 하는 작업이다. 대표적인 전처리가 정규화(normalization)로, 데이터를 특정 범위로 바꾸는 처리다. 예를 들어 0~255인 픽셀 값을 255로 나눠 0~1 범위로 맞춘다. 값의 범위가 들쭉날쭉하면 학습이 불안정해지기 때문이다.

### 배치

배치(batch)는 입력 데이터를 여러 개 하나로 묶은 것이다. 이미지 한 장(784픽셀)씩 넣는 대신 100장을 묶어서 넣으면 형상은 다음과 같이 바뀐다.

```text
1장씩:   입력 (784,)      → 출력 (10,)
100장씩: 입력 (100, 784)  → 출력 (100, 10)
```

배치로 묶어 한 번에 계산하면 처리 시간이 크게 줄어든다. 수치 계산 라이브러리와 GPU는 작은 계산 여러 번보다 큰 배열 계산 한 번을 훨씬 효율적으로 처리하기 때문이다.

지금까지는 가중치가 이미 정해져 있다고 보고 예측하는 과정만 봤다. 마지막으로, 처음에 말한 신경망의 장점인 "가중치를 데이터로부터 학습한다"는 게 어떤 과정인지 큰 그림을 보자.

## 10. 학습 과정 미리 보기

지금까지는 가중치가 이미 정해져 있다고 보고 예측하는 과정만 봤다. 이렇게 입력층에서 출력층 방향으로 가중합·편향·활성화 함수를 차례로 적용해 예측값을 계산하는 과정을 순전파(forward propagation)라고 한다.

처음에 말한 신경망의 장점인 "가중치를 데이터로부터 학습한다"는 이 순전파 뒤에 이어지는 과정이다. 큰 그림은 다음 순서의 반복이다.

```text
1. 순전파로 예측
      ↓
2. 손실로 틀린 정도 측정
      ↓
3. 역전파로 기울기 계산
      ↓
4. 경사하강법으로 가중치 수정
      ↓
   1로 돌아가 반복
```

손실을 어떻게 재고, 기울기를 어떻게 구해, 가중치를 어떻게 고치는지는 다음 노트(신경망 학습)에서 차례로 본다.
