# 합성곱 신경망(CNN)

## 1. 전체 구조

합성곱 신경망(CNN, Convolutional Neural Network)은 이미지처럼 형상을 가진 데이터를, 그 형상(공간 정보)을 유지한 채 처리하며 특징을 뽑는 신경망이다. 주로 이미지 인식에 쓰인다.

지금까지 본 신경망은 인접한 층의 모든 뉴런이 서로 연결되어 있었다. 이를 완전연결(fully connected)이라 하고, 완전연결 계층을 Affine 계층이라고 한다.

```text
[완전연결 신경망]
x → Affine → ReLU → Affine → ReLU → Affine → ReLU → Affine → ReLU → Affine → Softmax

[CNN]
x → Conv → ReLU → Pooling → Conv → ReLU → Pooling → Conv → ReLU → Affine → ReLU → Affine → Softmax
```

그림: 완전연결 신경망은 Affine-ReLU를 반복하고, CNN은 Conv-ReLU-(Pooling)을 반복한 뒤 마지막에 Affine-ReLU와 Affine-Softmax를 쓴다

CNN에는 합성곱 계층(Conv)과 풀링 계층(Pooling)이 새로 추가된다. 앞쪽은 Conv-ReLU-(Pooling) 흐름으로 이어지고(풀링은 생략되기도 한다), 출력에 가까운 층은 지금까지의 Affine-ReLU 구성을, 마지막 출력층은 Affine-Softmax 조합을 그대로 쓴다.

그럼 왜 Affine 계층 대신 합성곱 계층이 필요할까?

## 2. 합성곱 계층

### 완전연결 계층의 문제점

완전연결 계층의 문제는 데이터의 형상이 무시된다는 것이다. 이미지는 보통 채널(channel, 색상)·높이·너비로 이루어진 3차원 데이터다. 그런데 완전연결 계층에 넣으려면 이를 1차원으로 평탄화(flatten)해야 한다.

```text
(1, 28, 28) 이미지 → 평탄화 → 784개 숫자의 한 줄
```

이미지에서는 가까운 픽셀끼리 값이 비슷하고, 위아래로 이어진 픽셀이 선을 이루는 등 공간적 관계가 중요하다. 평탄화하면 이런 위치 관계가 사라지고, 완전연결 계층은 모든 픽셀을 서로 상관없는 입력으로 취급한다.

반면 합성곱 계층은 형상을 유지한다. 3차원 데이터를 받아 3차원 데이터로 내보낸다. 그래서 형상에 담긴 정보를 살릴 수 있다. 합성곱 계층의 입출력 데이터를 특징 맵(feature map)이라 하고, 입력을 입력 특징 맵, 출력을 출력 특징 맵이라고 한다.

### 합성곱 연산

합성곱 연산은 이미지 처리에서 말하는 필터(filter) 연산이다. 필터를 커널(kernel)이라고도 한다.

```text
   input (4, 4)          filter (3, 3)        output (2, 2)

  1  2  3  0
  0  1  2  3             2  0  1               15  16
  3  0  1  2      (*)    0  1  2      =>        6  15
  2  3  0  1             1  0  2
```

필터를 입력 위에 겹쳐 놓고, 겹친 자리의 원소끼리 곱해서 모두 더한다. 이 값이 출력의 한 칸이 된다. 필터가 겹쳐 있는 입력 영역을 윈도우(window)라 하며, 크기는 필터와 같다. 윈도우를 일정 간격으로 옮겨 가며 같은 계산을 반복한다.

```text
왼쪽 위 윈도우:
 1  2  3       2  0  1
 0  1  2   x   0  1  2   → 1·2 + 2·0 + 3·1 + 0·0 + 1·1 + 2·2 + 3·1 + 0·0 + 1·2 = 15
 3  0  1       1  0  2
```

완전연결 신경망에 가중치와 편향이 있었듯, CNN에서는 필터의 값이 가중치에 해당한다. 편향은 필터 하나당 값 하나이고, 필터를 적용한 결과의 모든 원소에 같은 값을 더한다.

참고로 수학에서 말하는 합성곱은 필터를 뒤집어서 곱하지만, 딥러닝에서는 뒤집지 않고 곱한다(정확히는 교차 상관, cross-correlation). 필터 값을 어차피 학습으로 정하므로 결과에는 차이가 없어서 그냥 합성곱이라고 부른다.

### 패딩

위 예에서 4×4 입력이 2×2로 줄었다. 합성곱을 거칠 때마다 크기가 줄면, 층을 깊게 쌓다 보면 어느 순간 출력이 1×1이 되어 더 이상 합성곱을 할 수 없다.

그래서 합성곱 전에 입력 주변을 특정 값(보통 0)으로 채운다. 이를 패딩(padding)이라 한다.

```text
패딩 폭 1:
 0  0  0  0  0  0
 0  1  2  3  0  0
 0  0  1  2  3  0
 0  3  0  1  2  0
 0  2  3  0  1  0
 0  0  0  0  0  0
→ (6, 6)에 3×3 필터를 적용하면 출력은 (4, 4)로 입력 크기가 유지된다
```

패딩은 주로 출력 크기를 조정하기 위해 쓴다. 가장자리 픽셀도 필터의 가운데에 올 수 있어, 가장자리 정보가 덜 손실된다는 효과도 있다.

### 스트라이드

필터를 적용하는 위치의 간격을 스트라이드(stride)라고 한다. 스트라이드가 2면 윈도우가 두 칸씩 이동한다.

스트라이드를 키우면 출력이 작아지고, 패딩을 키우면 출력이 커진다. 이를 식으로 쓰면 다음과 같다.

```text
OH = (H + 2P − FH) / S + 1
OW = (W + 2P − FW) / S + 1

H, W: 입력 크기, FH, FW: 필터 크기, OH, OW: 출력 크기, P: 패딩, S: 스트라이드

예) 입력 (4, 4), 필터 (3, 3), 패딩 1, 스트라이드 1
    OH = (4 + 2 − 3) / 1 + 1 = 4
예) 입력 (7, 7), 필터 (3, 3), 패딩 0, 스트라이드 2
    OH = (7 + 0 − 3) / 2 + 1 = 3
```

나눗셈이 딱 떨어지지 않으면 오류를 내거나, 구현에 따라 내림해서 처리한다.

### 3차원 데이터의 합성곱

이미지는 채널이 있는 3차원 데이터다. 이때는 채널마다 따로 합성곱을 하고, 그 결과를 모두 더해 출력 한 장을 만든다.

```text
입력 (C, H, W)  (*)  필터 (C, FH, FW)  →  출력 (1, OH, OW)
```

그래서 입력의 채널 수와 필터의 채널 수는 반드시 같아야 한다. 필터 하나가 모든 채널을 한꺼번에 보고 한 장의 특징 맵을 만드는 것이다.

### 블록으로 생각하기

필터 하나는 출력 한 장(채널 1개)을 만든다. 출력도 여러 채널로 만들려면 필터를 여러 개 쓴다.

```text
입력           필터 FN개              출력             편향
(C, H, W) (*) (FN, C, FH, FW)  →  (FN, OH, OW)  +  (FN, 1, 1)  →  (FN, OH, OW)
```

필터를 FN개 쓰면 출력 특징 맵도 FN장이 되고, 이를 쌓은 블록 (FN, OH, OW)를 다음 층으로 넘긴다. 그래서 필터 가중치는 (출력 채널 수, 입력 채널 수, 높이, 너비) 순서의 4차원 데이터가 된다. 편향은 출력 채널 하나에 값 하나씩이라 (FN, 1, 1)이다.

### 배치 처리

신경망에서 입력을 묶어 한꺼번에 계산했듯(배치 처리, batch processing), 합성곱도 데이터 차원을 하나 늘려 4차원으로 다룬다.

```text
(N, C, H, W)  (*)  (FN, C, FH, FW)  →  (N, FN, OH, OW)

N: 한 번에 처리하는 데이터 수
```

4차원 데이터가 한 번 흐를 때마다 데이터 N개의 합성곱이 한꺼번에 이루어진다.

합성곱 계층을 지나도 특징 맵의 크기는 꽤 크다. 크기를 줄이는 계층이 다음에 볼 풀링이다.

## 3. 풀링 계층

풀링(pooling)은 세로·가로 방향의 공간을 줄이는 연산이다.

```text
최대 풀링 (2×2, 스트라이드 2)

  1  2 | 1  0
  0  1 | 2  3             2  3
 ------+------     =>
  3  0 | 1  2             4  2
  2  4 | 0  1
```

최대 풀링(max pooling)은 영역에서 최댓값을, 평균 풀링(average pooling)은 영역의 평균을 취한다. 이미지 인식에서는 주로 최대 풀링을 쓴다. 보통 윈도우 크기와 스트라이드를 같게 잡는다(예: 2×2, 스트라이드 2).

풀링 계층의 특징은 세 가지다.

```text
1. 학습할 매개변수가 없다: 최댓값이나 평균을 고르는 정해진 처리이기 때문이다
2. 채널 수가 변하지 않는다: 채널마다 독립적으로 계산한다
3. 입력의 작은 변화에 강하다: 입력이 한두 칸 밀려도 영역의 최댓값은 잘 변하지 않는다
```

구조를 다 봤으니, 이제 합성곱 계층이 실제로 무엇을 배우는지 보자.

## 4. 필터와 특징 맵

### 필터는 기준, 특징 맵은 결과

필터(가중치)는 "무엇을 찾을지"에 대한 기준이다. 어떤 패턴을 찾을지를 학습해서 담고 있고, 모든 입력 이미지에 똑같이 적용된다. 특징 맵(합성곱 출력)은 그 기준으로 입력에서 찾아낸 결과다. 입력 이미지의 어디에, 그 패턴이 얼마나 강하게 있는지를 담으므로 이미지마다 달라진다.

예를 들어 세로선을 찾는 필터를 쓰면, 특징 맵은 세로선이 있는 자리에서 값이 크고 없는 자리에서 값이 작다.

### 합성곱 계층의 두 가지 성질

이 구조에서 CNN의 핵심 성질 두 가지가 나온다.

```text
지역 연결(local connectivity): 출력 한 칸은 입력의 작은 영역(윈도우)만 본다
가중치 공유(weight sharing):  같은 필터를 이미지의 모든 위치에서 재사용한다
```

가중치 공유 덕분에 매개변수 수가 크게 줄어든다. 28×28 이미지를 완전연결 계층으로 뉴런 100개에 연결하면 가중치가 784 × 100 = 78,400개다. 반면 3×3 필터 100개는 9 × 100 = 900개뿐이고, 이 수는 입력 이미지가 커져도 늘지 않는다. 또 고양이가 이미지 왼쪽에 있든 오른쪽에 있든 같은 필터로 찾을 수 있다.

### 층이 깊어질수록

```text
앞쪽 층: 가장자리(에지), 색 변화 같은 단순한 패턴
중간 층: 앞 층의 결과를 조합해 질감, 모양
뒤쪽 층: 더 조합해 눈, 바퀴, 얼굴 같은 사물의 부분
```

층이 깊어질수록 특징 맵은 사물의 의미 있는 정보를 더 추상적으로 표현한다.

### 필터의 학습

필터 값은 사람이 정하지 않고, 다른 가중치처럼 학습으로 정해진다. 필터가 받는 목표는 "손실을 줄여라" 하나뿐이다. 하지만 정답을 잘 맞히려면 사물을 구분하는 데 유용한 패턴을 찾아야 하므로, 결과적으로 필터가 사물의 중요한 특징을 찾도록 학습된다.

## 5. 대표적인 CNN

CNN은 LeNet에서 시작해 층이 점점 깊어지는 방향으로 발전했다. 각 모델이 "어떤 문제를 해결하려고" 나왔는지에 주목하면 흐름이 보인다.

```text
LeNet(1998) → AlexNet(2012) → VGG(2014) / GoogLeNet(2014) → ResNet(2015)
 CNN의 기본형    딥러닝 붐        깊게 / 넓고 효율적으로        아주 깊게
```

### LeNet

LeNet은 손글씨 숫자 인식을 위해 만든 CNN이다. 1989년에 처음 제안되었고, 1998년에 발표된 LeNet-5가 잘 알려져 있다. 합성곱을 쓰는 신경망의 아이디어 자체는 1980년의 네오코그니트론(Neocognitron)까지 거슬러 올라가지만, 역전파로 학습하는 현재 형태의 CNN은 LeNet이 기본형이다.

완전연결 계층만 쓰면 이미지를 한 줄로 펼쳐야 해서 공간 정보가 사라진다. LeNet은 합성곱으로 공간 구조를 유지하며 특징을 뽑고, 필터를 공유해 매개변수 수를 줄이려고 나왔다.

합성곱 계층과 서브샘플링(subsampling) 계층을 반복하고, 마지막에 완전연결 계층으로 결과를 낸다. 서브샘플링은 공간 크기를 줄이는 처리로, LeNet은 영역의 평균으로 줄였다. 지금의 CNN과 비교하면 두 가지가 다르다.

| 구분 | LeNet | 지금의 CNN |
| --- | --- | --- |
| 활성화 함수 | 시그모이드 | ReLU |
| 크기 줄이기 | 서브샘플링(평균) | 최대 풀링 |

### AlexNet

AlexNet(2012)은 이미지 인식 대회 ILSVRC(ImageNet Large Scale Visual Recognition Challenge) 2012에서 기존 방법을 큰 차이로 이기며 딥러닝 붐을 일으켰다.

배경은 이렇다. ImageNet 같은 대량의 데이터와 GPU(Graphics Processing Unit)의 발전으로 큰 신경망을 학습할 수 있는 환경이 갖춰졌다. 하지만 층을 깊게 하면 시그모이드는 기울기 소실이 생기고, 모델이 커지면 과대적합이 생긴다. AlexNet은 이 문제들을 해결하며 LeNet보다 크고 깊게 만들었다.

```text
구조: 합성곱 5층 + 완전연결 3층
- 활성화 함수로 ReLU를 사용 (기울기 소실 완화)
- 드롭아웃으로 과대적합 억제
- GPU로 대규모 학습
- LRN(Local Response Normalization)으로 국소적 정규화
```

LRN(국소적 응답 정규화)은 한 뉴런의 출력을, 같은 위치에 있는 이웃 채널 값들의 제곱합으로 나누는 정규화다. 다 같이 강하게 반응한 값들은 함께 낮추고, 혼자 튀는 반응은 상대적으로 더 눈에 띄게 만든다. 하지만 같은 위치에 실제로 여러 특징이 함께 있는 경우에도 모두 낮춰 버릴 수 있고, 성능 향상도 크지 않아 지금은 배치 정규화로 대체되었다.

### VGG

VGG(Visual Geometry Group, 2014)는 "층을 깊게 하면 성능이 얼마나 좋아지는가"를 확인하려 했다. 그래서 구조를 최대한 단순하게 했다.

```text
- 3×3 작은 필터만 사용해 합성곱 층을 깊게 쌓음 (16층, 19층 버전)
- 합성곱 2~4층 뒤에 풀링으로 크기를 절반씩 줄이는 과정을 반복
```

큰 필터 대신 작은 필터를 깊게 쌓은 이유는 다음 노트(딥러닝)에서 자세히 본다. 구조가 단순해 응용하기 쉬워 많이 쓰였지만, 매개변수가 많아(대부분 마지막 완전연결 계층에 있다) 무겁다.

### GoogLeNet

GoogLeNet(2014)은 ILSVRC 2014 우승 모델로 22층 구조다. 두 가지 문제를 해결하려 했다.

```text
문제 1: 이미지마다 특징의 크기가 달라, 어떤 크기의 필터가 좋은지 정하기 어렵다
→ 크기가 다른 필터(1×1, 3×3, 5×5)와 풀링을 나란히 적용하고 결과를 합친다 (인셉션 구조)

문제 2: 깊고 넓게 하면 계산량이 폭발적으로 늘어난다
→ 1×1 합성곱으로 채널 수를 먼저 줄인다
```

```text
            +--> 1x1 conv ----------------+
            |                              |
 input -----+--> 1x1 conv --> 3x3 conv ----+--> concat --> output
            |                              |
            +--> 1x1 conv --> 5x5 conv ----+
            |                              |
            +--> 3x3 pool --> 1x1 conv ----+
```

그림: 인셉션 구조. 여러 크기의 필터를 나란히 적용하고 채널 방향으로 합친다. 큰 필터 앞의 1×1 합성곱이 채널 수를 줄인다

1×1 합성곱은 공간 크기는 그대로 두고 채널 방향으로만 섞는 연산이라, 채널 수를 줄이는 데 쓸 수 있다. 덕분에 GoogLeNet은 VGG보다 깊으면서도 매개변수는 훨씬 적다.

### ResNet

ResNet(Residual Network, 2015)은 ILSVRC 2015 우승 모델로, 152층까지 쌓았다.

층을 일정 이상 깊게 쌓으면 오히려 성능이 떨어지는 문제가 있었다. 과대적합이라면 훈련 데이터 성능은 좋아야 하는데, 훈련 데이터 성능부터 나빠졌다. 이를 성능 저하(degradation) 문제라고 한다. 이론상 깊은 신경망은 추가한 층이 입력을 그대로 내보내기만(항등 함수) 해도 얕은 신경망만큼은 성능이 나와야 한다. 그런데 여러 비선형 층으로 "그대로 내보내기"를 학습하는 것조차 어려웠고, 깊어질수록 기울기도 앞쪽 층까지 잘 전달되지 않았다. ResNet은 이를 스킵 연결(skip connection)로 해결했다.

```text
     x ----------------------+
     |                       |
     v                       |
 [weight layer]              |
     |                       |
   ReLU                      |
     |                       |
 [weight layer]              |
     |                       |
     v                       v
    F(x) ------------------> (+) --> ReLU --> F(x) + x
```

그림: 스킵 연결. 입력 x가 층 두 개를 건너뛰어 출력 F(x)에 더해진다

스킵 연결은 입력을 몇 개 층을 건너뛰어 출력에 더한다(출력 = F(x) + x). 두 가지 효과가 있다.

```text
1. 학습이 쉬워진다: 층은 출력 전체가 아니라 입력과의 차이(잔차, residual) F(x)만 학습하면 된다
   그대로 내보내는 게 최선이라면 F(x) = 0만 배우면 되므로, 층을 더 쌓아도 최소한 나빠지지는 않는다
2. 기울기가 잘 전달된다: 덧셈 노드는 역전파 때 기울기를 그대로 흘려보내므로,
   건너뛴 경로로 기울기가 줄어들지 않고 앞쪽 층까지 전달된다
```

이 "덧셈 경로로 기울기를 그대로 전달한다"는 아이디어는 뒤에서 LSTM, 트랜스포머에서도 다시 나온다.
