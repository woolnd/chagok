# RNN을 사용한 문장 생성

## 1. 언어 모델을 사용한 문장 생성

앞 장에서 만든 언어 모델(language model)은 지금까지 주어진 단어들로부터 다음에 출현할 단어의 확률분포를 출력한다. 이 성질을 이용하면 언어 모델로 새로운 문장을 생성할 수 있다.

그림: 첫 단어 "I"를 입력 → 언어 모델이 다음 단어 후보들의 확률분포 출력 → 그중 하나를 골라 다음 입력으로 넣기를 반복

### 다음 단어를 고르는 방법

첫 번째 단어가 주어졌을 때 다음 단어는 어떻게 생성할까? 방법은 크게 결정적 선택과 확률적 선택 두 가지다.

먼저 확률이 가장 높은 단어를 선택하는 방법을 떠올릴 수 있다. 이것이 결정적(deterministic) 선택이다. 결정적이란 결과가 하나로 정해지는 것, 즉 결과를 예측할 수 있는 것을 말한다. 결정적 선택은 항상 확률이 가장 높은 단어를 고르므로 결과가 매번 같다.

다른 하나는 확률적(probabilistic) 선택이다. 각 후보 단어의 확률에 맞게 선택하는 것으로, 이렇게 확률분포에 따라 하나를 뽑는 것을 샘플링(sampling)이라고 한다. 샘플링은 각 단어의 확률을 뽑힐 가능성으로 삼아 무작위로 뽑는다. 그래서 확률이 높은 단어는 자주 선택되지만, 확률이 낮은 단어도 가끔 선택된다. 확률적인 알고리즘에서는 결과가 확률에 따라 정해지므로, 선택되는 단어는 실행할 때마다 달라진다.

그림: 다음 단어 후보 say 0.5, hello 0.3, goodbye 0.1, … → 결정적 선택은 항상 say, 샘플링은 say가 가장 자주 나오지만 hello나 goodbye가 나올 때도 있다

### 새로 생성된 문장

단어를 고르고, 고른 단어를 다시 다음 입력으로 넣는 작업을 원하는 만큼(또는 <eos> 같은 종결 기호가 나올 때까지) 반복하면 문장이 만들어진다.

여기서 주목할 점은 이렇게 생성한 문장은 훈련 데이터에는 존재하지 않는, 말 그대로 새로 생성된 문장이라는 것이다. 언어 모델은 훈련 데이터를 암기한 것이 아니라 훈련 데이터에서 사용된 단어의 정렬 패턴을 학습한 것이기 때문이다. 만약 언어 모델이 말뭉치(corpus)로부터 단어의 출현 패턴을 올바르게 학습할 수 있다면, 그 모델이 새로 생성하는 문장은 우리 인간에게도 자연스럽고 의미가 통하는 문장일 것으로 기대할 수 있다.

## 2. seq2seq

언어 모델은 문장을 처음부터 생성했다. 이번에는 주어진 문장을 다른 문장으로 바꾸는 문제를 본다.

세상에는 시계열 데이터(time series data)가 넘쳐난다. 언어 데이터, 음성 데이터, 동영상 데이터는 모두 시계열 데이터다. 그리고 시계열 데이터를 또 다른 시계열 데이터로 변환하는 문제도 숱하게 생각할 수 있다. 기계 번역(machine translation)이나 음성 인식(speech recognition)이 대표적이다. 이처럼 시계열 데이터를 다른 시계열 데이터로 변환하는 모델로, 2개의 RNN(Recurrent Neural Network)을 이용하는 seq2seq(sequence to sequence)라는 방법이 있다.

### Encoder-Decoder 모델

seq2seq를 Encoder-Decoder 모델이라고도 한다. 말 그대로 Encoder는 입력 데이터를 인코딩(부호화)하고, Decoder는 인코딩된 데이터를 디코딩(복호화)한다. 인코딩(encoding)이란 정보를 어떤 규칙에 따라 변환하는 것이고, 디코딩(decoding)은 인코딩된 정보를 원래의 정보로 되돌리는 것이다.

그림: "나는 고양이로소이다" → Encoder → h → Decoder → "I am a cat"

### Encoder

Encoder는 RNN을 이용해 시계열 데이터를 h라는 은닉 상태 벡터(hidden state vector)로 변환한다. 여기서는 LSTM(Long Short-Term Memory)을 사용하지만, 단순한 RNN이나 GRU(Gated Recurrent Unit) 등도 물론 이용할 수 있다. 여기서는 우리말 문장을 단어 단위로 쪼개 입력한다고 가정한다.

그림: 나 / 는 / 고양이 / 로소 / 이다 → 각각 Embedding → LSTM을 차례로 통과 → 마지막 LSTM의 은닉 상태 h 출력

Encoder가 출력하는 벡터 h는 LSTM 계층의 마지막 은닉 상태다. 이 마지막 은닉 상태 h에 입력 문장을 번역하는 데 필요한 정보가 인코딩된다.

여기서 중요한 점은 LSTM의 은닉 상태 h가 고정 길이 벡터라는 사실이다. 입력 문장이 3단어든 30단어든 h의 크기는 같다. 그래서 인코딩한다는 것은 결국 임의 길이의 문장을 고정 길이 벡터로 변환하는 작업이 된다.

### Decoder

Decoder는 앞 장의 언어 모델 신경망(Embedding → LSTM → Affine → Softmax)과 완전히 같은 구성이다. 단 한 가지만 다른데, 바로 LSTM 계층이 벡터 h를 입력받는다는 점이다. 앞 장의 언어 모델에서는 LSTM 계층이 아무것도 받지 않았다(은닉 상태가 영벡터에서 시작). 이처럼 단 하나의 사소한 차이가 평범한 언어 모델을 번역도 해낼 수 있는 Decoder로 탈바꿈시킨다. 즉 Decoder는 "h라는 조건이 주어진 언어 모델"이다.

그림: Decoder 입력은 <eos> → I → am → a → cat, 출력은 I → am → a → cat → <eos>. 첫 LSTM이 Encoder의 h를 받는다

여기서 <eos>(end of sentence)라는 구분 기호(특수 문자)를 이용한다. 이 기호는 말 그대로 구분자이며, Decoder에 문장 생성의 시작을 알리는 신호로 이용된다. 또 Decoder가 <eos>를 출력하면 생성을 멈추므로 종료 신호이기도 하다. 즉 <eos>는 Decoder에 시작/종료를 알리는 구분자다.

### Encoder와 Decoder를 잇는 가교

seq2seq는 LSTM 두 개(Encoder의 LSTM과 Decoder의 LSTM)로 구성된다. 이때 LSTM 계층의 은닉 상태가 Encoder와 Decoder를 이어주는 가교가 된다. 순전파 때는 Encoder에서 인코딩된 정보가 LSTM 계층의 은닉 상태를 통해 Decoder에 전해진다. 그리고 역전파 때는 이 가교를 통해 기울기가 Decoder로부터 Encoder로 전해진다. 그래서 두 LSTM을 하나의 신경망처럼 한 번에 학습할 수 있다.

## 3. 가변 길이 시계열 데이터

seq2seq를 실제로 학습시키려면 해결할 문제가 하나 있다. 번역할 문장은 길이가 제각각인데, 미니배치(mini-batch)로 한꺼번에 계산하려면 데이터의 길이가 같아야 한다.

### 패딩

가변 길이 시계열 데이터를 미니배치로 학습하기 위한 가장 단순한 방법은 패딩(padding)을 사용하는 것이다. 패딩이란 원래의 데이터에 의미 없는 데이터를 채워 모든 데이터의 길이를 균일하게 맞추는 기법이다. 이처럼 패딩을 적용해 데이터 크기를 통일시키면 가변 길이 시계열 데이터도 처리할 수 있다.

### 패딩 전용 처리

그러나 패딩을 쓰면 본래 존재하지 않던 패딩용 문자까지 seq2seq가 처리하게 된다. 그래서 정확성이 중요하다면 seq2seq에 패딩 전용 처리를 추가해야 한다.

- Decoder: 입력된 데이터가 패딩이라면 그 시각의 손실은 결과에 반영하지 않는다. 패딩 위치를 표시하는 마스크(mask) 기능을 추가해 해결할 수 있다.
- Encoder: 입력된 데이터가 패딩이라면 LSTM 계층이 은닉 상태를 갱신하지 않고 이전 시각의 값을 그대로 넘기게 한다. 그러면 LSTM 계층은 마치 처음부터 패딩이 존재하지 않았던 것처럼 인코딩할 수 있다.

## 4. seq2seq 구현

앞에서 본 구조를 계층 단위로 나누면 Encoder 클래스, Decoder 클래스, 그리고 둘을 묶은 seq2seq 클래스가 된다.

### Encoder 클래스

Encoder 클래스는 문자열(단어 ID 시퀀스)을 받아 벡터 h로 변환한다. Embedding 계층과 LSTM 계층으로 구성된다. Embedding 계층에서는 단어 ID를 단어 벡터로 변환하고, 이 벡터가 LSTM 계층으로 입력된다.

LSTM 계층은 오른쪽(시간 방향)으로는 은닉 상태와 기억 셀(memory cell)을 출력하고, 위쪽으로는 은닉 상태만 출력한다. Encoder에는 위쪽에 다른 계층이 없으므로 위쪽 출력은 버린다. 마지막 단어를 처리한 후의 은닉 상태 h만 꺼내 출력하고, 이 h가 Decoder로 전달된다.

그림: Time Embedding → Time LSTM → 마지막 시각의 은닉 상태만 꺼내 h로 출력

### Decoder 클래스

Decoder 클래스는 Encoder 클래스가 출력한 h를 받아 목적으로 하는 다른 문자열을 출력한다. Time Embedding → Time LSTM → Time Affine 순으로 쌓는다.

이때 Time Embedding이 처리하는 것은 h가 아니라 Decoder에 매 시각 입력되는 단어(ID)다. 생성 시에는 직전 시각에 출력한 단어가 다음 입력이 되고(학습 시에는 정답 단어), 이 단어 ID는 정수이므로 Embedding으로 벡터화한 뒤 LSTM에 넣는다. 반면 h는 Encoder에서 이미 벡터가 된 상태이므로 Embedding을 거치지 않는다.

그림: h는 옆에서 Decoder LSTM의 초기 은닉 상태로 들어가고, 단어(<eos>, I, am …)는 아래에서 Time Embedding → Time LSTM으로 들어간다

Encoder가 넘긴 h는 Decoder LSTM 계층의 초기 은닉 상태로 설정된다. 기억 셀은 넘기지 않으므로 Decoder의 기억 셀은 0에서 시작한다. 즉 Encoder와 Decoder 사이를 오가는 정보는 h 하나뿐이다.

### 학습 시와 생성 시의 차이

RNN으로 문장을 생성할 때는 학습 시와 생성 시의 데이터 부여 방법이 다르다.

- 학습 시: 정답을 알고 있기 때문에 시계열 방향의 데이터를 한꺼번에 줄 수 있다. 각 시각의 입력으로 모델의 예측이 아닌 정답 단어를 넣는다. 이를 교사 강요(teacher forcing)라고 한다.
- 생성(추론) 시: 정답을 모르므로 최초 시작을 알리는 구분 문자(<eos>) 하나만 준다. 그리고 그 출력으로부터 단어를 하나 고르고, 고른 단어를 다음 입력으로 사용하는 과정을 반복한다. 이때 단어는 1절의 결정적 선택이나 확률적 선택(샘플링)으로 고른다.

### seq2seq 클래스

seq2seq 클래스는 Encoder 클래스와 Decoder 클래스를 연결하고, 맨 위에 Time Softmax with Loss 계층을 두어 손실을 계산한다.

그림: 입력 문장 → [Encoder: Time Embedding → Time LSTM] → h → [Decoder: Time Embedding → Time LSTM → Time Affine] → Time Softmax with Loss ← 정답 문장

순전파는 Encoder가 입력 문장을 h로 바꾸고, Decoder가 h와 정답 문장(교사 강요)을 받아 각 시각의 점수를 출력하면, Time Softmax with Loss가 정답과 비교해 손실을 구하는 순서로 진행된다. 역전파는 그 반대로 Time Softmax with Loss → Decoder → h → Encoder 순서로 기울기가 흐른다. 2절에서 본 "은닉 상태가 가교가 된다"는 것이 바로 이 흐름이다.

## 5. seq2seq 학습과 평가

seq2seq의 학습은 기본적인 신경망의 학습과 같다.

1. 학습 데이터에서 미니배치를 선택한다.
2. 미니배치로부터 기울기를 계산한다.
3. 기울기를 사용하여 매개변수를 갱신한다.

평가는 에포크(epoch)마다 테스트 데이터의 문제를 풀게 해서 정답률로 측정한다.

## 6. seq2seq 개선

기본 seq2seq는 학습이 느리고 정답률도 아쉬운 경우가 있다. 여기서는 학습 속도와 정확도를 높이는 두 가지 개선을 본다.

### 입력 데이터 반전

첫 번째 개선은 입력 데이터의 순서를 반전(reverse)시키는 것이다. 입력문 반전은 입력 문장 전체의 단어 순서를 거꾸로 뒤집는 기법이며, 출력은 그대로 둔다. 이 트릭을 사용하면 많은 경우 학습 진행이 빨라져서, 결과적으로 최종 정확도가 좋아진다고 한다. 데이터를 반전시키는 효과는 어떤 문제를 다루느냐에 따라 다르지만, 대부분의 경우 더 좋은 결과로 이어진다.

그림: 입력 "나 는 고양이 로소 이다" → 반전 → "이다 로소 고양이 는 나". 출력 "I am a cat"은 그대로

### 반전하면 왜 좋아지나?

직관적으로는 기울기 전파가 원활해지기 때문이다. 예를 들어 "나는 고양이로소이다"를 "I am a cat"으로 번역하는 문제에서, "나"라는 단어가 "I"로 변환되는 과정을 생각해 보자.

반전하지 않으면 "나"에서 "I"까지 가려면 "는", "고양이", "로소", "이다"까지 총 네 단어 분량의 LSTM 계층을 거쳐야 한다. 따라서 역전파 시 "I"로부터 전해지는 기울기가 "나"에 도달하기까지 그 먼 거리만큼 영향을 더 받게 된다.

입력문을 반전시켜 "이다 로소 고양이 는 나" 순으로 바꾸면, "나"는 Encoder의 마지막 입력이 되어 Decoder의 첫 출력 "I"와 바로 옆이 된다. 그래서 기울기가 직접 전해진다. 즉 입력의 첫 단어가 출력의 첫 단어와 가까워져 기울기가 잘 전달되고 학습이 빨라진다.

### 평균 거리는 같은데 왜 성능이 좋아지나?

입력 데이터를 반전해도 단어 사이의 평균적인 거리는 그대로다. 앞부분은 가까워지는 대신 뒤쪽 단어들은 오히려 멀어지기 때문이다. 그런데도 성능이 좋아지는 이유는 Decoder가 앞에서부터 차례로 생성하기 때문이다. 앞에서 생성한 단어가 다음 단어의 입력이 되므로, 앞부분을 잘 맞히면 뒤도 잘 이어진다. 그래서 앞부분을 잘 맞히는 효과가 커서 전체 성능이 좋아지는 경우가 많다.

### 엿보기(Peeky)

두 번째 개선은 엿보기(Peeky)다. 기본 seq2seq에서는 Encoder의 출력 h를 Decoder의 첫 번째 LSTM 계층만 받았다. 하지만 h에는 Decoder에 필요한 정보가 모두 담겨 있으므로, 이를 더 활용하는 것이 좋다. 엿보기는 이 h를 Decoder의 다른 계층에도 전해주는 것이다.

그림: Decoder의 모든 시각의 LSTM 계층과 Affine 계층에 Encoder의 출력 h가 화살표로 들어간다

모든 시각의 Affine 계층과 LSTM 계층에 Encoder의 출력 h를 전해준다. 이때 각 계층은 원래 입력과 h를 연결(concatenate)해 입력받는다. 기존에는 하나의 LSTM만이 소유하던 중요 정보 h를 여러 계층이 공유하게 되는 것이다.

이는 집단 지성에 비유할 수 있다. 중요한 정보를 한 사람이 독점하는 게 아니라 많은 사람과 공유한다면 더 올바른 결정을 내릴 가능성이 커질 것이다.

다만 Peeky를 이용하면 각 계층의 입력이 h만큼 커지므로, 신경망의 가중치 매개변수가 커져서 계산량도 늘어난다.

## 7. seq2seq를 이용하는 애플리케이션

seq2seq처럼 한 시계열 데이터를 다른 시계열 데이터로 변환하는 프레임워크는 다양한 문제에 적용할 수 있다.

- 기계 번역: 한 언어의 문장을 다른 언어의 문장으로 변환
- 자동 요약: 긴 문장을 짧게 요약된 문장으로 변환
- 질의응답: 질문을 응답으로 변환
- 메일 자동 응답: 받은 메일의 문장을 답변 문장으로 변환

이처럼 seq2seq는 2개가 짝을 이루는 시계열 데이터를 다루는 문제에 이용할 수 있다. 자연어 외에도 음성이나 영상 등에도 이용할 수 있다.

### 챗봇

챗봇(chatbot)은 사람과 컴퓨터가 텍스트로 대화를 나누는 프로그램이다. 대화라는 것은 상대의 말과 자신의 말로 구성되기 때문에, 상대의 말을 자신의 말로 변환하는 문제로 볼 수 있다.

### 알고리즘 학습

소스 코드도 문자로 쓰인 시계열 데이터다. 따라서 소스 코드를 그대로 seq2seq에 입력할 수 있고, 그 실행 결과(원하는 답)와 대조하여 학습시킬 수 있다.

### 이미지 캡셔닝

이미지 캡셔닝(image captioning)은 이미지를 문장으로 변환한다. 지금까지와 다른 점은 Encoder가 LSTM에서 합성곱 신경망(CNN, Convolutional Neural Network)으로 바뀐 것이 전부다. Decoder는 지금까지와 똑같은 신경망을 이용한다.

그림: 이미지 → CNN(Encoder) → 특징 맵 → 평탄화 → Affine → LSTM(Decoder) → "a dog is running"

CNN의 특징 맵(feature map)은 3차원(채널·높이·너비)이므로, 1차원으로 평탄화(flatten)한 후 완전연결인 Affine 계층에서 변환한다. 그런 다음 변환된 데이터를 Decoder에 전달하면 지금까지와 같은 문장 생성을 수행할 수 있다.
