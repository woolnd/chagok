# 어텐션

## 1. seq2seq의 문제점

seq2seq에서는 Encoder가 시계열 데이터를 인코딩하고, 인코딩된 정보를 Decoder로 전달한다. 이때 Encoder의 출력은 고정 길이의 벡터였다. 바로 이 고정 길이라는 데에 큰 문제가 있다.

고정 길이 벡터라 함은 입력 문장의 길이에 관계없이 항상 같은 길이의 벡터로 변환한다는 뜻이다. 3단어짜리 문장이든 100단어짜리 문장이든 똑같은 크기의 벡터 하나에 밀어 넣어야 한다. 그래서 문장이 길어질수록 필요한 정보가 벡터에 다 담기지 못하게 된다. 큰 옷장의 옷을 작은 가방 하나에 억지로 담는 것과 같다.

이 문제를 해결하는 방법이 어텐션(attention)이다. 어텐션은 여러 정보 중 지금 필요한 정보에 집중해 가져오는 방법이다. 아래에서 Encoder와 Decoder를 차례로 개선하며 어텐션을 만들어 본다.

## 2. Encoder 개선

### 모든 시각의 은닉 상태 이용하기

지금까지는 LSTM 계층의 마지막 은닉 상태만 Decoder에 전달했다. 그러나 Encoder 출력의 길이는 입력 문장의 길이에 따라 바꿔 주는 게 좋다. 그래서 시각별 LSTM 계층의 은닉 상태 벡터를 모두 이용한다.

그림: 나 / 는 / 고양이 / 로소 / 이다 → Encoder LSTM → 5개 시각의 은닉 상태를 모두 모아 hs로 출력

각 시각(각 단어)의 은닉 상태 벡터를 모두 이용하면 입력된 단어와 같은 수의 벡터를 얻을 수 있다. 5단어를 입력하면 벡터 5개, 10단어를 입력하면 벡터 10개다. 이것으로 Encoder는 하나의 고정 길이 벡터라는 제약으로부터 해방된다.

### 은닉 상태에 담긴 정보

여기서 주목할 것은 시각별 LSTM 계층의 은닉 상태에 어떤 정보가 담겨 있느냐다. 각 시각의 은닉 상태에는 직전에 입력된 단어에 대한 정보가 많이 포함되어 있다.

예를 들어 "고양이"를 입력했을 때의 LSTM 계층의 출력은 직전에 입력한 "고양이"라는 단어의 영향을 가장 크게 받는다. 따라서 이 은닉 상태 벡터는 "고양이"의 성분이 많이 들어간 벡터라고 생각할 수 있다. 그렇게 보면 Encoder가 출력하는 hs 행렬은 각 단어에 해당하는 벡터들의 집합이다.

```text
hs = ( hs₁   ← "나" 성분이 많은 벡터
       hs₂   ← "는" 성분이 많은 벡터
       hs₃   ← "고양이" 성분이 많은 벡터
       hs₄   ← "로소" 성분이 많은 벡터
       hs₅ ) ← "이다" 성분이 많은 벡터

형상: (T, H)   T: 입력 단어 수, H: 은닉 상태 벡터 크기
```

다만 Encoder는 왼쪽에서 오른쪽으로 읽으므로, 각 은닉 상태에는 그 단어와 그 앞 단어들의 정보만 담긴다. 이 한계는 뒤의 양방향 RNN에서 해결한다.

단지 Encoder의 은닉 상태를 모든 시각만큼 꺼내는 이 작은 개선 덕분에, Encoder는 입력 문장의 길이에 비례한 정보를 인코딩할 수 있게 되었다.

## 3. Decoder 개선 ①: 선택을 가중합으로

### 사람은 어떻게 번역하나?

Encoder는 각 단어에 대응하는 LSTM 계층의 은닉 상태 벡터를 hs로 모아 출력하고, 이 hs가 Decoder에 전달되어 시계열 변환이 이뤄진다. 그런데 앞 장의 Decoder는 Encoder LSTM 계층의 마지막 은닉 상태만 이용했다. hs에서 마지막 줄만 빼내어 Decoder에 전달한 것이다. 이제 hs 전부를 활용할 수 있도록 Decoder를 개선한다.

사람이 문장을 번역할 때 머릿속에서 어떤 일이 일어날까? "나는 고양이로소이다"를 영어로 번역한다면 대부분 "나 = I", "고양이 = cat"이라는 지식을 이용할 것이다. 즉 우리는 번역하는 순간마다 원문의 어떤 단어에 주목하고, 그 단어를 변환한다.

그렇다면 입력과 출력의 여러 단어 중 어떤 단어끼리 서로 관련되어 있는가라는 대응 관계를 seq2seq에게 학습시킬 수 없을까?

### 어텐션의 목표

목표는 도착어(번역 결과 언어) 단어와 대응 관계에 있는 출발어(원문 언어) 단어의 정보를 골라내고, 그 정보를 이용하여 번역을 수행하는 것이다. 즉 필요한 정보에만 주목하여 그 정보로부터 시계열 변환을 수행하는 것이 목표다. 이 구조를 어텐션이라 부른다.

이를 위해 Decoder에 어떤 계산을 수행하는 계층을 새로 추가한다. 이 계층이 받는 입력은 두 가지로, 하나는 Encoder로부터 받는 hs, 다른 하나는 Decoder의 시각별 LSTM 계층의 은닉 상태다. 그리고 여기에서 필요한 정보만 골라 위쪽의 Affine 계층으로 출력한다. Encoder의 마지막 은닉 상태 벡터는 지금까지와 똑같이 Decoder의 첫 번째 LSTM 계층에 전달한다.

그림: Decoder의 각 시각 LSTM 출력 h와 Encoder의 hs가 새 계층("어떤 계산")으로 들어가고, 그 출력이 Affine 계층으로 올라간다

### 얼라인먼트 추출

이 신경망으로 하고 싶은 일은 단어들의 얼라인먼트(alignment) 추출이다. 얼라인먼트란 출발어 문장과 도착어 문장에서 서로 대응하는 단어(또는 문구) 쌍을 말한다. 즉 각 시각에서 Decoder가 다음에 출력할 단어와 대응 관계인 입력 단어의 벡터를 hs에서 골라내겠다는 뜻이다. 예를 들어 Decoder가 "I"를 출력할 때는 hs에서 "나"에 대응하는 벡터를 선택하면 된다.

### 선택은 미분할 수 없다

이러한 선택 작업을 어떤 계산으로 해내려는 것인데, 여기서 문제는 선택하는 작업은 미분할 수 없다는 점이다. 5개 중 하나를 고르는 것은 "고른다 / 안 고른다"가 뚝 끊어지는 작업이라, 계단 함수처럼 기울기를 구할 수 없다. 기울기가 없으면 오차역전파법으로 학습할 수 없다.

그러면 선택한다는 작업을 미분 가능한 연산으로 대체할 수 없을까? 아이디어는 아주 단순하다. 하나를 선택하는 게 아니라 모든 것을 선택하는 것이다. 대신 각 단어의 중요도를 나타내는 가중치를 별도로 계산한다.

### 가중치 a와 맥락 벡터 c

가중치(기호 a)는 확률분포처럼 각 원소가 0.0~1.0 사이의 스칼라이며, 모든 원소의 총합은 1이 된다. 각 단어의 중요도를 나타내는 가중치 a와 각 단어의 벡터 hs로부터 가중합(weighted sum)을 구하면 우리가 원하는 벡터를 얻는다. 그 결과를 맥락 벡터(context vector)라 부르며 기호 c로 표기한다.

```text
c = a₁hs₁ + a₂hs₂ + … + a_T hs_T = Σᵢ aᵢ hsᵢ

a: 각 입력 단어의 가중치 (형상 (T,), 총합 1)
hs: 각 입력 단어의 벡터 (형상 (T, H))
c: 맥락 벡터 (형상 (H,))
```

예를 들어 다음과 같이 "나"에 대응하는 가중치가 0.8이면, 맥락 벡터 c에는 "나" 벡터의 성분이 많이 포함된다.

```text
         나     는     고양이   로소    이다
a   =  0.80   0.05   0.10    0.03   0.02

c = 0.80 × hs(나) + 0.05 × hs(는) + 0.10 × hs(고양이) + …
  ≈ 거의 hs(나)
```

즉 "나" 벡터를 선택하는 작업을 이 가중합으로 대체하고 있다고 할 수 있다. 가중치가 한 단어에 1, 나머지에 0이면 정확히 선택한 것과 같아지고, 그 사이 값이면 "부드럽게 선택"한 셈이다. 가중합은 곱셈과 덧셈뿐이므로 미분할 수 있다.

## 4. Decoder 개선 ②: 가중치 a 구하기

### 내적으로 유사도 구하기

그렇다면 가중치 a는 어떻게 구해야 할까? 사람이 정하는 것이 아니라 데이터로부터 자동으로 학습할 수 있도록 준비해야 한다.

아이디어는 Decoder LSTM 계층의 은닉 상태 벡터 h가 hs의 각 단어 벡터와 얼마나 비슷한가를 수치로 나타내는 것이다. 이때 벡터의 내적(inner product)을 이용한다. 내적의 직관적인 의미는 두 벡터가 얼마나 같은 방향을 향하고 있는가이다. 같은 방향이면 크고, 수직이면 0, 반대 방향이면 음수가 된다.

```text
sᵢ = h · hsᵢ        (i = 1, …, T)

h: Decoder LSTM의 현재 은닉 상태 (형상 (H,))
s: 각 입력 단어와의 유사도 (형상 (T,))
```

번역에서 hs는 원문 각 단어의 정보이고, h는 Decoder가 지금까지 번역한 흐름을 담은 상태다. 둘을 내적하면 "지금 번역 상태에서 원문의 각 단어가 얼마나 관련 있는지"를 알 수 있다.

### 소프트맥스로 정규화

내적한 결과 s는 정규화하기 전의 값이며 점수(score)라고도 한다. 점수는 음수일 수도 있고 합이 1도 아니므로, s를 정규화하기 위해 보통 소프트맥스 함수를 사용한다. 소프트맥스 함수를 이용하면 그 출력인 a의 각 원소는 0.0~1.0 사이의 값이 되고 모든 원소의 총합은 1이 된다.

```text
a = softmax(s)

예)  s = ( 4.0,  0.6,  1.8,  −0.3,  −0.9 )
     a ≈ ( 0.86, 0.03, 0.09,  0.01,  0.01 )   (총합 1)
```

이렇게 얻은 a가 3절에서 본 가중치다. 정리하면 a는 다음 단어를 번역하기 위해 원문의 어느 단어를 얼마나 참고해야 하는지를 나타낸다.

### 어디에 주목할지는 어떻게 학습되나?

여기서 Attention 계층 자체에는 학습하는 매개변수가 없다. 내적과 소프트맥스, 가중합뿐이다. 그런데도 어디에 주목할지가 학습되는 이유는, Encoder와 Decoder의 LSTM 가중치가 학습되면서 h와 hs가 "대응하는 단어끼리 내적이 커지도록" 바뀌기 때문이다. 손실을 줄이려면 올바른 원문 단어를 참고해야 하므로, 학습이 진행될수록 대응하는 단어에 큰 가중치가 실리게 된다.

이때 Decoder의 h가 어떤 입력 단어와 비슷해질지는 위치가 아니라 의미로 학습된다. 언어마다 어순이 달라 출력의 첫 단어가 입력의 첫 단어와 대응한다는 보장이 없다. 예를 들어 한국어 "나는 고양이를 좋아한다"와 영어 "I like cats"는 동사의 위치가 다르다. 어텐션은 매 시각 필요한 의미의 입력 단어에 주목하도록 학습해, 어순이 다른 문장 간의 대응(정렬)을 처리한다.

## 5. Decoder 개선 ③: Attention 계층

### 두 단계 계산

지금까지 본 두 계산을 합친 것이 Attention 계층이다. Attention 계층은 두 단계로 계산한다.

1. Attention Weight 계층: Encoder가 출력한 각 단어의 벡터 hs와 Decoder LSTM의 은닉 상태 h를 내적해 유사도 점수 s를 구하고, 소프트맥스로 정규화해 가중치 a를 얻는다. 각 입력 단어를 얼마나 반영할지 정하는 단계다.
2. Weight Sum 계층: 이 가중치 a의 비율대로 hs의 단어 벡터들을 실제로 가중합해, 지금 필요한 입력 정보를 담은 맥락 벡터 c를 만든다.

```text
[Attention Weight]   s = h · hs     →   a = softmax(s)
[Weight Sum]         c = Σᵢ aᵢ hsᵢ
```

정리하면 어텐션은 찾는 정보(지금의 h)와 각 정보의 벡터(hs)를 내적해 유사도를 구하고, 소프트맥스로 가중치를 만든 뒤, 그 가중치로 정보들을 가중합해 필요한 정보를 담은 벡터를 만드는 방법이다.

### 어텐션을 갖춘 Decoder의 계층 구성

Attention 계층은 Decoder의 LSTM 계층과 Affine 계층 사이에 들어간다. 각 시각마다 Attention 계층이 맥락 벡터 c를 만들고, 이 c와 LSTM의 은닉 상태 h를 연결(concatenate)해 Affine 계층에 입력한다.

그림: Time Embedding → Time LSTM → Time Attention(hs도 입력) → [c와 h 연결] → Time Affine → Time Softmax with Loss

여러 시각의 Attention 계층을 한꺼번에 처리하도록 묶은 것이 Time Attention 계층이다. 각 시각의 Attention 계층은 같은 hs를 받고, 그 시각의 h만 다르다.

```text
시각 1: h(<eos>) 로 hs 조회 → c₁ ≈ hs(나)     → "I" 예측
시각 2: h(I)     로 hs 조회 → c₂ ≈ hs(이다)   → "am" 예측
시각 3: h(am)    로 hs 조회 → c₃ ≈ hs(고양이) → "a" 예측
…
```

이렇게 입력 전체를 고정 길이 벡터 하나에 압축하던 seq2seq의 한계를, 매 시각 필요한 입력 정보를 새로 꺼내 쓰는 방식으로 해결했다.

## 6. 어텐션을 갖춘 seq2seq의 역전파

### 기울기의 흐름

어텐션을 갖춘 seq2seq의 역전파는 손실에서 시작해 Affine 계층을 거친 뒤, 맥락 벡터 c 쪽과 Decoder의 h 쪽으로 나뉜다(순전파에서 c와 h를 연결해 Affine에 넣었기 때문). c의 기울기는 Attention 계층의 Weight Sum과 Attention Weight를 거꾸로 지나며 h의 기울기와 hs의 기울기로 나뉜다.

그림: 손실 → Affine → (c의 기울기 → Weight Sum → Attention Weight → h, hs) + (h의 기울기)

### Decoder의 h: 두 경로의 기울기를 더한다

Decoder LSTM의 은닉 상태 h는 순전파에서 두 곳에 사용되었다.

- c와 연결되어 Affine 계층에 직접 입력된 경로
- Attention 계층에서 hs와 내적해 가중치 a를 만든 경로

순전파에서 분기했으므로 역전파 때는 두 경로의 기울기(Affine에서 온 기울기 + Attention에서 온 기울기)를 더해 위쪽에서 온 기울기로 삼는다. 여기에 다음 시각에서 넘어온 기울기까지 더해 Time LSTM의 역전파를 진행한다.

### Encoder의 hs: 모든 시각에서 기울기를 받는다

Encoder는 어텐션을 통해 모든 시각의 hs에서 기울기를 직접 받는다. hs는 Decoder의 모든 시각에서 어텐션에 사용되었으므로, 각 Decoder 시각에서 온 hs의 기울기를 모두 합산한다. 또한 Decoder의 초기 은닉 상태는 Encoder의 마지막 은닉 상태였으므로, Encoder의 마지막 시각에는 Decoder 초기 은닉 상태의 기울기까지 더해 역전파한다.

어텐션이 없으면 Encoder는 마지막 은닉 상태 하나로만 기울기를 받아, 앞쪽 단어까지 긴 시간 경로를 거쳐야 했다. 어텐션이 있으면 기울기가 Encoder의 모든 시각에 직접 전달되므로 기울기 소실이 줄어든다. 입력 데이터 반전이 앞쪽 단어의 거리를 줄여 준 것과 비슷한 효과를, 모든 단어에 대해 한꺼번에 얻는 셈이다.

## 7. 어텐션 시각화와 얼라인먼트

얼라인먼트 추출은 원래 사람이 수작업으로 하거나 통계적 방법으로 따로 추출했다. 어텐션은 학습 과정에서 어텐션 가중치를 통해 얼라인먼트를 자동으로 학습한다.

각 출력 시각의 가중치 a를 행으로 쌓아 색으로 칠하면, 출력 단어마다 어떤 입력 단어에 주목했는지를 눈으로 확인할 수 있다.

그림: 가로축은 입력 단어, 세로축은 출력 단어인 격자. 칸이 밝을수록 가중치가 크다. "I" 행은 "나" 칸이, "cat" 행은 "고양이" 칸이 밝다

이처럼 어텐션은 성능을 높일 뿐 아니라, 모델이 무엇을 보고 판단했는지 사람이 이해할 수 있게 해 준다.

## 8. 양방향 RNN

지금부터는 어텐션에 관한 남은 이야기와 응용이다. 먼저 Encoder를 더 개선한다.

### 단방향 LSTM의 한계

지금까지 Encoder는 단방향 LSTM으로, 글을 왼쪽에서 오른쪽으로 읽었다. 그래서 "고양이"에 대응하는 은닉 상태 벡터에는 "나", "는", "고양이"까지의 정보만 담기고, 오른쪽에 오는 "로소", "이다"의 정보는 담기지 않는다. 그런데 번역처럼 문장 전체가 한꺼번에 주어지는 문제라면 오른쪽에서 왼쪽으로도 읽을 수 있다.

### 양방향 LSTM

양방향 LSTM(bidirectional LSTM)은 기존 LSTM 계층에 역방향으로 처리하는 LSTM 계층을 하나 더 추가한다. 각 시각에서는 두 LSTM 계층의 은닉 상태를 연결한 벡터를 최종 은닉 상태로 사용한다(연결 외에 합이나 평균을 쓰는 방법도 있다). 이렇게 하면 각 단어에 대응하는 은닉 상태 벡터에 좌우 양쪽 방향의 정보가 균형 있게 담긴다.

그림: 위 줄 LSTM은 "나 → 이다" 방향, 아래 줄 LSTM은 "이다 → 나" 방향. 같은 단어 위치의 두 은닉 상태를 연결해 그 단어의 벡터로 사용

구현도 간단하다. Time LSTM 계층 두 개를 쓰되, 하나에는 입력 문장을 그대로("A B C D") 넣어 왼쪽에서 오른쪽으로 처리하고, 다른 하나에는 순서를 뒤집어("D C B A") 넣어 오른쪽에서 왼쪽으로 처리한다. 역방향 계층의 출력은 다시 원래 순서로 뒤집은 뒤, 같은 위치끼리 두 계층의 출력을 연결하면 양방향 LSTM 계층이 된다(Time BiLSTM 계층).

## 9. Attention 계층 사용 방법

지금까지는 Attention 계층을 LSTM 계층과 Affine 계층 사이에 넣어, Affine 계층이 맥락 벡터를 이용했다. 하지만 Attention 계층의 위치가 반드시 여기일 필요는 없다. 다른 구성으로, Attention 계층의 출력(맥락 벡터)을 다음 시각의 LSTM 계층에 입력해 LSTM 계층이 맥락 벡터의 정보를 이용하게 할 수도 있다.

그림: (가) LSTM → Attention → Affine 순서 / (나) Attention의 출력 c가 다음 시각 LSTM의 입력으로 들어감

어느 위치가 최종 정확도에 더 좋은지는 실제 데이터로 검증해 봐야 안다. 두 구성 모두 맥락 벡터를 잘 활용하므로 큰 차이가 없을 수도 있다. 구현 관점에서는 LSTM과 Affine 사이에 넣는 구성이 더 쉽다. Decoder의 데이터 흐름이 아래에서 위로 가는 한 방향이라 Attention 계층을 쉽게 모듈화(Time Attention 계층)할 수 있기 때문이다.

## 10. seq2seq 심층화와 skip 연결

### 층을 깊게 쌓기

번역 같은 실제 문제는 훨씬 복잡하므로 더 높은 표현력이 필요하다. 가장 먼저 생각할 방법은 LSTM 계층을 깊게 쌓는 것이다. 예를 들어 Encoder와 Decoder에 3층 LSTM을 쓰고, Decoder LSTM의 은닉 상태를 Attention 계층에 넣은 뒤, 출력인 맥락 벡터를 Decoder의 여러 계층(LSTM 계층과 Affine 계층)으로 전파할 수 있다.

Encoder와 Decoder에는 같은 층수의 LSTM을 쓰는 것이 일반적이며, 이 외에도 Attention 계층을 여러 개 쓰는 등 다양한 변형이 가능하다. 층을 깊게 할 때는 일반화 성능을 떨어뜨리지 않는 것이 중요하고, 이를 위해 드롭아웃과 가중치 공유가 효과적이다.

### skip 연결

층을 깊게 할 때 쓰는 중요한 기법이 skip 연결(skip connection, 잔차 연결, 숏컷)이다. 계층을 넘어 선을 연결하는 단순한 기법으로, 어떤 계층(예: LSTM 계층)의 입력을 그 계층을 거치지 않고 건너뛰어 계층의 출력 쪽으로 바로 보낸다.

그림: 아래 LSTM 계층에 들어가는 입력이 옆으로 난 선을 타고 LSTM 두 개를 건너뛰어 맨 위의 덧셈 노드(+)로 가고, 위 LSTM 계층의 출력도 같은 덧셈 노드로 들어간다

이렇게 건너뛴 선과 계층의 출력이 만나는 지점(덧셈 노드)이 접속부다. 접속부에서는 계층을 거친 출력과 계층을 건너뛰어 온 원래 입력이 원소별로 더해진다. 원소별로 더하므로 두 값의 크기(차원)가 같아야 한다. CNN의 ResNet에서 본 스킵 연결과 같은 아이디어다.

```text
출력 = 계층(x) + x
```

### skip 연결이 기울기 소실을 막는 이유

덧셈 노드는 역전파 때 상류의 기울기를 그대로 흘려보낸다. 그래서 skip 연결을 지나는 기울기는 아무 영향도 받지 않고 모든 계층으로 전달된다. 층이 깊어져도 기울기가 소실(혹은 폭발)되지 않아 학습이 잘 된다.

```text
RNN 기울기 문제와 대응
- 시간 방향 기울기 소실 → LSTM, GRU 같은 게이트가 추가된 RNN
- 시간 방향 기울기 폭발 → 기울기 클리핑
- 깊이 방향 기울기 소실 → skip 연결
```

## 11. 구글 신경망 기계 번역(GNMT)

### 기계 번역의 역사

기계 번역은 사람이 규칙을 직접 만드는 규칙 기반 번역에서, 비슷한 번역 예문을 응용하는 용례 기반 번역, 대량의 번역 데이터에서 단어·구의 번역 확률을 학습하는 통계 기반 번역으로 발전했다. 점점 사람이 정하는 부분을 줄이고 데이터에서 자동으로 배우는 방향으로 바뀌어 온 것이다.

현재는 문장 전체를 신경망으로 번역하는 신경망 기계 번역(NMT, Neural Machine Translation)이 주류다. NMT는 처음에는 통계 기반 번역과 대비되는 말로 쓰였지만, 지금은 seq2seq를 사용한 기계 번역의 총칭으로 쓰인다. 구글 번역은 2016년부터 신경망 번역인 GNMT(Google Neural Machine Translation)를 사용한다.

### GNMT의 구성

GNMT도 어텐션을 갖춘 seq2seq처럼 Encoder, Decoder, Attention으로 구성된다. 다만 번역 정확도를 높이기 위해 지금까지 본 개선이 모두 더해졌다.

- LSTM 계층의 다층화 (8층)
- 양방향 LSTM (Encoder의 첫 번째 계층만)
- skip 연결
- 학습 시간 단축을 위한 다수의 GPU 분산 학습

이 외에도 낮은 빈도 단어 처리, 추론 고속화를 위한 양자화 등의 기법이 함께 쓰였다. 그 결과 GNMT는 기존 구문 기반 기계 번역(PBMT, Phrase-Based Machine Translation)보다 번역 품질을 크게 끌어올려 사람의 번역에 가까워졌다.

다만 아직 부자연스러운 번역이나 사람이 하지 않을 실수도 한다. 또한 대량의 학습 데이터가 필요하고, 모델 하나를 학습하는 데 100개 가까운 GPU로 6일이 걸릴 만큼 컴퓨팅 자원이 많이 든다.

## 12. 뉴럴 튜링 머신(NTM)

### 외부 메모리라는 아이디어

사람은 복잡한 문제를 풀 때 종이와 펜이라는 외부 저장 장치를 쓴다. 신경망도 외부 메모리를 이용해 능력을 확장할 수 있다. RNN이나 LSTM은 내부 상태로 시계열 데이터를 기억하지만, 내부 상태의 길이가 고정이라 담을 수 있는 정보량이 제한적이다. 그래서 RNN 외부에 메모리를 두고 필요한 정보를 거기에 기록하는 방안이 나왔다.

어텐션을 갖춘 seq2seq도 이렇게 해석할 수 있다. Encoder가 필요한 정보를 메모리(hs)에 쓰고, Decoder가 어텐션으로 그 메모리에서 필요한 정보를 읽어 들이는 메모리 조작이다. 이를 확장해 RNN 외부에 메모리를 두고 어텐션으로 읽고 쓰는 대표적인 연구가 딥마인드(DeepMind)의 뉴럴 튜링 머신(NTM, Neural Turing Machine)이다. 이후 메모리 조작을 강화한 DNC(Differentiable Neural Computer)로 개선되었으며, 본질적인 기술은 같다.

### NTM의 계층 구성

- LSTM 계층: 컨트롤러로서 주된 처리를 한다.
- Write Head 계층: 각 시각에서 LSTM의 은닉 상태를 받아 필요한 정보를 메모리에 쓴다.
- Read Head 계층: 메모리에서 중요한 정보를 읽어 다음 시각의 LSTM 계층으로 전달한다.

### 미분 가능한 메모리 조작

메모리의 특정 번지를 골라 읽거나 쓰는 "선택" 작업 자체는 미분할 수 없다(3절의 문제와 같다). 그래서 어텐션으로 모든 번지의 데이터를 선택하되, 각 데이터의 기여도를 가중치로 나타내 미분 가능한 계산으로 대체한다. NTM은 두 가지 어텐션을 사용한다.

- 콘텐츠 기반 어텐션: 지금까지 본 어텐션과 같다. 입력으로 주어진 질의(query) 벡터와 비슷한 벡터를 메모리에서 찾는다.
- 위치 기반 어텐션: 이전 시각에 주목한 메모리 위치(각 위치의 가중치)를 기준으로 그 전후로 이동(시프트)한다. 1차원 합성곱으로 구현되며, 메모리 위치를 하나씩 옮겨 가며 읽는 컴퓨터 특유의 움직임을 재현한다.

이 외에도 어텐션 가중치를 날카롭게 다듬는 처리, 이전 시각의 가중치를 더하는 처리 등이 함께 쓰인다.

메모리 조작을 미분 가능한 계산으로 만들었으므로, 메모리 조작 순서도 데이터로부터 학습할 수 있다. 일반적인 컴퓨터는 사람이 작성한 프로그램대로 동작하지만, NTM은 알고리즘의 입력과 출력으로부터 알고리즘 자체(로직)를 학습한다. 실제로 seq2seq만으로는 풀지 못하던 긴 시계열 기억 문제와 정렬 문제를 잘 해결했다.

## 13. 트랜스포머의 등장과 셀프어텐션

### 등장 배경

언어 모델, 문장 생성, seq2seq, 어텐션을 갖춘 seq2seq까지 모두 RNN이 쓰였다. RNN은 가변 길이 시계열 데이터를 잘 처리하지만, 이전 시각의 계산 결과를 이용해 순서대로 계산하므로 시간 방향으로 병렬 계산하기가 기본적으로 불가능하다. 100단어 문장이면 100번을 차례로 계산해야 한다. 딥러닝 학습이 GPU 병렬 계산 환경에서 이뤄진다는 점을 생각하면 이는 큰 병목이다.

그래서 RNN을 없애는 연구가 활발히 이뤄졌다(RNN 대신 합성곱 계층을 쓴 ConvS2S도 그중 하나다). 가장 유명한 것이 2017년 「Attention Is All You Need」 논문의 트랜스포머(Transformer)다. 이름 그대로 RNN 없이 어텐션만으로 처리한다.

### 셀프어텐션

트랜스포머의 핵심은 셀프어텐션(Self-Attention)이다. 지금까지의 어텐션은 번역처럼 서로 다른 두 시계열 데이터(Encoder의 hs와 Decoder의 h) 사이의 대응 관계를 구했다. 셀프어텐션은 두 입력이 모두 하나의 시계열 데이터에서 나와, 하나의 시계열 데이터 안에서 각 원소가 다른 원소들과 어떻게 관련되는지를 구한다. 직역하면 "자신에 대한 주목"이다.

```text
지금까지의 어텐션:  Decoder의 h  로  Encoder의 hs 를 조회   (두 문장 사이)
셀프어텐션:         문장의 각 단어 로  같은 문장의 단어들을 조회 (한 문장 안)
```

예를 들어 "The animal didn't cross the street because it was too tired"에서 "it"은 셀프어텐션으로 문장 안의 모든 단어를 보고, 그중 "animal"에 높은 가중치를 준다. 그 결과 "it"의 새 표현에 "animal"의 정보가 담긴다. 즉 셀프어텐션은 각 단어의 벡터를 문맥이 반영된 벡터로 바꾸는 역할을 한다. 같은 "it"이라도 문장에 따라 다른 벡터가 되는 것이다.

### RNN과 비교한 장점

- 병렬 계산: 모든 단어 쌍의 유사도를 행렬 곱 한 번으로 계산하므로, 시각 순서대로 계산할 필요가 없다.
- 먼 단어 간의 관계: RNN은 먼 단어까지 정보가 여러 시각을 거쳐 전달되며 희미해지지만, 셀프어텐션은 거리와 상관없이 모든 단어가 직접 연결된다.

## 14. 트랜스포머의 구조

### 전체 구조

트랜스포머를 단순화하면 Encoder 쪽은 Time Embedding → (셀프어텐션 → Feed Forward)를 N겹 쌓고, Decoder 쪽은 Time Embedding → (셀프어텐션 → Encoder 출력을 받는 어텐션 → Feed Forward)를 N겹 쌓은 뒤 Time Affine → Time Softmax with Loss로 손실을 구한다. RNN 자리에 어텐션이 들어간 seq2seq라고 보면 된다.

논문의 실제 구조는 여기에 몇 가지가 더해진다.

```text
[Encoder] (N = 6번 반복)
입력 단어 → 임베딩 + 위치 인코딩
  → 멀티헤드 셀프어텐션 → Add & Norm
  → Feed Forward      → Add & Norm
  → (다음 Encoder 블록)

[Decoder] (N = 6번 반복)
지금까지의 출력 단어 → 임베딩 + 위치 인코딩
  → 마스크드 멀티헤드 셀프어텐션            → Add & Norm
  → 멀티헤드 크로스 어텐션 (Encoder 출력 사용) → Add & Norm
  → Feed Forward                          → Add & Norm
  → (다음 Decoder 블록)
  → Linear → Softmax → 다음 단어의 확률
```

논문의 기본 설정은 블록 수 N = 6, 단어 벡터 크기 d_model = 512, 헤드 수 h = 8, Feed Forward 은닉층 크기 d_ff = 2048이다. 모든 블록의 입력과 출력 크기를 d_model로 맞춰 두었기 때문에 블록을 그대로 반복해서 쌓을 수 있다. 아래에서 각 부품을 입력 쪽부터 차례로 본다.

### 입력 임베딩과 위치 인코딩

입력 단어는 Embedding 계층으로 d_model 크기의 벡터가 된다. 문제는 셀프어텐션이 모든 단어를 한꺼번에 보기 때문에 순서 정보가 없다는 점이다. RNN은 순서대로 처리하니 순서가 자연히 담겼지만, 셀프어텐션은 "나는 고양이를 좋아한다"와 단어를 뒤섞은 문장을 구분하지 못한다(CBOW에서 맥락의 순서가 무시됐던 것과 같은 문제).

그래서 각 위치마다 고유한 벡터를 만들어 임베딩 벡터에 더한다. 이를 위치 인코딩(Positional Encoding)이라 한다. 논문은 사인·코사인 함수로 위치 벡터를 만든다.

```text
PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))

pos: 단어의 위치, i: 벡터 안의 차원 번호
입력 = 단어 임베딩 + PE(위치)
```

차원마다 주기가 다른 파동을 쓰므로 위치마다 서로 다른 패턴의 벡터가 나온다. 시계의 초침·분침·시침이 함께 시각을 나타내는 것과 비슷하다. 빠르게 도는 차원은 가까운 위치를, 느리게 도는 차원은 먼 위치를 구별한다. 또한 함수로 계산하므로 학습 때 보지 못한 긴 문장에도 적용할 수 있을 것으로 기대했다. 위치 벡터를 학습되는 매개변수로 두는 방법도 있으며, 논문에서는 두 방법의 성능이 비슷했다.

### Query, Key, Value

트랜스포머는 어텐션의 역할을 세 벡터로 나눠 부른다.

| 벡터 | 의미 | 앞에서 본 어텐션에 대응 |
| --- | --- | --- |
| Query (Q) | 지금 무엇을 찾고 있는가 | Decoder의 은닉 상태 h |
| Key (K) | 각 단어가 어떤 정보를 가졌는지 나타내는 표지 | 내적 대상인 hs |
| Value (V) | 실제로 가져올 정보 | 가중합 대상인 hs |

앞에서 본 어텐션에서는 hs 하나가 Key와 Value 역할을 함께 했다. 트랜스포머는 각 단어 벡터 x에 서로 다른 가중치 행렬 W_Q, W_K, W_V를 곱해 Q, K, V를 따로 만든다.

```text
Q = X × W_Q,   K = X × W_K,   V = X × W_V

X: 단어 벡터들을 쌓은 행렬 (단어 수 × d_model)
```

이 가중치들은 학습되는 매개변수이므로, "무엇을 찾을지", "어떻게 찾아질지", "무엇을 건네줄지"를 각각 학습할 수 있어 표현력이 높아진다. 앞에서 본 Attention 계층에는 매개변수가 없었던 것과 다른 점이다.

도서관 검색에 비유하면 Query는 검색어, Key는 각 책의 제목과 키워드, Value는 책의 실제 내용이다. 검색어와 제목이 비슷한 책일수록 그 내용을 많이 가져온다.

### Scaled Dot-Product Attention

트랜스포머의 기본 어텐션 계산은 다음과 같다.

```text
Attention(Q, K, V) = softmax(Q × Kᵀ / √d_k) × V
```

1. Q와 K를 내적해 각 단어 쌍의 유사도 점수를 구한다 (Attention Weight 앞부분).
2. √d_k(Key 벡터 차원 수의 제곱근)로 나눈다.
3. 소프트맥스로 합이 1인 가중치를 만든다.
4. 그 가중치로 V를 가중합한다 (Weight Sum).

앞에서 배운 "내적 → 소프트맥스 → 가중합"과 같고, 2번만 추가되었다. 다만 단어 하나씩이 아니라 모든 단어의 Q를 행렬로 쌓아 Q × Kᵀ 한 번에 모든 단어 쌍의 점수를 구하므로 병렬로 계산된다.

```text
Q × Kᵀ 의 형상: (단어 수 × 단어 수)
i행 j열 = i번째 단어가 j번째 단어를 얼마나 참고할지의 점수
```

√d_k로 나누는 이유는 다음과 같다. 벡터 차원이 클수록 내적은 더하는 항이 많아져 값이 넓게 퍼진다(Xavier 초깃값에서 n개를 더하면 분산이 n배, 표준편차가 √n배가 되던 것과 같은 원리). 내적 값이 너무 크면 소프트맥스 출력이 한 단어에 거의 1, 나머지에 거의 0으로 쏠리고, 이 구간에서는 소프트맥스의 기울기가 거의 0이 된다(시그모이드 출력이 0·1로 치우치면 기울기 소실이 생기던 것과 같은 원리). 그래서 √d_k로 나눠 값의 크기를 조정해 소프트맥스가 적당히 퍼지게 만든다. 이름의 "Scaled"가 이 부분이다.

### 멀티헤드 어텐션

어텐션을 하나만 쓰면 한 단어가 주목하는 방식이 한 가지로 정해진다. 그런데 문장에서 단어 사이의 관계는 여러 종류다. 예를 들어 동사 입장에서는 주어가 누구인지, 목적어가 무엇인지, 시제를 나타내는 단어가 어디 있는지 등을 동시에 봐야 한다.

멀티헤드 어텐션(Multi-Head Attention)은 어텐션을 여러 개(헤드) 병렬로 계산한다.

```text
headᵢ = Attention(Q × W_Qᵢ, K × W_Kᵢ, V × W_Vᵢ)    (i = 1 ~ h)
MultiHead(Q, K, V) = Concat(head₁, …, head_h) × W_O
```

1. 헤드마다 서로 다른 가중치 W_Qᵢ, W_Kᵢ, W_Vᵢ로 Q, K, V를 작은 차원(d_k = d_model / h = 512 / 8 = 64)으로 변환한다.
2. 각 헤드가 Scaled Dot-Product Attention을 따로 계산한다.
3. h개 헤드의 결과를 연결(Concat)하면 다시 d_model 크기(64 × 8 = 512)가 된다.
4. 출력 가중치 W_O를 곱해 헤드들의 정보를 섞고 최종 출력을 만든다.

헤드마다 가중치가 다르므로 서로 다른 관점의 관계를 학습한다. 한 헤드는 주어-동사 관계, 다른 헤드는 대명사가 가리키는 대상에 주목하는 식이다. CNN에서 필터를 여러 개 써서 서로 다른 특징을 찾던 것과 비슷하다. 헤드마다 차원을 1/h로 줄였으므로 전체 계산량은 큰 어텐션 하나를 쓸 때와 비슷하다.

### Add & Norm (skip 연결 + 계층 정규화)

모든 부품(어텐션, Feed Forward) 뒤에는 Add & Norm이 붙는다.

```text
출력 = LayerNorm(x + 부품(x))
```

- Add (skip 연결): 부품의 입력 x를 부품을 건너뛰어 부품의 출력과 더한다. 10절에서 본 skip 연결과 같으며, 블록을 깊게 쌓아도 기울기가 덧셈 경로로 그대로 전달되어 깊이 방향의 기울기 소실을 막는다. 모든 부품의 입출력 크기를 d_model로 맞춘 이유도 이 원소별 덧셈을 하기 위해서다.
- Norm (계층 정규화): 배치 정규화는 미니배치 방향으로 평균과 분산을 구했지만, 계층 정규화(Layer Normalization)는 데이터 하나(단어 하나)의 벡터 안에서 평균과 분산을 구해 정규화한다. 문장 길이가 제각각이고 배치 크기에 영향을 받지 않아야 하는 시계열 데이터에 알맞다. 정규화 뒤에는 배치 정규화처럼 학습되는 γ, β로 다시 조정한다.

### Feed Forward 계층

Feed Forward 계층은 시간 방향으로 독립적으로 처리하는 피드포워드 신경망이다. 정확히는 은닉층이 1개이고 활성화 함수로 ReLU를 쓰는 완전연결 신경망이다.

```text
FFN(x) = max(0, x × W₁ + b₁) × W₂ + b₂
(512 → 2048 → 512)
```

같은 신경망을 각 단어 위치마다 따로 적용하므로 Position-wise Feed-Forward Network라고도 한다. 어텐션이 다른 단어들의 정보를 모아 오는 단계라면, Feed Forward는 모아 온 정보를 각 단어 안에서 비선형적으로 한 번 더 가공하는 단계다. 어텐션 자체는 가중합(선형 결합)이 중심이라, 비선형 활성화 함수가 들어간 Feed Forward가 있어야 블록을 쌓는 의미가 생긴다(활성화 함수가 선형이면 층을 깊게 하는 의미가 없어지던 것과 같은 이유).

### Encoder 블록

Encoder 블록은 두 부품으로 이루어진다.

1. 멀티헤드 셀프어텐션 + Add & Norm: Q, K, V를 모두 입력 문장 자신에서 만든다. 문장의 각 단어가 다른 모든 단어를 참고해 문맥이 반영된 표현이 된다.
2. Feed Forward + Add & Norm

이 블록을 6번 쌓으면 마지막 출력은 입력 문장의 각 단어를 문맥까지 담아 표현한 벡터들이 된다. 이것이 어텐션을 갖춘 seq2seq의 Encoder 출력 hs에 해당하며, Decoder가 크로스 어텐션에서 참고한다.

### Decoder 블록

Decoder 블록은 세 부품으로 이루어진다.

① 마스크드 멀티헤드 셀프어텐션 + Add & Norm

Decoder도 지금까지 만든 출력 문장에 셀프어텐션을 한다. 학습 때는 정답 문장("<eos> I am a cat")을 한꺼번에 넣어 모든 위치를 병렬로 계산한다(교사 강요). 그런데 그대로 두면 "am"을 예측해야 하는 위치에서 뒤에 오는 "a cat"까지 볼 수 있다. 정답을 미리 보고 맞히는 커닝이다.

그래서 각 위치가 자기보다 뒤에 있는 단어를 보지 못하도록 마스크(mask)를 씌운다. 소프트맥스 전에 뒤쪽 단어들의 점수를 매우 작은 값(−∞에 가까운 값)으로 바꾸면 exp(−∞) = 0이므로 소프트맥스 후 가중치가 0이 된다.

```text
            <eos>   I    am    a    cat
<eos> 위치    O     X    X     X    X
I 위치        O     O    X     X    X
am 위치       O     O    O     X    X
a 위치        O     O    O     O    X
cat 위치      O     O    O     O    O
(O: 볼 수 있음, X: 마스크)
```

이렇게 하면 학습 때 병렬로 계산하면서도, 실제로 한 단어씩 생성할 때와 같은 조건(앞 단어만 볼 수 있음)을 유지한다.

② 멀티헤드 크로스 어텐션 + Add & Norm

크로스 어텐션(Encoder-Decoder Attention)은 Query를 Decoder에서, Key와 Value를 Encoder의 최종 출력에서 가져온다.

```text
Q: ①을 거친 Decoder의 표현 (지금까지 번역한 상태 → 다음에 필요한 정보)
K, V: Encoder의 최종 출력 (원문 각 단어의 문맥 표현)
```

어텐션을 갖춘 seq2seq의 어텐션(Decoder의 h로 Encoder의 hs를 조회)과 같은 역할이다. 번역할 때 원문의 어느 단어를 볼지 정하는 얼라인먼트를 여기서 학습한다. 셀프어텐션이 "같은 문장 안의 관계"라면, 크로스 어텐션은 "두 문장 사이의 관계"다.

그림: Encoder 마지막 블록의 출력이 Decoder 모든 블록의 크로스 어텐션(K, V 자리)으로 화살표로 들어간다

③ Feed Forward + Add & Norm

Encoder와 같다.

### 출력층과 학습, 추론

Decoder의 마지막 블록 출력에 Linear(Affine) 계층을 적용해 어휘 수만큼의 점수를 만들고, 소프트맥스로 다음 단어의 확률을 구한다. 학습 때는 교차 엔트로피로 손실을 구해 역전파한다(Time Affine → Time Softmax with Loss). 논문에서는 입력 임베딩과 이 출력 Linear 계층의 가중치를 공유하는데, 이는 게이트가 추가된 RNN에서 본 가중치 공유(weight tying)와 같은 기법이다.

|  | 학습 | 추론(생성) |
| --- | --- | --- |
| Decoder 입력 | 정답 문장 전체를 한꺼번에 | 지금까지 생성한 단어들 |
| 계산 방식 | 마스크를 씌워 모든 위치를 병렬 계산 | 한 단어씩 생성하고, 생성한 단어를 입력에 붙여 반복 |
| 종료 | 손실 계산 후 역전파 | 끝을 나타내는 기호가 나오면 종료 |

즉 학습은 병렬로 빠르게 하고, 추론은 RNN 때처럼 한 단어씩 생성한다.

## 15. 트랜스포머의 성과와 그 이후

### 성과와 의의

트랜스포머는 계산량을 줄이고 GPU 병렬 계산의 혜택을 더 많이 누려, GNMT보다 학습 시간을 크게 줄였다. 영어-프랑스어 번역 벤치마크(WMT)의 BLEU 점수도 GNMT(RNN 기반), ConvS2S(CNN 기반)를 모두 웃돌았다. 즉 어텐션은 RNN과 함께 쓰는 보조 모듈을 넘어, RNN을 대체하는 모듈로도 쓸 수 있다.

### 트랜스포머 이후

트랜스포머의 Encoder와 Decoder는 각각 떼어서도 쓰인다.

| 구조 | 대표 모델 | 특징 |
| --- | --- | --- |
| Encoder만 사용 | BERT | 마스크 없이 문장 전체를 양방향으로 보고 이해하는 데 강함 (분류, 검색용 임베딩 등) |
| Decoder만 사용 | GPT 계열 등 대부분의 LLM | 크로스 어텐션 없이 마스크드 셀프어텐션만으로 다음 토큰을 예측해 문장 생성 |
| Encoder-Decoder 모두 사용 | 원래 트랜스포머, T5 | 번역, 요약처럼 입력 시퀀스를 다른 시퀀스로 변환 |

오늘날 LLM(Large Language Model)이 다음 토큰을 하나씩 예측하는 방식은 결국 언어 모델(앞 단어들이 주어졌을 때 다음 단어의 확률 예측)을 트랜스포머 Decoder로 구현한 것이다. 언어 모델 → RNN → seq2seq → 어텐션 → 트랜스포머로 이어진 흐름이 그대로 현재의 LLM으로 이어진다.
