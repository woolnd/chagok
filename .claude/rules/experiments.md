# 실험 규칙

- 한 실험에서 한 모듈만 켜고 끈다. 나머지 설정은 베이스라인과 같게 둔다.
- 품질·속도·비용을 `docs/DESIGN.md`의 지표로 잰다. 비용이 드는 선택은 선택지 2개 이상을 비교한다.
- 5%p 미만 차이는 개선으로 보지 않는다.
- 결과가 이상하면 생성 단계보다 검색 결과부터 본다.
- 실험이 끝나면 `docs/DECISIONS.md`에 기록하고 `exp:` 커밋을 남긴다. `docs/STATUS.md` 실험 로그도 갱신한다.
- 채택은 사람이 결정한다. 결과와 판정만 보고한다.
