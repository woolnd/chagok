## 2026-11-08 Parent Document 채택, K=5 (#34)

**문제**: 짧은 키워드 질문(q030 "CNN", q007 "임계값")에서 같은 부모 아래 하위 섹션들이 1~5등을 다 차지해, 개념을 설명하는 다른 섹션이 밀려난다.

**선택지**:
1. 섹션 그대로 돌려줌 (지금)
2. Parent Document: 작은 섹션으로 찾고, `##` 부모 섹션(`path[:2]`)으로 묶어 겹치지 않는 부모 K개를 돌려준다. K = 3, 5, 10

**채택 기준** (실험 전에 정함, 이슈 #34 댓글): 새로 틀린 질문 0개, 회귀 Hit@5 100% 유지, 새로 맞힌 질문 1개 이상. 채점은 돌려준 부모 섹션 아래에 정답이 있으면 맞음. 틀린 질문이 3개뿐이라 3번은 잡음 기준(3문항)보다 낮게 잡았고, 질문별 맞음/틀림 변화 목록으로 7번 원칙(실패 사례를 뺀 질문으로도 확인)을 대신한다.

**결과** (노트 10개, 평가셋 100개 중 답없음 제외 89개, 하이브리드 0.8 + 리랭커 -9.6):

| | 회귀 Hit@K | 능력 Hit@K | 능력 Hit@1 | 능력 MRR | 새로 맞힘 | 새로 틀림 |
| --- | --- | --- | --- | --- | --- | --- |
| K=3 끔 → 켬 | 100% → 100% | 68% → 84% | 26% → 58% | 0.46 → 0.69 | q021·q030·q045 | 0 |
| K=5 끔 → 켬 | 100% → 100% | 84% → 89% | 26% → 58% | 0.50 → 0.71 | q030 | 0 |
| K=10 끔 → 켬 | 100% → 100% | 95% → 95% | 26% → 58% | 0.52 → 0.71 | 없음 | 0 |

- 순위가 오른 질문 7개(q021, q030, q045, q046, q062, q069, q076), 내려간 질문 0개. K와 상관없이 같다
- q007 "임계값"은 여전히 5등 밖, q006은 정답 섹션이 달라 해당 없음
- 답없음 11개 중 7개 막음 (끔과 같음)
- 처음에는 리랭커에 부모마다 1등 하위 섹션만 넘겨 회귀 q074·q088이 막혔다. q074는 게이트를 통과시키던 섹션이 2등 형제(Adam)였다. 묶느라 건너뛴 섹션도 리랭커에 넘겨, 게이트가 묶기 전과 같은 섹션을 보고 판단하게 고쳤다
- 속도: 검색만 25ms로 같음. 리랭커 게이트 포함 중간값 229ms → 284ms, 최대 721ms → 827ms (K=5, mps). 출제 게이트 기준 5초 이하
- 비용: 0원 (LLM 호출 없음)

**결정**: 채택, K=5. `hybrid.PARENT = True` 기본값, CI도 켠 채로 돈다. 끄고 비교할 때는 `evaluate.py noparent`. 돌려주는 본문은 아직 1등 하위 섹션 하나이고, 부모 섹션 전체 글을 합쳐 LLM에 넣는 것은 Phase 3 출제에서 한다.

**버린 이유**:
- 1번: 형제 섹션이 칸을 차지해 능력 MRR 0.50에 머문다.
- K=3: q086을 못 맞힌다.
- K=10: Hit@K가 K=5보다 오르지 않는데 출제 때 LLM에 넣을 글이 두 배가 된다.
