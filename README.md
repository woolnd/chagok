# 차곡 (chagok)

> 내가 쓴 학습 노트로 복습 문제를 만들어, 평일 아침마다 메일로 보내주는 서비스. 내가 한 번 확인한 문제만 메일로 나간다.

## 흐름
노트 → 관련 내용 찾기(검색) → 문제 만들기 → AI가 1차 검사 → 내가 최종 검토 → 메일

## 북극성 지표
검토 승인율 = 내가 고치지 않고 바로 승인한 문제 수 ÷ 내가 본 문제 수

## 🛠 사용 기술
- LangGraph, Claude, LangSmith
- BM25(kiwi) + 벡터 검색, LLM Wiki
- Docker, Railway

## 실행
```bash
uv sync
```

## 조각(청크) 모양
노트의 `##` 섹션 하나가 조각 하나가 된다. 조각 맨 앞에는 "노트 제목 | 배운 날짜 | 소제목" 머리말이 붙는다.

```python
{
    "id": "2026-10-15_perceptron.md#퍼셉트론 > 1. 퍼셉트론이란",  # 파일명#제목 > 소제목
    "text": "퍼셉트론 | 2026-10-15 | 1. 퍼셉트론이란\n본문...",   # 머리말 + 본문(### 소제목, 표 포함)
    "file": "2026-10-15_perceptron.md",  # 파일명
    "page": 1,                           # 페이지 번호 (## 섹션 순번)
    "date": "2026-10-15",                # 배운 날짜
    "topic": "퍼셉트론",                  # 주제 (노트 제목)
    "kind": "이론",                       # 성격 (이론/실습/질문, 지금은 이론으로 고정)
}
```

## 적재
`uv run python -m chagok.store`를 돌리면 `raw/`의 노트를 전부 조각으로 만들어 `store/`에 저장한다. 새 노트가 생기면 다시 돌린다.

| 파일 | 내용 | 검색 때 쓰는 곳 |
|---|---|---|
| `chunks.json` | 조각 원본 (위의 조각 모양) | 번호로 조각 되찾기 |
| `bm25_tokens.json` | 조각마다 kiwi 형태소 단어 목록 (명사·동사·형용사·영어·숫자만, 조사·어미는 버림) | BM25 점수 |
| `faiss.index` | 조각마다 bge-m3 벡터(1024차원), HNSW (M 16, ef_search 64) | 의미 검색 |

- 세 파일은 같은 순서다: i번째 = i번째 조각. 검색은 번호만 돌려주므로 `chunks.json[i]`로 조각을 꺼낸다.
- `store/`는 다시 만들 수 있어서 git에 올리지 않는다.
