# 차곡 (chagok)

> 내가 쓴 학습 노트로 복습 문제를 만들어, 평일 아침마다 메일로 보내주는 서비스. 내가 한 번 확인한 문제만 메일로 나간다.

## 흐름
노트 → 관련 내용 찾기(검색) → 문제 만들기 → AI가 1차 검사 → 내가 최종 검토 → 메일

## 북극성 지표
검토 승인율 = 내가 고치지 않고 바로 승인한 문제 수 ÷ 내가 본 문제 수

## 🛠 사용 기술
- LangGraph, Claude, LangSmith
- BM25(kiwi) + 벡터 검색, LLM Wiki
- Docker, Railway

## 실행
```bash
uv sync
```

## 조각(청크) 모양
노트의 `##` 섹션 하나가 조각 하나가 된다. 조각 맨 앞에는 "노트 제목 | 배운 날짜 | 소제목" 머리말이 붙는다.

```python
{
    "id": "2026-10-15_perceptron.md#퍼셉트론 > 1. 퍼셉트론이란",  # 파일명#제목 > 소제목
    "text": "퍼셉트론 | 2026-10-15 | 1. 퍼셉트론이란\n본문...",   # 머리말 + 본문(### 소제목, 표 포함)
    "file": "2026-10-15_perceptron.md",  # 파일명
    "page": 1,                           # 페이지 번호 (## 섹션 순번)
    "date": "2026-10-15",                # 배운 날짜
    "topic": "퍼셉트론",                  # 주제 (노트 제목)
    "kind": "이론",                       # 성격 (이론/실습/질문, 지금은 이론으로 고정)
}
```

## 적재
`uv run python -m chagok.store`를 돌리면 `raw/`의 노트를 전부 조각으로 만들어 `store/`에 저장한다. 새 노트가 생기면 다시 돌린다.

| 파일 | 내용 | 검색 때 쓰는 곳 |
|---|---|---|
| `chunks.json` | 조각 원본 (위의 조각 모양) | 번호로 조각 되찾기 |
| `bm25_tokens.json` | 조각마다 kiwi 형태소 단어 목록 (명사·동사·형용사·영어·숫자만, 조사·어미는 버림) | BM25 점수 |
| `faiss.index` | 조각마다 bge-m3 벡터(1024차원), HNSW (M 16, ef_search 64) | 의미 검색 |

- 세 파일은 같은 순서다: i번째 = i번째 조각. 검색은 번호만 돌려주므로 `chunks.json[i]`로 조각을 꺼낸다.
- `store/`는 다시 만들 수 있어서 git에 올리지 않는다.

## 검색
개념 하나(검색어)로 문제의 근거가 될 노트 조각을 찾는다. `src/chagok/search.py`

```
"기울기 소실"
  ├─ BM25: kiwi로 자른 단어가 얼마나 겹치나 → 상위 10개
  ├─ 벡터: bge-m3 벡터가 얼마나 가까운가 (FAISS HNSW) → 상위 10개
  ▼
RRF: 두 순위를 등수로 합침 → 상위 10개 조각
  ▼
리랭크: bge-reranker-v2-m3가 (검색어, 조각)을 같이 읽고 다시 정렬 → 3개만 남김
```

- BM25는 정확한 용어(LSTM, BPTT)에 강하고, 벡터는 표현이 달라도 뜻이 같은 것에 강하다. 둘을 합쳐 서로 놓친 걸 메운다.
- RRF는 점수 대신 등수로 합친다: 조각마다 `1 / (60 + 등수)`를 더한다. BM25와 벡터는 점수 단위가 달라서 그대로 더할 수 없다.
- 검색은 조각 번호만 돌려주고, `chunks.json[번호]`로 조각 원본을 꺼낸다.
- 리랭커는 검색어와 조각을 한 쌍씩 같이 읽어서 더 정확하지만 느리다. 그래서 RRF로 줄인 10개에만 쓴다.
- 리랭커는 4개(리랭크 안 함, bge-reranker-v2-m3, bge-reranker-v2-m3-ko, Qwen3-Reranker-0.6B)를 비교해 골랐다. 지금 평가셋에선 리랭크 안 함과 점수가 같아서, 고도화 때 승인율로 다시 비교한다.

평가: `uv run python -m chagok.search`
- `eval/concepts.csv` 개념 30개로 Recall@k, MRR: RRF 10개, 리랭크 후 3개 (정답이 `###` 소제목이면 그 위 `##` 조각을 찾으면 맞힘)
- HNSW 결과가 전부 비교한 결과와 얼마나 겹치는지
