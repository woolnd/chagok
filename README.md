# 차곡 (chagok)

> 내가 쓴 학습 노트로 복습 문제를 만들어, 평일 아침마다 메일로 보내주는 서비스. 내가 한 번 확인한 문제만 메일로 나간다.

## 흐름
노트 → 관련 내용 찾기(검색) → 문제 만들기 → AI가 1차 검사 → 내가 최종 검토 → 메일

## 북극성 지표
검토 승인율 = 내가 고치지 않고 바로 승인한 문제 수 ÷ 내가 본 문제 수

## 🛠 사용 기술
- LangGraph, Claude, LangSmith
- BM25(kiwi) + 벡터 검색, LLM Wiki
- Docker, Railway

## 실행
```bash
uv sync
```
