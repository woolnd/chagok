# 특징 추출

## 정의
전이 학습의 한 방법으로, 학습된 모델의 가중치를 고정하고 출력층만 학습하는 방법이다.

## 핵심 포인트
- 가중치를 고정하고 출력층만 학습하는 방법이 특징 추출(feature extraction)이라는 것
- 파인튜닝은 가중치를 초깃값으로 삼고 일부 또는 전체 층을 다시 학습하는 것이라서, 가중치를 고정하는지 여부로 두 방법을 구분한다는 것
- 전이 학습은 한 문제에서 학습한 지식(가중치)을 다른 문제에 재사용하는 방법 전반을 가리킨다는 것
