# 양의 상호정보량

## 정의
점별 상호정보량(PMI)의 문제를 피하기 위해 실제로 구현할 때 사용하는 양의 상호정보량(PPMI, Positive PMI)은 PPMI(x, y) = max(0, PMI(x, y))로 정의한다. PMI가 음수일 때는 0으로 취급하므로, 단어 사이의 관련성을 0 이상의 실수로 나타낼 수 있다.

## 핵심 포인트
- PMI는 동시발생 횟수가 0이면 log₂0 = −∞가 되는 문제가 있어, 이를 피하려고 PPMI를 사용한다.
- PPMI = max(0, PMI): PMI가 음수이면 0으로 취급한다.
- PPMI로 단어 사이의 관련성을 0 이상의 실수로 나타낸다.
