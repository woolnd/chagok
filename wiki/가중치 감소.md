# 가중치 감소

## 정의
가중치 감소(weight decay)는 손실 함수에 "가중치가 클수록 커지는 벌칙(penalty)"을 더해, 가중치가 커지지 않게 하는 방법이다.

## 핵심 포인트
- L2 정규화는 새 손실 = 원래 손실 + ½λ(w₁² + w₂² + … + wₙ²)이며, 미분하면 기울기 = 원래 기울기 + λW이다
- 역전파에서 기울기에 λW가 더해져 매 갱신마다 가중치가 자기 크기에 비례해 0 쪽으로 끌려간다. 0이 되지는 않는다
- L1 정규화는 미분해도 λ만큼 일정한 힘으로 줄여 작은 가중치를 0으로 만들며, 필요 없는 입력을 끊어 내는 단순한 모델이 된다
