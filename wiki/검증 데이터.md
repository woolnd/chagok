# 검증 데이터

## 정의
하이퍼파라미터의 성능을 평가하기 위해 훈련 데이터와 별도로 따로 떼어 둔 데이터. 하이퍼파라미터를 여러 값으로 바꿔 가며 성능을 비교할 때 시험 데이터 대신 사용한다.

## 핵심 포인트
- 하이퍼파라미터 성능 평가 전용 데이터이며, 가중치 학습에는 쓰지 않는다
- 시험 데이터로 하이퍼파라미터를 고르면 시험 데이터에 과대적합되어 범용 성능 평가가 무의미해진다
- 훈련/검증/시험 데이터의 역할 구분: 훈련=가중치 학습, 검증=하이퍼파라미터 평가, 시험=마지막에 한 번 범용 성능 평가
- 가장 간단한 방법은 훈련 데이터의 20% 정도를 검증 데이터로 떼어 두는 것
