# 검증 데이터

## 정의
하이퍼파라미터를 조정할 때 쓰는 하이퍼파라미터 전용 확인 데이터이며, 일반적으로 검증 데이터(validation data)라고 부른다.

## 핵심 포인트
- 하이퍼파라미터의 성능 평가에 사용하며, 시험 데이터를 하이퍼파라미터 조정에 쓰면 시험 데이터에 과대적합되어 범용 성능이 떨어지는 모델이 될 수 있다.
- 훈련 데이터는 매개변수 학습에, 검증 데이터는 하이퍼파라미터 성능 평가에, 시험 데이터는 신경망의 범용 성능 평가에 쓴다.
- 가장 간단한 얻는 방법은 훈련 데이터 중 20% 정도를 검증 데이터로 먼저 분리하는 것이다.
