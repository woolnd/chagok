# 동시발생 행렬

## 정의
단어의 주변 단어를 세어 집계한 행렬. 어떤 단어에 주목했을 때 그 주변에 어떤 단어가 몇 번이나 등장하는지를 세어 집계하는 방법이다.

## 핵심 포인트
- 윈도우 크기 1일 때 "you say goodbye and i say hello ."에서 you의 맥락은 say 하나이며, you는 [0, 1, 0, 0, 0, 0, 0]으로 표현된다
- 동시발생 행렬의 각 행이 해당 단어를 표현한 벡터가 된다
- 분포 가설(단어의 의미는 주변 단어에 의해 형성된다)에 기초한 단어 벡터 표현 방법이다
