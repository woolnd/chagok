# 동시발생 행렬

## 정의
단어의 주변 단어를 세어 집계한 표로, 이 표의 각 행이 해당 단어를 표현한 벡터가 된다. 이 표가 행렬의 형태를 띤다는 뜻에서 동시발생 행렬(co-occurrence matrix)이라고 한다.

## 핵심 포인트
- 어떤 단어에 주목했을 때 그 주변에 어떤 단어가 몇 번이나 등장하는지를 세어 집계하는 방법이다
- 분포 가설에 기초해 단어를 벡터로 나타내는 방법이다
- 윈도우 크기 1일 때 you의 맥락은 say 하나이므로 you는 [0, 1, 0, 0, 0, 0, 0]으로 표현된다
- 표의 각 행이 단어 벡터가 되며, 단어 벡터 간 유사도는 코사인 유사도로 비교한다
