# 합성곱 계층

## 정의
합성곱 계층은 형상을 유지하며, 입력 데이터에 필터를 적용해 합성곱 연산을 처리하는 계층이다. 합성곱 연산은 이미지 처리에서 말하는 필터(filter) 연산에 해당한다.

## 핵심 포인트
- 완전연결 계층은 데이터의 형상을 무시하고 3차원 데이터를 평탄화해야 하는 반면, 합성곱 계층은 형상을 유지하여 3차원 데이터로 입출력한다
- 합성곱 연산은 윈도우를 일정 간격으로 이동하며 대응하는 원소끼리 곱한 후 총합을 구하는 방식이며, 출력 크기는 OH = (H + 2P − FH) / S + 1 로 구한다
- 패딩은 출력 크기를 조정하기 위해 입력 주변을 특정 값으로 채우는 것이고, 스트라이드는 필터를 적용하는 위치의 간격이며 스트라이드를 키우면 출력 크기가 작아진다
