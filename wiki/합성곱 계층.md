# 합성곱 계층

## 정의
합성곱 계층(Conv)은 형상(공간 정보)을 유지한 채 3차원 데이터를 받아 3차원 데이터로 내보내는 계층이다. 입출력 데이터는 특징 맵(feature map)이라 한다.

## 핵심 포인트
- 완전연결 계층은 입력을 평탄화하면서 형상(공간적 관계)을 무시하지만, 합성곱 계층은 형상을 유지하여 3차원 데이터를 3차원으로 내보낸다
- 합성곱 연산은 필터(커널)를 입력 위의 윈도우에 겹쳐 원소끼리 곱해 모두 더하는 방식이며, 필터 값이 가중치에 해당하고 필터당 편향은 하나다
- 출력 크기는 OH = (H + 2P − FH) / S + 1로 계산되며, 패딩(P)과 스트라이드(S)가 출력 크기를 조정한다
