# 신경망

## 정의
신경망(neural network)은 퍼셉트론의 단점인 가중치와 임계값을 사람이 직접 정해야 한다는 문제를 해결한다. 가중치 매개변수(parameter)의 적절한 값을 데이터로부터 자동으로 학습하기 때문이다.

## 핵심 포인트
- 퍼셉트론은 가중치와 임계값을 사람이 직접 정해야 하며, 가중치가 수백만 개라면 불가능하다
- 신경망은 가중치 매개변수의 적절한 값을 데이터로부터 자동으로 학습한다
- 입력층, 은닉층, 출력층으로 구성되며 은닉층의 값은 겉으로 드러나지 않고 신경망 안에서만 쓰인다
- 구조는 다층 퍼셉트론과 거의 같고, 차이는 활성화 함수에 있다
