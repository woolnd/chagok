# 활성화 함수

## 정의
활성화 함수(activation function): 입력 신호에 가중치를 곱하고 편향을 더한 총합을 받아, 이를 적절한 출력 신호로 변환해 주는 함수다.

## 핵심 포인트
- 입력 신호의 총합 b + w₁x₁ + w₂x₂를 어떤 함수 h(x)가 변환하여 출력 y를 만드는가? (y = h(a), a = b + w₁x₁ + w₂x₂)
- h(x)가 활성화 여부를 정하는 역할을 한다는 점: 계단 함수 h(x)에서 x ≤ 0이면 출력 0, x > 0이면 출력 1인가?
- 편향 b는 임계값 θ의 음수(b = −θ)이며, 임계값이 높을수록 편향이 작아 활성화되기 어렵다는 관계
