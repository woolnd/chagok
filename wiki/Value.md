# Value

## 정의
Value (V): 실제로 가져올 정보. 각 단어 벡터 x에 가중치 행렬 W_V를 곱해 V = X × W_V로 만든다.

## 핵심 포인트
- Value는 실제로 가져올 정보이며, 어텐션 가중치로 V를 가중합해 결과를 만든다.
- Q, K, V는 각각 서로 다른 학습되는 가중치 행렬(W_Q, W_K, W_V)을 곱해 만든다.
- 도서관 비유에서 Value는 책의 실제 내용에 해당하며, 검색어(Query)와 제목·키워드(Key)가 비슷할수록 그 내용을 많이 가져온다.
