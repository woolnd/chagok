# ReLU 함수

## 정의
ReLU(Rectified Linear Unit) 함수: 입력이 0을 넘으면 그 입력을 그대로 출력하고, 0 이하이면 0을 출력하는 함수.

## 핵심 포인트
- 입력이 0보다 크면 출력은 입력 그대로이고, 0 이하이면 출력은 0이다 (h(x) = x (x > 0), h(x) = 0 (x ≤ 0)).
- 시그모이드 함수와 달리 입력이 0보다 크면 기울기가 항상 1이라 기울기가 줄어들지 않아 기울기 소실 문제를 완화한다.
- 음수 입력에서는 기울기가 0이라 뉴런이 죽는 문제가 있으며, 이를 위해 Leaky ReLU 같은 변형을 쓰기도 한다.
