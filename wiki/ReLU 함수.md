# ReLU 함수

## 정의
ReLU(Rectified Linear Unit) 함수는 입력이 0을 넘으면 입력을 그대로 출력하고, 0 이하이면 0을 출력하는 함수다.

## 핵심 포인트
- h(x) = x (x > 0), h(x) = 0 (x ≤ 0)으로 정의되며, 0에서 꺾이므로 전체로 보면 비선형 함수다.
- 시그모이드 대신 ReLU를 쓰는 이유는 기울기 소실을 줄이기 위해서다. 입력이 0보다 크면 기울기가 항상 1이라 여러 번 곱해도 줄어들지 않는다.
- 입력이 0 이하이면 기울기가 0이라 뉴런이 계속 음수만 받으면 학습되지 않는 '뉴런이 죽는다(dying ReLU)' 문제가 있으며, 이를 완화하려고 Leaky ReLU 같은 변형을 쓰기도 한다.
