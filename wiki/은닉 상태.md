# 은닉 상태

## 정의
RNN의 출력 hₜ를 은닉 상태(hidden state) 혹은 은닉 상태 벡터(hidden state vector)라고 한다.

## 핵심 포인트
- 은닉 상태 hₜ는 hₜ = tanh(hₜ₋₁ W_h + xₜ W_x + b)로 계산되며, 이전 시각의 출력 hₜ₋₁에 기초해 갱신된다.
- RNN 계층을 상태를 가지는 계층 혹은 메모리가 있는 계층이라고 하는 이유가 은닉 상태에 있다.
- LSTM에서 은닉 상태 h는 hₜ = o ⊙ tanh(cₜ)로 구하며, RNN 계층과 마찬가지로 다른 계층으로 출력된다. 기억 셀 c는 LSTM 계층 내에서만 주고받는다.
