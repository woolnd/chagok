# 멀티헤드 어텐션

## 정의
어텐션을 여러 개(헤드) 병렬로 계산한다. 헤드마다 서로 다른 가중치 W_Qᵢ, W_Kᵢ, W_Vᵢ로 Q, K, V를 작은 차원(d_k = d_model / h)으로 변환해 각각 Scaled Dot-Product Attention을 계산하고, h개 헤드의 결과를 연결(Concat)한 뒤 출력 가중치 W_O를 곱한다.

## 핵심 포인트
- 어텐션을 하나만 쓰면 한 단어가 주목하는 방식이 한 가지로 정해지지만, 헤드를 여러 개 두면 단어 사이의 여러 종류 관계를 동시에 학습할 수 있다.
- 헤드마다 차원을 1/h로 줄이므로(d_k = 512 / 8 = 64) 전체 계산량은 큰 어텐션 하나를 쓸 때와 비슷하다.
- h개 헤드 결과를 Concat하면 다시 d_model 크기(64 × 8 = 512)가 되고, W_O로 헤드들의 정보를 섞어 최종 출력을 만든다.
