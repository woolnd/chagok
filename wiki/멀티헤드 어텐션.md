# 멀티헤드 어텐션

## 정의
멀티헤드 어텐션(Multi-Head Attention)은 어텐션을 여러 개(헤드) 병렬로 계산한다.

## 핵심 포인트
- 헤드마다 서로 다른 가중치 W_Qᵢ, W_Kᵢ, W_Vᵢ로 Q, K, V를 작은 차원(d_k = d_model / h)으로 변환한 뒤 각 헤드가 Scaled Dot-Product Attention을 따로 계산한다.
- h개 헤드의 결과를 Concat하여 d_model 크기로 되돌리고, 출력 가중치 W_O를 곱해 헤드들의 정보를 섞어 최종 출력을 만든다.
- 헤드마다 가중치가 달라 서로 다른 관점의 단어 관계를 학습하며, 헤드마다 차원을 1/h로 줄였으므로 전체 계산량은 큰 어텐션 하나를 쓸 때와 비슷하다.
