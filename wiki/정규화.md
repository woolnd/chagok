# 정규화

## 정의
정규화(normalization)는 데이터를 특정 범위로 변환하는 처리다. 값에서 평균을 빼고 표준편차로 나누어, 값들의 순서와 상대적 간격은 유지한 채 평균 0, 분산 1인 분포로 맞추는 것이다.

## 핵심 포인트
- 정규화된 값 = (값 − 평균) / 표준편차 로 계산한다
- 예: 0~255 범위의 픽셀 값을 255로 나눠 0~1 범위로 바꾸는 것이 정규화다
- 배치 정규화는 미니배치 단위로 각 층의 값을 평균 0, 분산 1로 정규화한 뒤 학습되는 γ(확대)와 β(이동)로 다시 조정한다
