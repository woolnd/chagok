# L1 노름

## 정의
노름(norm)은 벡터의 크기(길이)를 재는 방법이다. L2 노름은 √(w₁² + w₂² + … + wₙ²)이고, L1 노름은 |w₁| + |w₂| + … + |wₙ|이다.

## 핵심 포인트
- L2 노름은 벡터의 길이(√ 합)이고, L1 노름은 절댓값의 합이다. 예: (3, 4)의 L2 노름은 5, L1 노름은 7이다.
- 가중치 감소에서 노름은 가중치의 크기를 재어 벌칙을 주는 데 쓰인다.
- L2 정규화는 L2 노름의 제곱에 ½λ를 곱해 손실에 더하며, 가중치를 0 쪽으로 비례해 끌어당겨 0이 되지는 않는다. L1 정규화는 L1 노름에 λ를 곱해 더하며, 작은 가중치를 아예 0으로 만든다.
