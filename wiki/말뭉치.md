# 말뭉치

## 정의
말뭉치(corpus)는 자연어 처리를 위해 모아 둔 대량의 텍스트 데이터다. 자연어 처리 연구나 앱을 염두에 두고 수집된 텍스트 데이터를 일반적으로 말뭉치라고 한다.

## 핵심 포인트
- 사람이 쓴 문장은 그대로는 컴퓨터가 계산할 수 없으므로 정제 → 정규화 → 토큰화 → 정수 인코딩과 패딩 → 벡터화 과정을 거쳐 숫자(벡터)로 바꿔 모델에 넣는다
- 정제는 분석에 방해되는 불필요한 문자(특수문자, 이모티콘, 반복 문자, HTML 태그, URL 등)를 지우는 단계다
- 토큰화는 문장을 모델이 처리할 최소 단위(토큰)로 나누는 단계이며, 한국어는 조사·어미 때문에 형태소 분석기로 나누는 경우가 많다
