# L2 정규화

## 정의
L2 정규화(L2 regularization)는 L2 노름의 제곱에 ½λ를 곱해 손실에 더한다.

## 핵심 포인트
- 새 손실 = 원래 손실 + ½λ(w₁² + w₂² + … + wₙ²)이며, 미분하면 기울기 = 원래 기울기 + λW가 된다
- 매 갱신마다 가중치가 자기 크기에 비례해 0 쪽으로 끌려가며, 큰 가중치는 크게 줄고 전체가 골고루 작아진다(0이 되지는 않는다)
- λ는 벌칙의 세기로 클수록 가중치를 강하게 누른다
