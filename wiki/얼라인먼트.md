# 얼라인먼트

## 정의
얼라인먼트란 출발어 문장과 도착어 문장에서 서로 대응하는 단어(또는 문구) 쌍을 말한다.

## 핵심 포인트
- 얼라인먼트는 각 시각에서 Decoder가 다음에 출력할 단어와 대응 관계인 입력 단어의 벡터를 hs에서 골라내는 것을 뜻한다. 예: Decoder가 "I"를 출력할 때 hs에서 "나"에 대응하는 벡터 선택
- 얼라인먼트 추출은 원래 사람이 수작업으로 하거나 통계적 방법으로 따로 추출했는데, 어텐션은 학습 과정에서 어텐션 가중치를 통해 얼라인먼트를 자동으로 학습한다
- 출력 시각별 가중치 a를 행으로 쌓아 시각화하면 출력 단어마다 어떤 입력 단어에 주목했는지 확인할 수 있다 (가로축 입력 단어, 세로축 출력 단어)
