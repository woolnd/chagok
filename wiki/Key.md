# Key

## 정의
각 단어가 어떤 정보를 가졌는지 나타내는 표지. 트랜스포머는 각 단어 벡터 x에 가중치 행렬 W_K를 곱해 K = X × W_K로 만든다.

## 핵심 포인트
- Query와 내적해 단어 쌍의 유사도 점수를 구하는 데 쓰인다
- 앞에서 본 어텐션에서는 hs 하나가 Key와 Value 역할을 함께 했고, 트랜스포머는 Key를 Value와 따로 만든다
- W_K는 학습되는 매개변수이므로 무엇을 표지로 삼을지 학습으로 정해진다
- 도서관 검색에 비유하면 각 책의 제목과 키워드에 해당한다
