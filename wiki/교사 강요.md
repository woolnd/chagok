# 교사 강요

## 정의
학습 시와 생성 시의 차이에서, 학습 시에는 각 시각의 입력으로 모델의 예측이 아닌 정답 단어를 넣는다. 이를 교사 강요(teacher forcing)라고 한다.

## 핵심 포인트
- 학습 시에는 정답을 알고 있으므로 시계열 방향의 데이터를 한꺼번에 줄 수 있다
- 각 시각의 입력으로 모델의 예측 대신 정답 단어를 넣는다
- 생성(추론) 시에는 정답을 모르므로 직전 출력을 다음 입력으로 사용하는 방식과 대비된다
