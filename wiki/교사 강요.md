# 교사 강요

## 정의
학습 시에는 정답을 알고 있기 때문에 시계열 방향의 데이터를 한꺼번에 줄 수 있다. 각 시각의 입력으로 모델의 예측이 아닌 정답 단어를 넣는다. 이를 교사 강요(teacher forcing)라고 한다.

## 핵심 포인트
- 학습 시 각 시각의 입력으로 모델의 예측이 아닌 정답 단어를 넣는다는 점
- 생성(추론) 시에는 정답을 모르므로 <eos> 하나만 주고, 출력에서 고른 단어를 다음 입력으로 사용하는 반복 과정이라는 점
- 학습 시(정답 입력)와 생성 시(직전 출력 입력)의 데이터 부여 방법 차이
