# update 게이트

## 정의
update 게이트 z는 은닉 상태를 얼마나 갱신할지 정한다. (1 − z) ⊙ hₜ₋₁ 부분은 과거 정보 중 무엇을 잊을지 정하므로 LSTM의 forget 게이트 역할을 하고, z ⊙ h̃ 부분은 새로 추가할 정보에 가중치를 주므로 input 게이트 역할을 한다.

## 핵심 포인트
- update 게이트 하나가 LSTM의 forget 게이트와 input 게이트의 역할을 함께 한다
- GRU에서 reset 게이트 r과 update 게이트 z 2개만 쓰는 구조를 알아야 한다
- r이 0에 가까우면 새 은닉 상태 후보 h̃는 과거 은닉 상태를 거의 보지 않고 입력만으로 결정된다
