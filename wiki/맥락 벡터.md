# 맥락 벡터

## 정의
출발어 단어 벡터들의 가중합으로 얻는 벡터. 각 입력 단어의 가중치 a(총합 1)와 단어 벡터 hs로 계산하며, c = Σᵢ aᵢ hsᵢ로 표기한다.

## 핵심 포인트
- 가중치 a는 각 원소가 0.0~1.0 사이의 스칼라이고 모든 원소의 총합은 1이다
- 가중치가 한 단어에 1, 나머지에 0이면 그 단어를 정확히 선택한 것과 같다
- 가중합은 곱셈과 덧셈으로만 이루어져 미분 가능하므로 선택 작업을 대체할 수 있다
- Attention 계층에서 맥락 벡터 c는 Decoder LSTM의 은닉 상태 h와 연결되어 Affine 계층에 입력된다
