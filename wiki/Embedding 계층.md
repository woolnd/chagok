# Embedding 계층

## 정의
Embedding 계층은 단어 ID에 해당하는 가중치 행을 바로 추출하는 계층이다. 원핫 표현으로 변환하고 MatMul 계층에서 행렬 곱을 하는 과정은 필요 없다.

## 핵심 포인트
- 원핫 벡터는 한 칸만 1이므로 MatMul의 결과는 가중치 행렬에서 해당 단어 ID의 행을 추출하는 것과 같다
- 가중치 W_in은 모든 단어의 임베딩 값을 단어 ID 순서대로 행마다 저장한 임베딩 테이블이다
- 순전파에서는 입력된 단어 ID에 해당하는 행만 추출해 출력하며, 미니배치 입력이면 해당 행들을 한꺼번에 꺼내 행렬로 출력한다
- 구조상 완전연결 계층과 같지만 입력 노드를 계산하지 않고 행만 꺼내며, 편향과 활성화 함수가 없다
