# 특징

## 정의
특징(feature)은 입력 데이터에서 본질적인 데이터를 정확하게 추출할 수 있도록 설계된 변환기다.

## 핵심 포인트
- 특징은 입력 데이터에서 본질적인 데이터를 추출하도록 설계된 변환기이다
- 이미지의 특징은 보통 벡터로 기술하며, 변환된 벡터를 지도 학습 분류 기법(SVM, KNN 등)으로 학습한다
- 특징은 사람이 설계하며, 문제에 적합한 특징을 쓰지 않으면 좋은 결과를 얻을 수 없다
