# Query

## 정의
Query는 지금 무엇을 찾고 있는가를 나타내는 벡터이며, 각 단어 벡터 x에 가중치 행렬 W_Q를 곱해 Q = X × W_Q로 만든다.

## 핵심 포인트
- Query는 검색어에 비유되며, Key·Value와 함께 각 단어 벡터에 서로 다른 학습 가중치 행렬을 곱해 만든다.
- 앞에서 본 어텐션에서는 Decoder의 은닉 상태 h가 Query 역할을 했다.
- Query와 Key를 내적해 유사도 점수를 구하고 이를 Value의 가중합에 사용한다.
