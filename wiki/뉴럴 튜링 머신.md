# 뉴럴 튜링 머신

## 정의
사람은 복잡한 문제를 풀 때 종이와 펜이라는 외부 저장 장치를 쓴다. 신경망도 외부 메모리를 이용해 능력을 확장할 수 있다. RNN 외부에 메모리를 두고 어텐션으로 읽고 쓰는 대표적인 연구가 딥마인드(DeepMind)의 뉴럴 튜링 머신(NTM, Neural Turing Machine)이다.

## 핵심 포인트
- NTM은 LSTM 컨트롤러, Write Head 계층, Read Head 계층으로 구성되며, Write Head는 LSTM의 은닉 상태를 받아 메모리에 쓰고 Read Head는 메모리에서 정보를 읽어 다음 시각의 LSTM으로 전달한다.
- 메모리 번지 선택은 미분할 수 없으므로 어텐션으로 모든 번지의 기여도를 가중치로 나타내 미분 가능한 계산으로 대체한다.
- 콘텐츠 기반 어텐션(질의 벡터와 비슷한 벡터를 찾기)과 위치 기반 어텐션(이전 가중치 기준으로 전후 시프트, 1차원 합성곱으로 구현)의 두 가지 어텐션을 사용한다.
- 메모리 조작이 미분 가능하므로 알고리즘 자체(로직)를 입력과 출력으로부터 학습할 수 있다.
