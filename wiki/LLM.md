# LLM

## 정의
말뭉치(corpus)는 자연어 처리를 위해 모아 둔 대량의 텍스트 데이터다. 자연어 처리 연구나 앱을 염두에 두고 수집된 텍스트 데이터를 일반적으로 말뭉치라고 한다.

## 핵심 포인트
- LLM에서 토큰이 처리의 기본 단위이므로 입력 길이(컨텍스트 길이)와 사용 비용이 토큰 수 기준으로 계산된다
- 사람이 쓴 문장을 컴퓨터가 계산하려면 정제 → 정규화 → 토큰화 → 정수 인코딩과 패딩 → 벡터화 과정을 거친다
- 현재 LLM에서 사용하는 표준 토큰화 방식은 서브워드 방식이며, 대표적인 예가 BPE(Byte Pair Encoding)다
