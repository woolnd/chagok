# LLM

## 정의
LLM(Large Language Model)은 다음 토큰을 하나씩 예측하는 방식으로 동작하며, 이는 언어 모델을 트랜스포머 Decoder로 구현한 것이다.

## 핵심 포인트
- LLM에서 토큰이 처리의 기본 단위이며, 입력 길이(컨텍스트 길이)와 사용 비용이 모두 토큰 수를 기준으로 계산된다
- 같은 문장도 토큰화 방식과 언어에 따라 토큰 수가 달라지며, 일반적으로 한국어는 영어보다 같은 내용에 더 많은 토큰이 필요하다
- 현재 LLM에서 사용하는 표준 토큰화 방식은 서브워드 방식이다
