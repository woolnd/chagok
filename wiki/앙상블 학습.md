# 앙상블 학습

## 정의
여러 모델을 따로 학습시킨 뒤, 시험 때 출력을 평균 내는 방법이다. 모델마다 하는 실수가 달라 서로 상쇄되므로 성능이 좋아진다.

## 핵심 포인트
- 여러 모델을 따로 학습시킨 뒤 시험 때 출력을 평균 낸다
- 모델마다 하는 실수가 달라 서로 상쇄되어 성능이 좋아진다
- 드롭아웃은 매번 다른 뉴런 조합(작은 신경망)을 학습하고 시험 때 평균 내는 것과 비슷해, 모델 하나로 앙상블 효과를 낸다
