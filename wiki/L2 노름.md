# L2 노름

## 정의
L2 노름은 벡터의 길이로, 각 원소를 제곱해 더한 뒤 제곱근을 취한 값이다. L2 노름 = √(w₁² + w₂² + … + wₙ²).

## 핵심 포인트
- L2 노름은 √(w₁² + … + wₙ²)로 벡터의 길이를 뜻한다. 예: (3, 4)의 L2 노름은 5이다.
- L1 노름(|w₁| + … + |wₙ|)과 계산 방식을 구분해야 한다. 예: (3, 4)의 L1 노름은 7이다.
- L2 정규화는 L2 노름의 제곱에 ½λ를 곱해 손실에 더하며, 미분하면 기울기에 λW가 더해져 가중치가 0 쪽으로 비례해 줄어든다(0이 되지는 않는다).
