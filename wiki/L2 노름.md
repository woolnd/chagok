# L2 노름

## 정의
L2 노름은 각 가중치를 제곱해 더한 뒤 루트를 씌운 값이다.

## 핵심 포인트
- L2 노름은 각 가중치를 제곱해 더한 뒤 루트를 씌운 값이다 (√(w₁² + w₂² + … + wₙ²))
- L1 노름과의 차이: L1 노름은 각 가중치의 절댓값을 더한 값이다
- L2 노름은 벡터의 길이(크기)를 나타내며, L2 정규화에서 가중치 크기를 재는 데 쓰인다
