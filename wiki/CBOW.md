# CBOW

## 정의
맥락으로부터 타깃(target, 가운데 단어)을 추측하는 용도의 신경망이다. 입력은 맥락이고, 이 맥락을 원핫 표현으로 바꿔 CBOW 모델이 처리할 수 있도록 준비한다.

## 핵심 포인트
- 입력 맥락이 여러 개일 때 은닉층 값은 전체를 평균하며, 맥락 입력들은 모두 같은 입력 측 가중치 W_in을 공유한다.
- 입력 측 가중치 W_in이 단어 분산 표현의 정체이며, 원핫 벡터와 가중치의 곱은 해당 단어 ID 위치의 가중치 행을 꺼내는 것이다.
- CBOW는 다중 클래스 분류를 수행하므로 소프트맥스와 교차 엔트로피 오차로 학습하며, 손실은 L = −log P(wₜ | wₜ₋₁, wₜ₊₁)이다.
- CBOW는 타깃 하나의 손실만 구하며, skip-gram보다 학습 속도가 빠르다.
