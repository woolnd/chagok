# input 게이트

## 정의
input 게이트(입력 게이트)는 g의 각 원소가 새로 추가되는 정보로서 가치가 얼마나 큰지를 판단하는 게이트다. 새 정보를 무비판적으로 수용하는 게 아니라 적절히 취사선택하는 것이 이 게이트의 역할이며, input 게이트에 의해 가중된 정보가 새로 추가된다.

## 핵심 포인트
- input 게이트의 출력 i는 시그모이드 함수로 구하며, 0.0~1.0 사이의 비율을 뜻한다.
- i와 g의 원소별 곱(아다마르 곱)을 기억 셀 cₜ₋₁에 더해 새로운 기억을 추가한다.
- g는 현재 입력과 이전 은닉 상태로 만든 새 정보를 tanh로 구한 값이며, g 자체는 게이트가 아니다.
