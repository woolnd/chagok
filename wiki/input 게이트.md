# input 게이트

## 정의
input 게이트(입력 게이트)는 g의 각 원소가 새로 추가되는 정보로서 가치가 얼마나 큰지를 판단한다. 새 정보를 무비판적으로 수용하는 게 아니라 적절히 취사선택하는 것이 이 게이트의 역할이다.

## 핵심 포인트
- input 게이트의 출력 i는 시그모이드 함수로 구하며, 입력 xₜ와 이전 은닉 상태 hₜ₋₁로부터 계산된다
- i와 g의 원소별 곱(아다마르 곱)을 기억 셀에 더해 새로운 정보를 추가한다
- input 게이트는 게이트이므로 활성화 함수로 시그모이드를 쓰고, g는 게이트가 아니므로 tanh를 쓴다
