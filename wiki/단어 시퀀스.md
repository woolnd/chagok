# 단어 시퀀스

## 정의
단어 시퀀스는 문장을 단어 단위로 나눠 순서대로 나열한 것으로, 순서가 의미를 가지며 정수 인코딩 후에는 단어 ID 시퀀스로 모델에 입력된다.

## 핵심 포인트
- 단어 시퀀스는 단어를 순서대로 나열한 것이므로 순서가 의미를 가진다.
- 정수 인코딩 후에는 단어 ID 시퀀스 형태로 모델에 입력된다.
- 언어 모델은 단어 시퀀스에 확률을 부여해 문장의 자연스러움을 평가한다.
