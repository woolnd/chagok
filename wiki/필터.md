# 필터

## 정의
합성곱 연산은 이미지 처리에서 말하는 필터(filter) 연산에 해당한다. 합성곱 계층의 필터(가중치)는 무엇을 찾을지에 대한 기준이다.

## 핵심 포인트
- 필터는 커널(kernel)이라고도 하며, 윈도우를 일정 간격으로 이동하며 입력 데이터에 적용된다.
- 필터의 값은 사람이 정하지 않고 순전파, 역전파, 경사 하강법으로 학습해 정해진다.
- 필터는 모든 입력 이미지에 똑같이 적용되며, 층이 깊어질수록 가장자리에서 사물의 부분으로 점점 추상적인 패턴을 찾는다.
