# 패딩

## 정의
합성곱 계층의 입력 데이터 주변을 특정 값(보통 0)으로 채우는 것을 패딩(padding)이라 한다.

## 핵심 포인트
- 합성곱을 거칠 때마다 크기가 줄어 층을 깊게 쌓으면 출력이 1×1이 되어 더 이상 합성곱을 할 수 없게 되므로, 이를 막기 위해 패딩을 쓴다
- 패딩은 주로 출력 크기를 조정하기 위해 쓰며, 가장자리 픽셀이 필터의 가운데에 올 수 있어 가장자리 정보가 덜 손실된다
- 패딩 P, 스트라이드 S일 때 출력 크기는 OH = (H + 2P − FH) / S + 1 이다
- 패딩 1, 입력 (4, 4), 필터 (3, 3), 스트라이드 1이면 출력은 (4, 4)로 입력 크기가 유지된다
