# 출력 측 가중치

## 정의
word2vec에서 사용하는 신경망에는 입력 측 완전연결 계층의 가중치(W_in)와 출력 측 완전연결 계층의 가중치(W_out) 두 가지가 있다. 입력 측 가중치 W_in은 각 행이 각 단어의 분산 표현에 해당하고, 출력 측 가중치 W_out에는 단어의 분산 표현이 열 방향으로 저장된다.

## 핵심 포인트
- 출력 측 가중치 W_out에는 단어의 분산 표현이 열 방향으로 저장된다
- 최종 분산 표현으로 입력 측 가중치만, 출력 측 가중치만, 또는 양쪽을 모두 이용하는 세 가지 선택지가 있다
- word2vec에서는 입력 측 가중치만 이용하는 것이 가장 대중적인 선택이다
- GloVe에서는 두 가중치를 더했을 때 좋은 결과를 얻었다
