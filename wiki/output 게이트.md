# output 게이트

## 정의
output 게이트(출력 게이트)는 tanh(cₜ)의 각 원소가 다음 시각의 은닉 상태에 얼마나 중요한지를 조정하는 게이트다. 다음 은닉 상태 hₜ의 출력을 담당하므로 output 게이트라고 한다.

## 핵심 포인트
- output 게이트의 열림 상태 o는 입력 xₜ와 이전 은닉 상태 hₜ₋₁로부터 σ(xₜW_x⁽ᵒ⁾ + hₜ₋₁W_h⁽ᵒ⁾ + b⁽ᵒ⁾)로 구한다
- 은닉 상태는 hₜ = o ⊙ tanh(cₜ)로 계산하며, ⊙는 원소별 곱인 아다마르 곱이다
- 게이트에는 시그모이드 함수(0.0~1.0 비율), 정보를 지니는 데이터에는 tanh 함수가 활성화 함수로 쓰인다는 역할 구분
