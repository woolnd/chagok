# 정제

## 정의
정제(cleaning)는 분석에 방해되는 불필요한 문자를 지우는 단계다. 특수문자, 이모티콘, 반복 문자(ㅋㅋㅋ), HTML(HyperText Markup Language) 태그, URL(Uniform Resource Locator) 등을 지운다.

## 핵심 포인트
- 정제는 분석에 방해되는 불필요한 문자를 지우는 단계이다
- 지우는 대상의 예: 특수문자, 이모티콘, 반복 문자(ㅋㅋㅋ), HTML 태그, URL
- 의미 없는 기호가 단어로 취급되면 단어 수만 늘고 학습에 방해가 되기 때문에 정제한다
