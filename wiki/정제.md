# 정제

## 정의
말뭉치(corpus)는 자연어 처리를 위해 모아 둔 대량의 텍스트 데이터다. 정제는 분석에 방해되는 불필요한 문자를 지우는 단계다.

## 핵심 포인트
- 특수문자, 이모티콘, 반복 문자(ㅋㅋㅋ), HTML 태그, URL 등을 지운다
- 의미 없는 기호가 단어로 취급되면 단어 수만 늘고 학습에 방해가 되기 때문이다
- 정제 → 정규화 → 토큰화 → 정수 인코딩과 패딩 → 벡터화 순서에서 첫 번째 단계다
