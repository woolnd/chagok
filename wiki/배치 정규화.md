# 배치 정규화

## 정의
배치 정규화(Batch Normalization)는 미니배치 단위로 각 층의 값을 평균 0, 분산 1로 정규화한 뒤, 학습되는 γ(확대)와 β(이동)로 다시 조정하는 방법이다. 신경망 중간 층(활성화 함수 앞 또는 뒤)에 끼워 넣는다.

## 핵심 포인트
- 각 층으로 들어오는 값의 분포를 학습 내내 일정하게 맞춰 활성화값이 고르게 퍼진 상태를 직접 유지한다
- 효과: 학습이 빠르고 학습률을 크게 잡아도 안정적으로 수렴하며, 가중치 초깃값에 덜 민감하고, 과대적합을 어느 정도 억제한다
- γ는 확대, β는 이동을 담당하며 처음에는 γ = 1, β = 0에서 시작해 학습으로 조정한다
