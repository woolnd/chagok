# 배치 정규화

## 정의
배치 정규화(Batch Normalization)는 각 층에서 값을 미니배치 단위로 평균 0, 분산 1이 되도록 정규화하는 방법이다. 층 사이(활성화 함수 앞 또는 뒤)에 끼워 넣는다.

## 핵심 포인트
- 정규화는 값에서 평균을 빼고 표준편차로 나누는 것이며, 값들의 순서와 상대적 간격은 그대로 두고 위치(평균)와 퍼짐(분산)만 맞춘다
- 정규화만 하면 표현력이 제한될 수 있어 학습되는 매개변수 γ(확대)와 β(이동)로 다시 조정하며, γ = 1, β = 0에서 시작한다
- 효과: 학습이 빠르고 학습률을 크게 잡아도 안정적으로 수렴하며, 초깃값에 덜 민감하고, 미니배치마다 생기는 잡음 효과로 과대적합을 어느 정도 억제한다
- 추론할 때는 미니배치 평균·분산을 구할 수 없으므로 학습 중 저장해 둔 미니배치 평균·분산의 이동평균으로 정규화한다
